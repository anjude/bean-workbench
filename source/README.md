# 原始素材库

`source/local-source/` 用于存放本机保留的原始素材，不进入 Git。这里的文件保持获取时的原貌，不编辑、不覆盖，也不放筛选结果、改造版本或构建产物。

需要挑选或二次开发时，先从 `source/local-source/` 复制到对应任务或业务仓的工作目录，再修改副本。后续切换任务时，仍从工作台根目录的 `source/README.md` 找到素材位置。
