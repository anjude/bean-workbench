## 得到的结论

- `portfolio-performance/portfolio` 可作交易流水和组合绩效参考；仓库采用 EPL-1.0，项目规模约 4.1k stars / 8,548 commits：`https://github.com/portfolio-performance/portfolio`。
- `QuantConnect/Lean` 可作合约/行情模块边界和数据/策略分层参考；仓库采用 Apache-2.0，项目规模约 22.2k stars / 13,408 commits；完整交易引擎范围超出当前个人只读系统：`https://github.com/QuantConnect/Lean`。
- `goldspanlabs/optopsy` 可参考期权策略统计与缓存，但采用 AGPL-3.0，README 提醒回测未完整覆盖流动性、滑点、指派和市场变化：`https://github.com/goldspanlabs/optopsy`。
- `yomikoye/optionable` 与 CSP/CC 记账流程接近，但 GitHub 页面显示约 15 stars / 45 commits，且页面未显示许可，不作为成熟范本或代码来源：`https://github.com/yomikoye/optionable`。
- 方案结论：借鉴成熟项目的流水事实源、合约与数据分层、绩效重算和质量状态；不移植完整自动交易平台。具体取舍见 `plans/美股期权投资分析系统.md`。
