## 每日投资报告

- 每份日报按理财skill的[每日持仓自检清单](../../../.agents/skills/finance-tools-investment/references/每日持仓自检清单.md)执行逐标的及组合检查；先核仓位，再查长期资格、估值/预期、自身与关联事件、期限、资金和压力，最后比较方案。未知项不显示通过；完整过程默认不落盘，正文只展示影响决定的结论与异常。

- 滚仓净收入放在“本周到期”重点持仓表，分“模型净收”和“报价净收区间”两列；相同目标展期日统一注明，其他仓位用简表保留，计算口径见理财 skill。

- 理财日报顺序：今天看这三件事（事件旁压缩列财报）→ 本周到期重点表 → 其他持仓简表 → 资金一行结论 → 数据说明。行情按标的只展示一次，股价和涨跌分列；合约名使用六位日期，张数和距到期单列。当前会话不渲染HTML颜色，不输出原始标签；细则见理财skill。
- 自动化「每日美股仓位分析与待补信息」（ID：`automation-2`）已按用户要求改为每天 **22:00（Asia/Shanghai）**；周末和休市日提供简短版。开盘后仍检查报价时间/状态与 IV 有效性，不保证权限或数据一定充分。
- 固定22:00按用户要求保留：美东夏令时常规开盘为上海21:30，冬令时为22:30；冬令时22点仍盘前，应据交易日历/时区标注，不假定全年此时都有盘中IV，不擅自改时间。
- 内容覆盖仓位/近期期限、价格与未来 14 天全局/标的事件、持有/开仓/roll/平仓条件比较；末尾最多列 3 项最影响判断的待补信息，注明补充后能完成什么计算。
- 围绕当周剩余权利金目标给候选比较：净收入/目标贡献、接股义务及资金余量变化、期限与新增事件、适用条件；互斥候选不重复累加，组合候选合并核算资金。无有效报价则给观察条件，无合格机会直接说明，不为达标扩大风险。
- 优先使用现有只读行情工具；无法更新时使用带原始时点的快照并注明冻结/过期，仍完成已有数据范围内的报告。不新增数据接入开发，不读取券商账户数据或创建订单。
- 日报全文直接展示在会话，用户要求时才保存；用户确认成交后持续维护仓位、流水和周目标，未经确认不假定成交/指派。首份定时日报已于 2026-10-26 晚间生成，过程见 `process/07-每日投资报告自动化.md`。
