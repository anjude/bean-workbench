  - 新建 `trigger_strategy/weekly_checkin_strategy.go`：沿用 HH:MM 编码比较（`GetHourMinFromTime`），每天 21:06 命中一次；`SubTimes<=0` 或 1 分钟内已触发则跳过。
  - `subscribe_processor.go` `NewSubscribeProcessors()`、`trigger_strategy.go` `NewTriggerStrategies()` 重新登记 weeklyCheckin 处理器/策略。
  - **不恢复独立 `WeeklyCheckinJob` cron**：统一 `MessageSubscribeJob`（每分钟扫描 `sub_times>0` + 按类型策略触发）已覆盖，无需单独任务。
