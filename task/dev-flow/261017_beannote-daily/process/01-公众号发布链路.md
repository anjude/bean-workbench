## 得到的结论

- **draft/add 必须带 `thumb_media_id`**：缺封面报 `40007 invalid media_id`，与正文内容无关（最小 payload `<p>test</p>` 复现）；带上合法封面 media_id 立即成功。`draft/batchget` 可正常读，说明账号有草稿箱读权限、不是账号类型问题
- **代理按目标主机粘住出口 IP**：api.weixin.qq.com 固定从 `58.251.160.140` 出，ipify 等站点从 `103.135.104.236` 出。查微信白名单 IP 别用通用回显站，以微信 `40164` 报错里的 IP 为准
- 封面链路可行：ImageGen 生成 → `sips --cropToHeightWidth` 居中裁 2.35:1（切掉右下角 AI 水印）→ JPEG 85% → `material/add_material` 上传换 media_id
- 排版输入要切元数据：选题判断、封面 prompt、留言引导不进排版，只排「标题 + 正文」

## 被推翻的判断

- 初判 `40007` 是内容问题（HTML 不合规或字段缺失）→ 最小 payload 同样报错，排除内容因素；再判是账号无草稿箱权限 → `draft/batchget` 成功且有 36 篇存量草稿，排除；最后定位到缺 thumb_media_id
- 初判出口 IP 不稳定（ipify 显示与微信报错不同）→ 连续探测发现按目标主机粘住，微信侧 IP 稳定
