## 目标

- 涉及 `business-repo/uni-gknow`、`business-repo/backend-superone` 与 `business-repo/frontend-contracts`，以及首测内容和微信入口。
- 现有测试的迁移不属于当前方案范围；用户已授权代码开发及本次新建单表 DDL，test 库 DDL 已执行；部署仍需按规则确认。
