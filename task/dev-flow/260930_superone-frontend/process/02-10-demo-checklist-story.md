# 02-10 演示页补「名人如何用清单」的内容层

> 豆哥：「演示页的执行清单介绍，要把名人使用的逻辑也写一写，比如巴菲特如何使用清单的」。

## 判断：这不是加一段文案，是把演示页的叙事补全
演示页原本是「是什么（hero）→ 分享图卡 → 能做什么 → 怎么用」，中间缺一环：
**凭什么是清单**。名人案例的作用不是背书，是回答「清单防的是哪一类错」——
漏掉的事本事本来就有，只是到点没想起来。这一环补上，产品介绍才立得住。

## 事实核查（不凭印象编）
- 阿图·葛文德《清单革命》：人的失误分两类——**无知之错**（没掌握知识，可原谅）与
  **无能之错**（掌握了却没正确使用，不可原谅）。清单只管后一种。
- 1935 年波音 **Model 299** 首飞坠毁（起飞前漏了解锁），军方的解法是给飞行员一张起飞前检查单，
  这型飞机后来定名 **B-17**。→ 文案里写「波音 Model 299 试飞」，不直接写 B-17，避免时间线含糊。
- 约翰·霍普金斯医院 **Peter Pronovost**：把中心静脉置管步骤写成五条交护士核对，
  一年防住 43 起感染、8 起死亡，省下 200 万美元。
- 查理·芒格：原话 "I'm a great believer in solving hard problems by using a checklist."；
  投资决策检查清单四条——能力圈（懂不懂）/ 内在价值与持久竞争优势 / 管理层诚信与才能 / 合理价格留安全边际。
- 沃伦·巴菲特：谈收购时说过 "I still would go for the one-page contract"（一页纸原则）；
  买入前的标准（能力圈 / 护城河 / 安全边际）同样是逐条核对的用法。
  → 巴菲特没有公开流传的「清单原件」，所以**不写成他有一张清单**，写他的原则是可核对的条式用法。

## 文案口径（照豆哥的禁用清单自查）
- 无「你」、无破折号、无「不是…而是…」句式、无排比与煽情金句。
- 不吹捧：不写「成功人士都在用」，写具体年份、具体数字、具体条款。
- 名人只做引子，**落点回到产品**：清单防的是「无能之错」，这才是执行清单要解决的问题。

## 排版取舍
- 新增两块卡：**为什么是清单**（两类失误对照，关键项用主色）与**谁在用清单**（1935 / 2001 / 芒格 / 巴菲特）。
- 分享图卡**从 hero 之后挪到页面末尾**：叙事顺序变成
  「是什么 → 为什么有效 → 谁在用 → 能做什么 → 怎么用 → 分享出去」，分享是收尾动作，不该插在开头。
- 样式全走 `--so-*` 令牌（`.so-demo__why-*` / `.so-demo__case-*` / `.so-demo__quote`），
  组件样式留在组件内 scoped，不进 `06-pages`（那是页面专属，这是组件）。
