# Superone 首页 UI 改版方案

## 需求理解

把已选 Figma 首页稿实现到 uni-app 微信小程序首页，先做一版供用户预览。页面保持原有功能和大方向，只调整元素与整体视觉；后端接口不变。

## 产品原型与结构

- **原型：** 模块切换型 dashboard，主题面板承载当前对象列表。
- **依据：** `src/pages/index/index.vue` 现有信息结构就是系统入口、五模块 rail + swiper、当前模块列表和固定主操作；本轮不把它改成另一种首页范式。
- **页面顺序：** 顶部左侧系统/签到；右上保留微信原生胶囊；左侧五模块导航；当前面板的标题、说明和主题列表；底部当前模块名称与唯一主操作。
- **主要动作：** 主题面板的「新建主题」，由现有底栏通过面板实例 `open()` 处理。
- **不出现：** 搜索、筛选、统计数据、新捷径、额外入口、卡片瀑布流、模块分界竖线、装饰性网格/强光斑。

## 状态矩阵

| 场景 | UI 表现 | 数据来源 | 可执行动作 / 回退 |
| --- | --- | --- | --- |
| 首次加载 | 保留现有加载状态组件，统一留在新面板的内容区 | `useTopicList` 当前状态 | 等待加载；不提前显示空态 |
| 有主题 | 轻量行式列表展示标题、可选置顶、更新时间、可选描述 | 现有主题列表 API 和 `rows` 映射 | 点行进详情；长按沿用当前操作菜单；上滑加载更多 |
| 服务端空数据 | 保留现有空态标题与描述 | `items.length === 0` 且无加载/错误 | 现有底部「新建主题」进入创建页 |
| 初次加载失败 | 保留错误信息和「重试」按钮 | `error` | 重试现有 `load` |
| 有数据刷新/分页加载 | 保留列表并在原提示区展示进行中状态 | 现有 composable 状态 | 下拉刷新或继续上滑 |
| 当前模块切换 | rail 选中态同步 swiper | 现有 `activeIndex` / `curSwiper` | 点击或横向滑动；实现不改 |
| 深色主题 | 同层级、同布局，以现有主题变量切换表面、文字、边框、主色 | `themeClass` 与 `--so-*` token | 沿用系统当前主题偏好 |

## 视觉方案

- 背景改为干净的中性浅底，不再显示强网格、动态光斑或浓重渐变。
- 主体延续主题面板的标题 + 说明 + 列表，不改信息顺序；标题略收敛，留白和行高更均匀。
- rail 不设竖线。未选项使用弱化文字，当前项用浅绿圆角底和品牌色文字标识。
- 模块导航和底栏可用项目已安装的 uni-icons 补充识别；图标只作视觉提示，不增添入口或操作。
- 主题列表仍用行式而非多层卡片；分隔线只留在条目之间，颜色更淡。置顶只用小型浅底标签。
- 顶部入口与底栏使用轻边框、轻表面和小阴影；不使用大面积玻璃模糊。右上原生胶囊保持系统控件空间。
- 底栏继续显示当前模块和该模块现有主按钮，使用安全区偏移；不改变按钮触发逻辑。
- 色彩和明暗表面以现有语义主题变量为准，允许为首页局部使用低饱和强调色，不新增全局主题。

## 改动面与复用

- `src/pages/index/index.vue`：只允许调整呈现模板与 `PANELS` 中的展示图标元数据；保留所有事件和 script 业务行为。
- `src/styles/06-pages/_p-index.scss`：首页背景、顶部入口、rail、内容容器、底栏样式。
- `src/components/business/biz-topic-panel.vue`：仅调整主题面板局部 CSS；复用当前 `useTopicList`、`rows`、空/错/加载 UI 与交互。
- 不修改接口、契约、store、composable、请求、路由、模块顺序、模块懒加载或模块组件分派。

## 验收标准

1. 微信小程序首页整体符合所选 Figma 方向：克制浅底、弱分栏、柔和绿色、右上胶囊安全区完整。
2. 五个模块名称、顺序、点击切换、swiper 手势切换和主按钮对应关系保持不变。
3. 主题标题、置顶、更新时间和描述仍使用现有真实数据字段；列表点击、长按、刷新、分页保持原结果。
4. 主题加载、空态、错误/重试和加载更多状态仍存在且不会与空列表混淆。
5. 不改 API/接口数据/功能行为，并保持浅色与深色主题适配。
6. `npm run type-check`、`npm run build:mp-weixin`、`git diff --check` 通过；能启动微信小程序预览时，检查首页布局、系统胶囊间距、底栏安全区及主题切换。

## 实施与验证

1. 只调整首页 shell 和主题面板样式；代码对照依据为 `src/pages/index/index.vue`、`src/styles/06-pages/_p-index.scss`、`src/components/business/biz-topic-panel.vue` 与 `src/styles/01-settings/_variables.scss`。
2. 先跑类型检查与微信小程序构建，再尝试目标端预览；记录实际可执行的预览结果。
3. 与 Figma 的布局和视觉层次比较，保持功能状态分支完全沿用现状。
