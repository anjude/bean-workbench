# 261108 Superone 首页 UI 改版

## 目标

把已选定的首页视觉方向落到 `uni-superone`，让用户在微信小程序里预览一版更克制、清爽的首页，同时保留现有页面结构、功能和后端接口。

## 范围

- 主仓：`business-repo/uni-superone`，默认 `release` 分支。
- 首页外壳：顶部系统/签到入口、微信原生胶囊安全区、左侧模块 rail、主题列表区域、底部当前模块主操作栏。
- 模块导航和底栏使用项目已有 uni-icons 图标；只增加图标展示元数据，不新增模块或动作。
- 首页当前主题面板的标题、列表行、时间、置顶标签及分隔线样式。
- 视觉依据：[Figma 首页稿](https://www.figma.com/design/nbqTVULZ3d3dngQUibuOgp?node-id=3-2)。

## 边界

- 只调整 UI/UX 与样式，不新增、删除或改变任何功能、业务规则、数据或路由。
- 不修改后端、共享契约、API 请求、Store/Composable、模块切换/懒加载/底部按钮调用逻辑；可改首页展示模板与图标映射。
- 保留五个模块及其当前顺序，保留主题列表的数据字段与现有加载、空态、错误、刷新和分页状态。
- 保留浅色/深色主题适配，胶囊位于右上方，不绘制替代控件；左右模块区之间不增加明显竖线。
- 暂不扩展其它模块内部内容布局或详情页样式。

## 当前状态

进行中。用户反馈第二轮仍不如原版；第三轮已收紧左侧导航和底栏尺寸，类型检查与小程序构建通过，等待开发者工具画面和用户反馈。
