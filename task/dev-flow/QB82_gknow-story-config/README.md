# QB82 鹅懂个啥副本配置化

## 目标

将鹅懂个啥现有副本内容改为后端托管的 JSON 配置，让后续新增或改写剧本不必修改并重新发布小程序；后端只管理记录、权限、发布状态和版本流程，不解析 JSON 内部字段。

## 范围

- `business-repo/backend-superone`：副本配置记录、查询与管理接口。
- `business-repo/frontend-contracts` 及 `business-repo/uni-gknow/src/contracts`：接口契约。
- `business-repo/uni-gknow`：副本 JSON 类型/解析、目录和播放器配置加载、现有副本内容迁移。
- 方案与阶段记录：本任务 `plans/`、`process/`。

## 边界

- 不建设可视化内容编辑后台；配置由小程序项目 `docs/content/` 中的 JSON 文件维护，通过管理员接口保存、预览和发布。
- 后端只把副本 JSON 当作不透明字符串存取，不定义、解析或校验内部字段，不因内容 schema 变化而改后端。
- 不改写副本内容本身的剧情判断；本任务迁移现有内容并保持播放行为。
- 不与可配置测试共用后端内容模型或业务校验。复用通用鉴权、管理权限、发布和版本控制经验。

## 当前状态

首版代码已实现，test 库已建表并导入 8 篇未发布草稿；本地真实服务接口与数据库验证、三仓构建检查通过。后端尚未部署，微信端预览和实际交互待验收；前端已清理本地故事注册及写死的副本标识。详情见 [开发过程](process/03-开发与迭代.md)。
