## 结论

图片按实际功能分组制定尺寸，不将所有素材压成同一个规格。按小程序 `750rpx` 设计宽度、常见 `375px` 逻辑屏宽和最高 3 倍屏幕像素密度估算：卡片的 120×130rpx 显示框约为 60×65 个逻辑像素，源图约 180×195px 已覆盖 3 倍屏；现有 288px 卡片图可以缩小，没必要继续按 2–3 倍逻辑尺寸机械保留到 360px。

| 资源用途 | 建议源图尺寸 | 画面比例与留白 | 目标体积 | 说明 |
| --- | --- | --- | --- | --- |
| 界面图标、玩法标志 | SVG 优先；位图 96×96 或 128×128 | 1:1，视觉主体居中 | SVG 尽量 <20KB；PNG <20KB | 用在工具入口、小游戏标识；图形简单时不保留 PNG/SVG 两套 |
| 鹅头像、表情 | 头像 96×96；表情保持 256×256 透明 PNG | 1:1，统一角色大小与安全边距 | 头像 <15KB；表情 <80KB | 头像在界面最大约 100rpx；表情最大约 190rpx，当前 256px 对高密度屏仍合适 |
| 项目/玩法卡片插画 | 统一画布 180×195 透明 PNG，SVG `viewBox` 对应 12:13 | 对应卡片最大 120×130rpx；主体占画布约 78%–86%，留白一致 | 单张 <80KB | 同一文件供首页与更小目录卡复用；先统一画布与视觉重心，不只拉伸文件尺寸 |
| 页面头图、角色主视觉 | 依据最大实际显示框 × 设备像素密度；常见长边 450–600px，超过 800px 需有清晰度理由 | 按组件比例；同一类页面统一画布比例和角色占比 | 单张 <250KB | 透明角色插画优先 PNG/WebP；大面积纯色或线稿优先 SVG；高于显示需求的图片才下采样 |
| 测评场景/结果插画 | 页面 SVG 保持矢量；Canvas 位图按 Canvas 实际绘制尺寸 ×2 导出，通常 480–540px 长边 | 插画主体与上下留白一致 | 单张 <100KB | 不再一律导出 640×560；Canvas 输出为 2 倍时，源图做到对应绘制宽高的 2 倍即可 |
| 微信分享卡/Canvas 海报底图 | 500×400（5:4）或由 Canvas 完整绘制 | 固定分享构图安全区 | 单张 <150KB | 与页面卡片图分开；不要为了统一尺寸拿 1:1 卡片图替代分享构图 |
| 封面照片/真实场景 | 按页面裁切比例，建议长边 800px | 在组件内明确 `aspectFill`/裁切焦点 | 按清晰度压缩，优先 <200KB | 与透明插画分开管理 |

尺寸均指源文件像素，不是 rpx 展示尺寸。建议统一用「最大显示逻辑像素 × 设备最高目标像素密度（按 3 倍）」，而不是把 rpx 数字直接乘 2–3。若页面使用 Canvas 并将成品导出为 2 倍，再按 Canvas 绘制尺寸计算位图输入；矢量图保留 SVG，不做无意义的位图放大。体积建议是优化目标，不应以压缩造成肉眼可见的边缘或细节损失。

### 主包仍大的原因与优化路径

1. **页面样式由 `App.vue` 全量引入。** `src/styles/index.scss` 把全部 16 页的 `06-pages/*.scss` 聚合进全局；编译结果所有页面 wxss 基本为 0，`app.wxss` 达 111KB。临时试把转盘页面样式改由页面引用后，`app.wxss` 从 111,338 降至 104,883 bytes，同时 `pages/tools/wheel/index.wxss` 产出 6,456 bytes，证明独立样式能随页面移出主包。下一步可将每页样式迁入对应 Vue 页面，通用 reset、layout 和跨页面组件样式留全局；总体 CSS 不会因此减少，但首包会变小。
2. **静态资源仍集中在 `src/static`。** 分包编译仍将其约 309KB 复制进主包。主页/图鉴卡片和共用鹅表情应留主包；鹅会读心/点灯主视觉、鹅方块音效、理财测评结果/分享图、转盘页图标可迁到各自分包 `static/`，同步改引用。鹅眼看我封面仅测评页使用，也可迁入测评分包。
3. **功能数据和逻辑位于分包根目录之外。** 试构建时 `decisionWheel.js`（27.7KB）、`useDecisionWheel.js`（5.6KB）、`useTacitBattle.js`（10.2KB）、理财题库与评估逻辑仍留主包。将仅由一个分包使用的模块移入 `src/pages/{tools,game,quiz}` 对应根目录，可继续减主包；认证、用户状态、通用页面容器、HTTP/WebSocket 传输与被多个包使用的表情组件应留主包。鹅镜题库被 App 的离线任务同步间接使用，需先拆开同步必需的轻量元数据与题目内容，不能机械搬走。
4. **运行时依赖是必要公共底座。** `common/vendor.js` 约 71KB，主要承载 Vue/uni-app 运行时；未发现可安全删掉的大型第三方库。理财 Canvas 图片、分享图、音效已试压，继续压缩收益有限；不建议再降画质。

### 建议顺序与限制

优先按 3 个功能分包组织页面；随后把页面 SCSS 从全局入口迁到页面级，并迁移只属于该分包的静态图和数据逻辑。拆分后主包可明显低于当前构建目录文件总量，但总包总体积大致不变；若目标是减少全量下载字节，需继续清理不再需要的功能或代码。迁移涉及 16 页样式和动态资源路径，实施后需要逐页检查路由、图鉴返回、分享落点和目标端样式加载；这轮只做临时构建验证，业务仓分包配置和源码均未改。
