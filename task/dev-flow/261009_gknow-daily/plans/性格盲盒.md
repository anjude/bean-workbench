## 1. 模块定位与命名

性格盲盒是探索页的大众性格测试栏目。用户通过具体生活情境里的选择，认识自己在社交、金钱、亲密关系等方面的行为模式。核心价值是得到一份有辨识度、能解释自己、愿意分享的性格画像。

模块名：**性格盲盒**。Slogan：**测测你的隐藏性格**。

“盲盒”表示结果随作答揭晓；同样的有效答案与版本得到同样的结果，不随机抽取人格。专业感来自内容区分、解释依据、视觉秩序和完整体验。幽默来自生活观察与性格矛盾，不把每道题写成段子。

用户给出的参考图仅用于理解信息层级、角色表现力、画像具体程度与视觉完成度；不采用其vibe coding题材、类型名称、人物设定、维度缩写、段落、口号或插画。设计原创面向大众的画像与资产，也不照搬其低多边形美术形式。

### 名称与主题规划

| 主题 | 名称建议 | 内容承诺 | 上线安排 |
| --- | --- | --- | --- |
| 原鹅BTI | **隐藏性格** | 从生活中的选择，看看不容易被别人看见的一面 | 首期接入；目录说明为“消息、聚会和日常小事里，你通常怎么反应？” |
| 已有理财测试 | **理财人格** | 观察面对机会、涨跌、他人意见和计划时的反应 | 首期接入，保留经验分流 |
| 恋爱主题 | **你的恋爱脑等级有多高** | 看关系里的投入、边界和自主判断 | 后续题稿独立评审 |
| 动物主题 | **你是哪种小动物人格** | 用动物形象表达生活与相处方式 | 后续题稿独立评审 |
| 年度主题 | **你的2027年度关键词** | 从当下关注和选择提炼下一年的行动主题 | 后续题稿独立评审 |

原建议“你的社交隐藏面”限定过窄：旧六题还有空闲安排、睡前等日常题。本版建议直接用“隐藏性格”，题库升级后也能覆盖更广的生活场景。目录首期只展示两个可用测试，不放大量“即将上线”空卡。

年度关键词可保留用户提出的幸运主题作为后续创作方向，结果以期待与行动主题表达，不写未来事件必然发生。每个主题独立设计内容和分类，不把同一组答案换名字重复出结果。

## 2. 用户流程与信息架构

探索页原鹅BTI、理财人格两张卡合为一张“性格盲盒”，与人生副本、恋爱副本、鹅眼看我并列。进入后选择测试。

`探索 → 性格盲盒目录 → 测试介绍 → 分流（仅需要的测试） → 场景作答 → 结果画像 → 分享/海报/其他测试`

### 目录

复用人生副本的目录组织方式和现有卡片组件。顶部展示模块名与slogan，下面两张卡展示各测试名称、具体描述、标识、真实题量。首期隐藏性格六题；理财人格13个问题，包含经验分流。耗时待实际体验后填写。

### 介绍

首屏明确测什么、题数、如何回答、开始按钮。不堆术语和多屏说明。作答提示建议：“按你通常会做的选，不用选看起来更好的。”

首期在开始处说明“选中后进入下一题，本轮支持回看修改”。不把不可回退包装为更科学的测量方法。新手理财继续说明接下来是假设场景。

## 3. 沉浸式测试组件与导航策略

### 布局

```text
┌────────────────────────────┐
│ 退出       隐藏性格     3/6 │
├────────────────────────────┤
│ 周五傍晚 · 群聊             │
│                            │
│     文字 / 聊天 / 图片       │
│       / 模拟行情             │
│                            │
│    场景区独立滚动           │
├────────────────────────────┤
│ 这里展示当前问题            │
│ A 选项                     │
│ B 选项                     │
│ C 选项                     │
│ D 选项（按实际题目数量）     │
│           跳过（按配置）    │
└────────────────────────────┘
```

顶部导航固定，上方是可滚动的现场，下方固定问题和选项。使用页面剩余高度分配，处理微信胶囊、顶部导航与底部安全区。长选项自然换行；矮屏时限制选项区最大高度并允许内部滚动，上方仍保留可读区域，不缩小字号强塞内容。

聊天采用自有消息界面，表现群聊/私聊的角色、左右气泡、时间和系统提示，不伪装成实际微信聊天。正文默认可直接阅读；如逐段展示，提供“显示全部”，不让用户一直等待。选项在场景展示结束或主动展开后可提交。

### 导航按测试配置

| 配置 | 用途 | 隐藏性格首期 | 理财人格首期 |
| --- | --- | --- | --- |
| `allowPrevious` | 是否提供上一题与修改已答题 | true | true |
| `advanceMode` | 选中后自动前进，或手动确认下一题 | auto | auto |
| `allowSkip` | 是否允许跳过题目 | false，保留旧规则 | true，保留旧规则 |
| `revealMode` | 完整展示或逐段展示场景 | 适配聊天与文字 | 适配文字与行情 |

组件按测试配置展示导航。首期两套测试选中后自动前进，均支持上一题和改答；理财跳过后可回看补选，从第一道场景可返回经验分流，重新选择路线时清空旧路线答案。

选中后立即高亮并记录，约250毫秒后前进，期间锁定重复点击；最后一题自动出结果。首期无每题评分/人格点评，也不增加无实际计算需要的“正在分析”假等待页。

退出按钮与“上一题”明确区分：退出可离开本次测试，不退回上一道题。方案建议保留本机续答：退出提供“继续答题/保存并退出”，再次进入可继续或重新开始。切后台暂停计时，恢复时继续当前状态，不能悄悄跳过多题。

### 其他MBTI是否允许回退

有允许的实例。Myers-Briggs官方亚洲网站发布的《MBTI Complete Assessment User Guide》第6页（PDF页索引5）明确允许用BACK修改前面页面答案；这是一份2023场次的使用指南，不能据此断言所有当前版本和所有平台规则相同。

来源：[官方使用指南](https://asia.themyersbriggs.com/wp-content/uploads/FAQ-for-students-MBTI-Complete-Assessment-RVHS.pdf)。

结论：回退与否是具体产品的交互选择，不能用来证明专业性或准确性。首期按用户最新意见提供回看修改，选中后仍自动前进。

## 4. 结果页：读完能说出自己是什么样的人

结果页采用统一骨架、各主题独立内容。阅读顺序为身份、解释、特点、代价、行动和分享。避免堆叠十几段泛化形容词。

| 层级 | 内容 | 设计要求 |
| --- | --- | --- |
| 主题标识 | 性格盲盒 · 隐藏性格/理财人格 | 保持栏目与当前测试的关系清楚 |
| 人格主视觉 | 与结果对应的原创角色/场景插画 | 用姿态、动作和道具体现行为，不能所有类型换色复用同一姿势 |
| 人格名称 | 简洁、具体、有认领感的名字 | 不强制以“鹅”结尾，不套职业身份，不发明英文四字母代码 |
| 一句话画像 | 最有辨识度的判断 | 表达这个人的行为方式或内在矛盾 |
| 核心画像 | 约100—160字 | 描述触发场景、通常动作与可能动机；适合完整结果页阅读 |
| 特征摘要 | 2—3项由当前算法确实支持的特征 | 有依据才显示；无依据不补满版式 |
| 优势与代价 | 各一段具体解释 | 不只夸，也不羞辱用户 |
| 一个建议 | 一项可以尝试的小动作 | 与该画像的代价对应 |
| 人格签名 | 一句代表性表达 | 由行为风格提炼，不复述原答案 |
| 操作 | 生成海报、邀请朋友测试、其他测试、重新测试 | 不把保存和分享图标混淆 |

### 大众内容表达示例（待评审，非题库定稿）

隐藏性格的结果可以像“有主见的协调者”：

> 你会先让大家把话说完，再把分歧整理成几个能选的方案。你看起来很好商量，但遇到真正看重的事，并不会一直退让。你擅长让事情继续往前走，也容易在没人接手时，替大家多负责一步。

人格签名示例：“我可以配合，但不是没有想法。”

这类内容面向普通人的相处与行动方式，不引用技术圈、AI、代码等特定人群语境。示例只能在题目与答案确实支持对应解释后成为正式结果。

理财人格重点解释钱与注意力如何分配、什么时候采取行动、什么信息会改变决定，不把结果写成收益能力或投资建议。恋爱主题重点解释关系中的行为，不根据一次问卷断言依恋诊断或关系成败。

### 维度与分数

展示层支持“文字特征”“有依据的倾向条”两种形式，不要求所有主题都画雷达或四条轴。

现有理财评分是七类反应支持度，不能直接当四条独立性格轴，也不能归一化成“人格纯度”。旧隐藏性格六题四型同样没有现成的多轴量表。首期用算法已有的类型、解释和可追溯特征完成报告感，不添加百分比或稀有人群排名。

新内容若需要维度，先定义两端、题目覆盖、计分和边界；支持展示后再配置倾向条。用户不需要在结果页看原答案或内部评分表。

回答不足显示暂不分类；理财双型、分散型、全跳过分别沿用已有含义。并列结果展示两种特点与相互关系，不能拼出一段互相否定的画像。全跳过不生成虚构人格或图鉴成绩。

## 5. 分享海报：一张有完整表达的性格名片

海报是独立排版产物，与结果页共用结构化内容，不截长结果页。目标是先看见身份，再读懂一项有辨识度的特点，愿意保存和转发。

### 海报阅读顺序

1. 小字号栏目与主题标识。
2. 原创人格主视觉，约占上部四分之一，给标题让出空间。
3. 人格名称与一句话画像，是整张图的视觉中心。
4. 最多3个有内容的特征标签。
5. 约70—100字画像摘要，保留具体动作和矛盾。
6. 可选特征展示：有真实依据才出现，无则折叠整块。
7. 人格签名，建立记忆点。
8. 品牌、小程序码、“扫码测测你的隐藏性格”或当前主题的准确提示。

默认竖版，建议逻辑画布750宽，完整结果通常控制在约1200—1500高；最终按实际文字测量高度。先测量再绘制，插画、标签和二维码区域都设安全间距。长标题换行，正文不通过无限缩小字号解决溢出；超过可读长度就编写专用摘要。

图像失败有可识别的文字/图形替代；二维码失败时保留结果页并支持重试，不把缺码图当成功的分享海报。生成、图片预览、原生分享菜单和保存均沿用现有平台适配。

默认不展示用户头像、昵称和原答案。二维码直达对应测试介绍，不暴露他人的完整结果；分享标题可带类型名，结果正文不进入URL。双型使用专门并列版式，避免标题、两张插画和正文硬挤在单型模板中。

## 6. 统一视觉系统

整体方向：有质感的性格画像册。暖白/浅纸色底、深色主文字、清晰标题和克制的卡片层次。模块标识可以有开盒意象，主要页面不堆礼盒、彩带、抽奖音效。

同一系列共享构图、字重、圆角、留白与插画笔触。隐藏性格可用青绿，理财用蓝绿/墨蓝，恋爱用低饱和珊瑚色，动物用自然色，年度主题用琥珀色；颜色用于区分主题，不能暗示人格高低。

插画建议使用轮廓清楚、有动作细节的编辑插画。既有理财资产可在迁移版复用，先评估清晰度与风格差异，后续按确认的美术方向统一。新图使用本地自有资产，按项目尺寸与体积规范导出，维护同系列源图；不下载参考图中的猫头鹰再改色。

阿白在栏目品牌、必要的观察与少量注释中出现，不要求每个人格都变成一只鹅。幽默靠画像里真实的行为矛盾，不加通用抒情、夸张稀缺性和空泛人设口号。

## 7. 题库与内容生产规则

每套测试先确定结果差异，再列观察情境和题目，保证结果能由多道题共同支持。内容文档至少包括目标、维度/类型定义、题目与选项、权重、覆盖关系、有效回答要求、平局/不足规则、画像、摘要、签名与视觉说明。

题目写具体生活取舍，各选项都有可理解的理由与代价。不要把“自私冲动”与“成熟理性”对立，也不要让最幽默、最长的选项永远对应一个类型。场景可独立，不强制串成一部长剧。

结果先写具体行为，再解释可能动机，最后写优势和代价。不从一条选择推导创伤、潜意识或整个人的本质；不制造准确率、纯度和人群百分位。专业调性需要可追溯解释，视觉本身不能证明测量有效。

### 迁移与内容升级的边界

首期接入已有两套测试：旧隐藏性格六题四型与理财经验分流保持可运行，理财原题、评分和已确认结果语义保留。展示名、结果组织与海报升级不自动授权重写题库和判型。

隐藏性格旧结果中的“随便都行鹅”等命名与短文偏趣味，已与新方向存在差距。正式内容升级先评审3道代表题、2份完整结果、对应海报摘要及插画方向，再决定全套题量与类型，不先批量生成再让用户删。新画像不得表达旧题无法支持的结论。

如果首期就要以全新调性公开呈现隐藏性格，内容样稿评审与完整稿确认是发布前条件；组件接入完成仅代表技术完成。两项工作可以并行准备，但不能用旧六题直接宣称完成深层人格识别。

## 8. 系统与组件设计

首期仅涉及 `business-repo/uni-gknow`。无新增数据库表、字段、迁移DML、后端接口或共享契约；复用现有登录、门禁、图鉴、二维码和分享调用。

### 职责分层

| 层 | 职责 |
| --- | --- |
| 目录配置 | 测试ID、展示名、介绍、路径、封面、题量和可用状态 |
| 页面与各测试控制器 | 当前题、分流、答案、评分、结果和图鉴写入 |
| `ImmersiveAssessmentPlayer` | 场景区、固定选项区、进度、导航策略、选中反馈和动作事件 |
| `AssessmentSceneRenderer` | 渲染文字、聊天、图片、模拟行情内容块 |
| 各测试评分器 | 纯逻辑计算，消费答案快照，输出主题结果 |
| 结果报告组件 | 主视觉、画像、可选特征、优势代价、签名与操作区 |
| 海报模型与绘制器 | 测量、排版、绘制；复用现有图片加载、码图和分享生命周期 |

副本播放器当前互动选项仍在正文区，底部固定的是继续按钮；只参考其节奏和几何，不把故事分支、结局与测评分数混入同一状态机。

### 内容块和会话模型

`AssessmentSceneBlock`使用带type的联合类型，首期 `text / chat / image / market`；一道题可组合多个块。chat含角色ID、显示名、左右位置、消息/时间/系统提示；market覆盖当前理财报价、比较与图表，并标明模拟行情。

题目含 `id / blocks / prompt / options`，选项含稳定 `id / text`。权重留在数据和评分器，不交给展示层。后续按真实需求增加邮件、账单或时间线类型，不提前建远程插件平台。

控制器传入题目、进度、选中状态、展示状态和导航策略，组件发出 `choose / skip / previous / next / revealAll / exit`。首期控制器拒绝不允许的previous/next事件，即使错误触发也不能改变答案。自动切题只有一处定时器与一个状态来源，不叠加旧展示计时器。

会话状态为 `intro → route（可选）→ presenting → answering → advancing → result`，补退出与错误状态。以题目ID和会话ID约束异步回调，旧题动画与计时器不能修改新题。

### 结果与海报数据

各主题结果经适配器输出统一报告字段：`testId / contentVersion / scoringVersion / kind / title / headline / portrait / strengths / tradeoff / suggestion / signature / illustration / tags / features? / posterSummary`。

`features`可缺省，每项必须有评分来源与展示方式；模板不得因字段缺失补随机值。理财保留single/mixed/scattered/empty等真实结果类型，混合结果传入两个画像摘要，不先压成一段单型文本。

报告与海报用同一份结果快照；纯展示文案调整与评分变更分别记录版本。海报缓存键覆盖主题、路线、版本、结果内容及码图落点，防止重测后复用旧图。

### 存储与兼容

建议本机草稿记录测试ID、题库/规则版本、路线、新手标记、会话ID、当前题ID、已答选项ID、更新时间和提交阶段；暂定7天有效。存储失败允许当次继续，提示进度未保存。过期或版本不符时说明原因并重新开始，不按位置猜测旧题答案。

## 11. 实施顺序、风险与回滚

1. 确认本版模块结构、展示名、答题策略与结果调性。
2. 内容与视觉先做小样：隐藏性格3题、2份完整画像、各自海报摘要和原创插画方向，检验区分度与整体调性。
3. 目录与通用答题组件接入旧两套数据，保持计分不变，完成所有理财场景迁移。
4. 接入结果报告和海报新模板；画像按已确认内容提供，不能凭版式补新结论。
5. 按用户认可的小样完成新隐藏性格题库与全套结果，单独记录题库/评分版本后切换。
6. 类型检查、微信编译及目标端验收，再按用户授权提交/发布。

真实风险包括旧题支撑不了新画像、理财展示迁移漏分支、固定答题区挤压场景、定时器重叠、草稿版本混用、共享海报组件影响其他玩法。内容先评审，计分独立回归，海报用独立模板与绘制器分别控制。

回滚按目录、答题组件接入、报告模板分别恢复到原调用，稳定ID、旧路由与原数据保留可恢复；不批量改写图鉴历史。此次未提交、推送或部署。
