# Demo 首页头部精简

## 需求

缩小 Demo 首页头部占用，让用户更快看到趣味测试和小游戏入口。

## 原型与结构

- 首页是体验入口 dashboard。头部提供品牌识别与一句简短主张，卡片区负责主要 CTA。
- 头部改为横向组合：小尺寸阿白头像 + 品牌短标 + 单行主标题 + 简短内容说明。
- 原来纵向的大头像、两行大标题和长介绍合并收敛；设置入口仍留在顶部导航栏。
- 无接口或数据状态变化；加载/失败继续由 `gk-page` 处理。

## 文件范围

- `business-repo/uni-gknow/src/pages/index/index.vue`：只调整 Demo hero 信息结构。
- `business-repo/uni-gknow/src/styles/06-pages/_home.scss`：收紧 hero 高度、字号、头像与间距。

## 验收

- 头部以紧凑横向方式呈现，品牌、主张和体验类型仍清楚。
- 主要趣味测试/小游戏入口、分享按钮、设置入口及门禁行为不变。
- `npm run type-check`、`npm run build:mp-weixin` 通过；页面实际视觉由微信开发者工具验收。
