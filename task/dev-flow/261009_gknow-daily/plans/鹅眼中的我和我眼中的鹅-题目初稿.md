## 题目规则

自评与他评保持相同题号、选项ID和语义，只替换提问视角。每题单选，不分好坏，不映射人格类型。朋友版额外提供“这个真没见过”，不计入一致或不同；自评允许“这题先跳过”。只有双方都选了实质选项才形成对照。

前两题观察相处行为，第三题切入解读；第四、五题回到具体行为，第六题以熟悉关系中的误会收尾。题序固定，选项顺序一致。

## 01 群里又问“周末去哪儿”

- 自评：聊了二十分钟还没定下来，你通常是哪个角色？
- 朋友：聊了二十分钟还没定下来，你觉得TA通常是哪个角色？

| ID | 选项 |
| --- | --- |
| a | 先开一条路：“这家怎么样？”发个地方让大家有得聊。 |
| b | 帮大家收个尾：“那就这两家，选一个吧。” |
| c | 跟着靠谱的人走：“你们定，时间地点发我。” |
| d | 另开一条支线：地方还没定，已经聊到谁上次喝多了。 |

## 02 朋友说“今天上班气死我了”

- 自评：你接下来最可能回什么？
- 朋友：你这样跟TA说，TA最可能回什么？

| ID | 选项 |
| --- | --- |
| a | “怎么了？展开讲讲。” |
| b | “这事能解决吗？我帮你想想。” |

| d | “等会儿，我也有个离谱的。” |

## 03 聚会散场，你突然安静了

- 自评：热闹了一晚上，回家路上不太说话了，你更可能在干什么？
- 朋友：热闹了一晚上，TA回家路上突然安静了，你第一反应觉得TA在干什么？

| ID | 选项 |
| --- | --- |
| a | 今晚挺开心，正在脑内回放。 |
| b | 社交电量用完，先静音一会儿。 |
| c | 想起刚才一句话，琢磨是不是说得不太合适。 |
| d | 没那么多剧情，就是困了。 |

## 05 刷到一个朋友可能会喜欢的东西

- 自评：一家店、一首歌或者一个离谱视频，你更常怎么分享？
- 朋友：一家店、一首歌或者一个离谱视频，TA更常怎么分享给你？

| ID | 选项 |
| --- | --- |
| a | 链接直接甩过去：“这不就是你！” |
| b | 先收藏，下次聊到再翻出来。 |
| c | 带上具体安排：“周六一起去？” |
| d | 一条接一条，等对方上线时已经凑够一屏。 |

## 06 朋友说：“我刚认识你时，以为你挺难接近的”

- 自评：听到这句话，你更可能接哪句？
- 朋友：你对TA说这句话，TA更可能接哪句？

| ID | 选项 |
| --- | --- |
| a | “我那会儿是不知道跟你聊什么。” |
| b | “是吗？我还觉得自己挺热情的。” |
| c | “你现在知道我话有多密了吧。” |
| d | “你也没好到哪去，我当时也不敢找你。” |

## 揭晓方式（候选）

标题：原来，你是这样看我的。

- 先呈现“有X题，你们想到一起了”，补充“双方都作答的Y题中”。Y为0时改为“这次还没有能对上的题，一起聊聊也行”。
- 不用默契分、匹配度或关系评级，也不强行生成六题总人格。
- 逐题展示“我选的 / 朋友选的”；朋友页面换成“TA选的 / 我选的”。对应不熟悉或跳过状态如实显示。
- 相同选择只说“这题想到一起了”；不同选择说“这题，你们看到的不太一样”，不把自评或他评当作真相。
- 一致和不同都可成为分享内容，由用户主动选择；海报不默认公开完整答卷。

第三题示例：自评d、朋友c时，可以展示“你说自己只是困了，朋友以为你还在琢磨刚才说过的话。”只描述这次选项差异，不推导深层人格。

结尾邀请：“哪一题最出乎意料？发给对方聊聊。”
