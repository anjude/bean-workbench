## 2026-10-14 第三款小游戏「鹅来点灯」

### 素材检索与玩法决策

- 在 `source/README.md` 指引的原始库中检索三套重复包，发现 `400多套h5微信朋友圈小游戏源码/games/diandeng/` 的「最强电灯泡」。参考原规则：4×4 灯阵，点击一个格子会切换该格及上下左右相邻格，目标把所有灯点亮，记录步数与用时。
- 对比已有鹅会读心（记忆魔术）和鹅的烟雾弹（限时辨色），点灯是可独立成立的空间逻辑玩法，操作和挑战维度不同；采用为第三款小游戏，改名「鹅来点灯」，将灯光事故包装为鹅的现场任务。
- 原始 H5 的外链、排行榜、广告、分享注入和图像不接入。只保留规则，页面用 Vue 状态逻辑与项目 CSS 重新制作。
- 盘面从全亮目标局面出发，随机执行合法点击生成初始盘，保证每局都有解；用户点击后同步切换十字范围。目标全亮，统计步数与本机最少步数；不设倒计时，强调想法和重玩。

### 原型与状态

- 原型：沉浸式单局逻辑小游戏。介绍只解释一次点击会影响十字范围；进入盘面后视觉中心为灯阵和步数；完成态展示步数、历史最佳及再开一局。
- 状态：介绍 → 进行中 → 完成 → 重玩；随机初盘必须可解；点击中的邻格越界忽略；完成时锁住盘面；本地最佳读取或写入失败均不妨碍游玩；游戏页面隐藏 / 返回时无计时器或后台任务需要恢复。
- 今日挑战：项目目录注册 `dailyChallenge`，完成时只收录挑战完成记录，不将「步数越少越好」错误记成正向分数。

### 改动范围

- 工作台方案及来源副本：本节、`source-reference/diandeng-index.html`、`source-reference/diandeng-game.js`。
- `business-repo/uni-gknow/src/data/projectCatalog.ts` 增加正式目录项和今日挑战文案；新增 `src/composables/useGooseLightsOut.ts`、`src/pages/game/goose-lights-out/index.vue`、`src/styles/06-pages/_goose-lights-out.scss`；更新 `src/pages.json`、`src/styles/index.scss`。首页依照目录自动展示第三款紧凑卡，今日挑战按目录候选自动轮换。
- 无后端、数据库、契约或网络接口变更；不新增图片依赖。

### 验收

- 检查所有初盘均由全亮状态经合法操作生成、点击仅翻转自身及四邻、全亮后完成态锁定、步数和最佳步数持久化、重玩刷新盘面；小程序构建产物包含页面路由。

## 2026-10-14 鹅表情接入与「鹅来点灯」双关升级

### 目标与边界

- 按场景复用现有八种鹅表情，为反馈、情绪和空状态增加角色表达；避免纯装饰性重复露出。
- 「鹅来点灯」改为连续两关：第一关直观易懂，让用户学会十字翻灯；第二关提高空间推理难度，并以「你来也过不了第二关」的梗作为挑战气氛，不使用无解盘、强制计时或侮辱性失败反馈。
- 为点灯游戏生成一张项目内主视觉，替换当前几何符号占位。复用已有表情作为通关/提示反馈；位图只新增一张，不做重复表情套图。

### 玩法与页面状态

- 关卡一用全亮棋盘经过一次角落点击生成，盘面只需一次有效操作即可复原；完成后明确提示「第一关通过」，再进入第二关。
- 关卡二仍从全亮目标经合法点击生成，保证有解；挑选并固定一个最少解步数明显高于第一关的盘面，不随机产生手感差异过大的难度。无需限时，允许反复尝试。
- 进度、关卡步数和总步数清晰区分；第二关完成后进入最终结算，重玩从第一关开始。本地最佳纪录改为双关总步数语义；旧单关纪录不迁移，避免口径误导。
- 状态：介绍 → 第一关进行中 → 第一关通过/切关 → 第二关进行中 → 双关完成 → 重玩；离开后无后台计时任务。今日挑战仍在双关全部完成后记入图鉴。

### 表情接入原则与落点

- 点灯开场/第一关通过/第二关挑战/最终结算分别选用适合情绪的表情与短反馈；避免同一屏角色重复、挤压灯阵或遮挡操作。
- 鹅会读心结果用偷笑/得意表情承接魔术揭晓；鹅的烟雾弹开场与答题反馈用得意/无语/开心等状态替代重复头像；趣味测试结果按语义使用表情；首页不额外堆贴纸，继续保留现有欢迎视觉与项目卡。
- 鹅图鉴记录继续按挑战项目与结果状态映射表情，空状态保留疑惑表情。

### 改动范围与验收

- 前端仓：`src/pages/game/goose-lights-out/index.vue`、`src/composables/useGooseLightsOut.ts`、`src/styles/06-pages/_goose-lights-out.scss`；按需更新读心、烟雾弹、测试结果或共用状态区域。新增 `src/static/illustrations/goose-lights-stage.png` 与资源说明。无后端、接口或契约改动。
- 表情只按需导入；图片规格匹配开场局部展示区，透明 PNG 长边约 600–800px，压缩后控制体积并核对透明边缘。
- 验收：第一关最少一次操作即可解决；第二关使用固定有解盘且最少解步数显著更多；关卡推进、步数、最终最佳纪录、重玩和每日挑战仅在完整通关后记卡正确；表情不抢主操作且图片正确打包；类型检查、小程序构建与 diff 检查通过。
- 体验风险：第二关虽有最少步数基线，主观难度仍需微信端试玩；若难到挫败，优先调整盘面而不削弱规则。
