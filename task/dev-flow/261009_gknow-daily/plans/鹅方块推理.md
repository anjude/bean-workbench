# 鹅方块推理 · 玩法方案

## 需求与范围

以彩色分区棋盘为基础，用排除标记和推理找到所有鹅。玩家双击格子找鹅：成功锁定 🪿，失败扣一条命并锁定 ❌；两种结果均不可修改或撤回。单击标记或取消普通 ❌，滑动可连续标记普通格子。每个颜色区域、每行和每列各一只鹅，任意两只鹅不能接触，包括斜角。通过 Tour 分步教会操作和规则。

## 界面与引导

- 原型：单关卡逻辑推理游戏，棋盘是视觉和操作中心；主操作是标记和放鹅。
- 首次引导按操作顺序展示：双击放鹅 → 颜色区域一只鹅 → 相邻八格不能有鹅，单击/滑动标记 ❌ → 行列各一只鹅 → 颜色锁定行列 → 行列锁定颜色。使用小棋盘和目标高亮，用户实际完成操作练习后继续；允许重新查看或关闭引导。
- 关卡内展示棋盘、已放鹅数量和必要的引导入口；完成后给出过关反馈。
- 单击与双击必须消歧：短暂等待第二次点击，双击只产生找鹅动作。滑动以第一个格子的状态决定本次操作：起点为 ❌ 时清除沿途普通标记，否则沿途统一标记 ❌；同一格重复经过不重复切换。锁定的鹅和失败格不响应修改，普通标记可以撤回。触摸中断、误触及离开页面应清理手势状态。

### 动画与音效

- 双击放鹅：格子轻微弹起，鹅出现时做短暂缩放；正确放置播放轻快提示音。
- 放错并扣命：格子轻晃、生命值变化，配短促音效；无需额外错误弹窗。
- 标记 ❌：标记轻微显现；滑动连续标记时控制音效频率，避免密集播放。
- 过关与失败：分别使用简短的成功/失败动效和音效，不遮挡结果与下一步操作。
- 游戏页提供音效开关并在本地记住偏好；音效加载或播放失败时游戏仍可正常操作。动画和音效使用自制素材，优先使用代码动画与短音频，控制小程序包体积。
- 拟用 uni-app 页面动画与微信小程序音频能力实现，控制资源大小并在目标端验证触摸、播放与退出清理。

## 状态与验收

| 状态 | 表现与操作 |
| --- | --- |
| 首次进入 | Tour 引导操作与三条规则，进入关卡 |
| 进行中 | 点击切换普通 ❌，滑动连续标记；双击找鹅，棋盘与数量同步 |
| 错误找鹅 | 扣一条命并将该格锁定为 ❌，不额外弹出提示；两条命耗尽后本关失败，可重试 |
| 成功找鹅 | 该格锁定为 🪿，不允许修改或撤回 |
| 提示 | 每关一次，揭示一只当前可推导的鹅并展示推理过程；如暂时没有可靠推导则不消耗次数 |
| 撤回 | 仅撤回普通标记等非致命操作；成功/失败找鹅均锁定，不返还生命 |
| 完成 | 所有鹅满足规则时展示过关反馈 |
| 退出或中断 | 清理手势状态；只保存解锁关数，不保存当前棋盘 |

验收覆盖单击/双击消歧、连续滑动、重复经过同一格、颜色/行列/八邻域约束、唯一解及无需猜测的推导、两条命及失败重试、每关一次提示、撤回、关数保存、Tour 各步骤及窄屏触控；运行 `npm run type-check` 和 `npm run build:mp-weixin`，再用微信开发者工具确认实际手势。

## 待确认

无。

### 提示策略

从已确认的鹅和找错后锁定的格子出发，按同行、同列、同色、相邻及行列与颜色区域交集规则逐步排除；发现只剩一个候选时揭示该鹅，并在弹窗中逐条解释排除原因和位置。普通 ❌ 可能由玩家误标，不作为确定事实。推导过程不读取标准答案；仅在展示前校验其与标准答案一致，找不到可靠推导时不消耗提示。

此前第五关设计了多个符合规则的候选并要求试探；用户要求智力游戏能靠推理通关，现已撤销多解设计。Tour 只讲操作和规则。

### 规则教学方向

- 玩家不需要靠试错找鹅；在已知规则之外，用小棋盘演示可复用的排除方法，不直接揭露当前关答案。
- 基础关系：颜色数量等于鹅数，行列数量相同且不能重复，所以每行每列恰好一只鹅。
- 颜色锁定行列：某颜色所有可能位置都在同一行或同一列时，那一行/列的鹅必属于该颜色，因此同一行/列的其他颜色格子可排除。
- 行列锁定颜色：某行或某列剩余候选都属于同一种颜色时，该颜色的鹅已被限制在这行/列，因此该颜色在其他行/列的格子可排除。
- 已确定的鹅可以排除同行、同列、同色及周围八格；上述步骤可反复组合，直到某行、某列或某个颜色区域只剩一个候选。
- 用户确认保留生命值和提示按钮，给尚不熟悉规则的玩家缓冲；规则引导负责教会玩家自行推理。
- 已在 Tour 增加两幅局部棋盘示例，分别说明“同色候选锁定一列”和“某行候选锁定同色”；行列规则同时解释鹅数与行列数相同。六步引导保持固定面板尺寸，可随时关闭或重新查看。
