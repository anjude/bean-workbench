## 1. 本轮已确认与本稿提案

用户已认可：投资理财小现场、真实即时反应、类似鹅BTI的题感、选择动态联动，以及参考鹅湾夜航的全屏卡通、背景、打字机。独立现场之间可接同一笔投资的后续，不写强行贯穿的冒险故事。

本稿落实用户同意继续设计的体量：36 道候选内容，单轮 12 道主题加 0—3 道追问，12 种主要结果与基于原答案的反差句。具体题文、12 种命名、分类门槛和选题次序仍是本轮可评审提案，不等于用户已逐条认可或授权开发。

这是原创趣味画像规则；不输出投资适宜性、能力、收益预测、财务健康等级、超过多少人或科学准确率。本轮不继承旧四轴，也不以当前写作规则宣称测量效度。

- S01—S12 按表顺序出现，六类现场各两次。单轮每个题位只取一题，主题不会因为某种人格分数高而被挤掉。
- 首次审稿/默认演示固定 Q01—Q12；候选题通过内容审阅后，再按 sessionSeed 为每题位选择版本，入场即冻结，重渲染不重抽。题目版本与具体题号必须保存。
- 每种线索在一轮主题选项中恰好出现 4 次；Q13—Q24 与对应默认题保持同样映射。这是曝光机会平衡，不是题目已统计等价。
- 选项按稳定 optionId 记录；可按 seed 轮换展示位置，字母只是显示，不作为计分键。动画跳过、打字速度、停留时间、背景点击均不计分。
- 不根据实时倾向迎合出题，不随机更换题设涨幅、资金用途、时间跨度或结果后继续沿用同一版本。

### 追问的名额与时机

三条追问线各占一个名额，不递归长出新题：

| 前置题位 | 选择 A | 选择 B | 选择 C | 选择 D | 追问出现位置 |
| --- | --- | --- | --- | --- | --- |
| S01 | B01 | B02 | B03 | B04 | S04 后 |
| S02 | B05 | B06 | B07 | B08 | S08 后 |
| S03 | B09 | B10 | B11 | B12 | S12 后、出结果前 |

12 道主题加三道追问的完整路线为：S01→S02→S03→S04→追问1→S05→S06→S07→S08→追问2→S09→S10→S11→S12→追问3→结果。

首三题的答案选定后确定追问题号；隔开若干独立场景再回访，允许人物想法变化。跳过前置题位时对应追问取消，不找无事实依据的题硬补。追问本身也可跳过，因此一轮为 12—15 个题位；换题会额外显示候选文本，但同题位最多记录一个有效答案，跳过也占本题位。

进度显示“主场景 4/12”，追问显示“回来看看 · 刚才那笔”，另显示已发生的回访数，不伪造总题数。中间不弹“再加一题测得更准”，追问是预定结构。

## 3. 联动究竟联动什么

### 事实、文案、画面与旁证

1. **事实联动**：记录已卖、是否买回、是否仅查看、原仓是否还在、是否只买一半、是否仍待研究。没有买回，不能出现“买回来第二天”；只是问代码，不能画成已持仓。
2. **文案联动**：追问开头可用原答案的短引用，例如“刚才你给另一半留了个位置”，引用只来自真实选项。
3. **画面联动**：买一半就画已买与未买两区；移除关注后不再显示主动关注卡，朋友截图是新的外部消息。Q13 关闭提醒和 Q01 删自选不能混称。
4. **结果联动**：本轮回扣与反差句引用路径，既可以“继续如此”，也可以“后来改变了主意”。不要求前后一致，不把转向扣为不认真。

没有跨题统一钱包，不因先前花钱而隐藏后续选项。独立题明确是新的假设，不将它们接成同一个账户的真实交易流水。Q12/Q24 尤其标明“另一份月结账单”，只有用户前面事实完全匹配才可以改成“回看刚才”。

后续涨跌是该追问题的虚构背景，出结果时不拿它验证谁操作正确，也不计算玩家输赢。所有动态分支都保留完整选项，不用分支只提供同一种倾向的答案。

### 答案记录最小结构

```text
assessmentVersion、sessionSeed
slotId、itemId、optionId、answerKind（选择/都不像/跳过）
primarySignal（只给主题）、evidenceId（只给追问）
parentItemId、parentOptionId（追问必填）
scenarioFacts、displayedVariant、promptExposure
```

事实用稳定字段，不从中文文本猜：exitDone、reentered、peerPositionBought、originalPositionKept、plannedBuyState、uninvestedPart、attentionAction、peerRole。题位内创建各自上下文，不共享一个会被别的假设覆写的 position。

逐题确认即锁定该答案；本期不提供答后回退改选。如未来增加改选，必须撤销该题及所有后代追问和事实后重新出题，不能只改一票留住旧剧情。重玩清空本轮全部答案与衍生结果。

## 4. 十二种理财人格

这是十二种在题目中可观察的行为主线，每个都有可晒的一句、承接的一面与具体边界。名称均为提案；结果页写“这一轮，你更像……”，不声称永远如此。

| 码 | 名称 | 海报一句 | 接住玩家的一面 | 与相邻结果的区别 |
| --- | --- | --- | --- | --- |
| R | 投资考据鹅 | 一句“听说”，到我这儿要查一下原文。 | 愿意把依据弄清楚，也能接受有些问题暂时没有答案。 | 查事实与原判断，不等同于一直收候选，也不代表查得对 |
| W | 自选区房东 | 关注了三十只，每只都比持仓住得久。 | 愿意保留可能性；真正下手前，常想再比较一下。 | 关注的是增加候选，不是反复刷新已持仓 |
| P | 按表营业鹅 | 行情每天更新，我按自己的日历上班。 | 借事先安排减少临时纠结，变化时也可以重新定计划。 | 依靠日程与流程，不单靠“拿很久” |
| A | 长期住户鹅 | 买入像签长租，日常涨跌只是楼下动静。 | 愿意给原来的想法时间，不急着把每一天结算成答案。 | 时间视角长，不等于亏了只等回本 |
| V | 账户巡逻员 | 没准备操作，就是再来看看。 | 想随时知道发生了什么；看得勤也可能动得少。 | 关注频率，不把它直接解释为交易频率高 |
| F | 上车补票鹅 | 先让我在场，详细攻略一会儿再补。 | 机会出现时愿意行动，也容易被“已经开始了”牵动。 | 由热度和错过感触发入场，不等于所有主动买入 |
| G | 卖后观察员 | 仓位清了，后续还在追。 | 对没走的那条路很有记性，会反复回看“如果当时”。 | 少赚与错过的反事实，不等于单纯查看持仓 |
| B | 回本下班鹅 | 不是舍不得走，是想从进来的门出去。 | 成本线像一个交代，让结束这件事更好接受。 | 退出锚在买入价，不等于长线或全部亏损厌恶 |
| T | 见好收工鹅 | 账面说赚了，我想先收一部分。 | 希望把结果落到手里，也愿意减少一笔仓位对自己的牵动。 | 选择收回/减少持仓，不以必须回本为前提 |
| H | 半仓调解员 | 想买和不想买的自己，各分到一半。 | 给不同想法各留位置，通过拆分把决定往前推。 | 分步骤/折中，不把任意分两份叫科学分散 |
| C | 现金候场鹅 | 钱先在我这儿，暂时不急着给它找工作。 | 能容许暂时不入场，为下一步保留余地。 | 明确选择暂留资金，不把没钱或不懂题算进来 |
| D | 消息接线鹅 | 下单之前，先问一句“你怎么看”。 | 愿意借别人的视角找线索，再决定接下来怎么做。 | 人际信息接力，不等于跟买、不研究或缺主见 |

这里保留了没有强笑点、但真实存在的长期/流程风格。不能为了十二个都像段子，把每个人都写成追涨、后悔、瞎忙。

## 5. 分类规则：能解释，允许混合

### 主结果只用十二道主题

每个有效主题选择只给表中一条线索加 1。记录 mainCount、opportunityCount、supportingSlots 和 supportingTopics。完整一轮每个 opportunityCount 为 4，主结果没有追问加分。

进入“主要人格候选”需同时满足：

1. mainCount 至少 3；
2. 来自至少两个主题；
3. 四次机会都已有效作答（opportunityCount = 4）。

这些是首版产品阈值，不是置信区间或经过验证的人格界线。

- 只有一个候选最高：展示该人格主卡。比如 R=3、其他均更少且 R 来自不同主题。
- 两个及以上候选同为最高：展示“混合款”并列名字，不按固定优先级、最后一题或随机数硬选一个。同为 3 的最多四种；界面最多展示两张主卡，其余同分列在“同样出现的倾向”，不宣称前两种更强。
- 同分展示顺序按首次支持题位，仅为排版；文案明确并列，不以此决定谁是主型。
- 无人达到阈值：展示“本轮混合款”，引用票数最高的至多两个行为及对应场景，说明“这轮选择比较分散”；其余倾向可展开。不得通过追问把某人补到三票来硬凑十二型。
- 主题缺答：只使用完整覆盖四次机会的线索参与主型，缺答带来的少票不等于反向倾向。若没有足够候选，则展示场景摘要；大量缺答或没有有效答案时不生成某种人格。
- 票数不得转成“人格占比 75%”“比 90% 的人理性”等显示。四次选三次只是原始证据，不是概率。

十二个名称均可由不同主题的三个支持项到达；四票也可达。展示不保证所有用户都落在单一十二型，混合款是正常结果。

### 为什么追问不和主题混着加票

追问由先前答案触发，某种行动会使某种线索更容易再次出现。直接累加，会把分支曝光优势误当成稳定人格。因此追问用于回扣、情境变化和主卡“这次还有一面”，不改变主结果票数，也不作为同分胜负依据。

追问可记录同行为继续或转向，但不写“前后矛盾”“测出隐藏人格”。R→D 可能只是新问题想听听别人；P→C 可能是日期到了仍改主意，这都应按实际行为表述。

## 6. 回扣、反差与结果页

### 结果页的顺序

1. 本轮主型或混合款名字，一句海报文案。
2. 两到三条来自真实选择的短依据，显示场景标题与原答案摘录。先用跨主题的支持项，不只挑同一种情境。
3. 一条路径回扣或反差。没有满足条件就省略，不用空泛段子补位。
4. “也有这一面”：最高的另一条主线索，至少两次且来自不同主题才显示；否则用一条追问的具体转向，清楚标明只有这一次。
5. 重玩、可选分享；结果页可展开全部已答题。分享不作为查看完整结果的门槛。

玩家只选过“再看看”时，不写“每天看八遍”“从不操作”等虚构频率。名称里的夸张海报句与下方证据分开，证据必须忠实。

### 可执行的回扣规则

按下表从上往下选第一条满足的；同优先级优先跨时间的父子链。最多一条反差，避免把结果变成长篇吐槽。引号内文字为草稿。

| 条件 | 回扣草稿 |
| --- | --- |
| S01=A，且 B01=D | “先算少赚了多少，后来买回一点，给‘如果当时’按了暂停。” |
| S01=D，且 B04=B | “自选或提醒已经清了，朋友一张截图，又把那笔计算带回来。”（按原动作选词） |
| S03=A，且 B09=D | “日期等到了，喜欢的价格没回来。最后，你还是把钱留住了。” |
| S03=B，且 B10=C | “先买一半，后来把另一半继续留着。两边的位置，你都想保留。” |
| S02=C，且 B07=B | “先跟着买，后来开始自己找依据。入场和研究，你这次用了这个顺序。” |
| S02=B，且 B06=C | “先比较了两边的收益，后来仍按自己的打算拿着。” |

以上 Sxx=字母仅为阅读简写；实现按稳定 optionId 匹配，候选题通过题位语义映射继承，不按显示位置。

不满足任何一条时，选一条真实追问回扣：“在‘另一半还在等’里，你最后选择了……”；未答追问则引用一条主题，完全无须生成反差。

### 三条走通的例子

- **巡逻但不急着动**：S02-B、S04-A、S09-A、S10-D，共 V 四票，跨别人赚钱与持有期间。主卡账户巡逻员；如果 B06-C 成立，补充“比较过，仍按自己的打算拿着”。不把频繁看账户等同于频繁交易。
- **查过，也听别人**：S01-B、S03-C、S07-A、S08-B，共 R 四票。追问 B11-D 是听别人经验，主卡仍为投资考据鹅，补一句研究之后也会问人，不增加 D 主票。
- **明显的双主线**：S03-A、S04-D、S11-A 给 P 三票；S01-A、S05-C、S12-A 给 G 三票。主卡并列按表营业鹅/卖后观察员，依据说明“买入依赖计划，卖后仍会回看错过”，不强行二选一。

## 7. 全屏卡通与节奏

美术沿用已确认的简线条、平面色块二维卡通；参考鹅湾夜航的舞台感，场景改为投资日常：沙发/床头、午休桌面、通勤地铁、电脑笔记、日历、晚间桌灯。允许同一背景换光线和前景物件复用，不为每题画一整张新图。

- 全屏背景负责时间地点，手机卡、消息、图表、账单是可读前景，题文与数字用真实文字组件，不烧进图片。
- 每题最多三段现场提示，然后出现问题与选项；点击打字区可一次显示全文。完成文字后所有选项同时出现，不让先出现的选项占优势。
- 读屏、静音和减少动态模式能完整获得同样信息；点击完成打字不得穿透成答案选择。
- 选后只演出实际动作，再出现一条阿白观察；下一题可立即点，不被动画强制等待。删关注/关提醒、购买/仅看等有独立表现。
- 追问进入时展示原场景缩略卡与真实选择短摘录，半屏以内就能想起，不播不可跳的回忆动画。
- 场景切换用短淡入或横切，不写鹅带你去码头买船票等世界观过场。
- 正式结果不装作正在联网分析大数据，可用一次卡片翻面，随后直接展示实际答案依据。

## 8. 状态与边界

| 状态 | 行为 |
| --- | --- |
| 初次进入 | 开场说明虚构闲钱、按反应选择，开始后冻结本轮题目与 seed |
| 打字中 | 轻点补全；补全文字的触摸不算选项点击 |
| 题目可答 | 全部条件与选项可见，“都不像/换一题”可用 |
| 都不像/代入不了 | 当前题不加票；同题位最多切换一次候选，候选仍不合适则跳过；只记录最终有效答案，原题曝光有记录 |
| 重复触摸 | 首次确认后锁定，不重复计分、不重复入追问队列 |
| 背景失败 | 纯色背景保留题文与选项，可继续；必要条件不能依赖插画 |
| 内容缺失/前置不匹配 | 不播放错误后续；取消该追问并继续主题，结果不引用未发生的内容 |
| 退出再进 | 本期只保留本次页面内存；明确重新开始，不暗示跨设备记住；如需断点续答另行定稿 |
| 进入后台再回来 | 同一页面实例继续当前题，不重抽、不过秒自动选 |
| 到达结尾 | 仅用本轮有效答案计算；无充分线索正常展示混合或场景摘要 |
| 重玩 | 清空答案、追问、事实、结果与动画；生成新 seed，审稿模式可固定同一套 |
| 分享失败 | 提示重试，结果继续可读；不要求好友互动解锁 |

换题是内容表达的替代尝试，不宣称心理测量等价；题目曝光版本保留，后续研究可单独分析。没有收集真实资金、收入、账户截图或交易权限；虚构答案当前不上传。
