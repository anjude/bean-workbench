## 2026-10-13 首款正式小游戏：鹅会读心（已确认开发）

### 目标与边界

- 用户已确定素材库的消失卡牌魔术为首款正式小游戏；用户已于 2026-10-13 确认开发，按「鹅会读心」及下述流程实现。
- 原型：按原素材保留逐屏推进的魔术表演：首页开场、六张牌默记、凝视读心兽 1 / 2 / 3 秒、五张牌揭晓、再玩一次。用鹅的品牌角色和页面动效重新表达，不把多段流程压成一个卡片页。正式首页在测试与工具之间加入「小游戏」分区及唯一首发卡片，旧鹅眼快手继续属于 demo。
- 纯前端：无新增数据库、接口、共享契约或服务端记录；仍使用现有启动与正式入口门禁。
- 来源：`source/local-source/h5-game-library/400多套h5微信朋友圈小游戏源码/games/duxinshu/` 的 `index.html`、`images/3.jpg`、`images/7.jpg`、`images/poker1.jpg`、`images/poker2.jpg`。原件只读；仅参考玩法，使用原生 Vue 与 CSS 重做牌面和页面，不搬运旧站脚本与外链。

### 流程与状态

| 状态 | 内容与主动作 | 边界 / 回退 |
| --- | --- | --- |
| 开场 | 介绍鹅要借走一张牌，提示上滑开始 | 上滑手势推进，结果页除外 |
| 记牌 | 展示六张牌，提示默记点数与花色，不点选 | 本轮牌组固定；上滑进入凝视 |
| 凝视 | 依次展示读心兽的 1 秒、2 秒、3 秒铺垫，每屏上滑继续 | 不自动跳过，不限制玩家停留；保留原素材逐步加压的节奏 |
| 揭晓 | 整组替换为五张牌，留出空位并提示「你记住的那张，是不是不见了？」 | 上滑进入收尾 |
| 收尾 / 再玩 | 用鹅的口吻收住魔术，点击「再来一次」回到开场 | 两组牌的花色与点数组合无交集；候选内部无重复，保持六变五 |
| 菜单转发 | 小程序卡片落到游戏入口，接收方从开场开始 | 沿用此前正文按钮收敛决定，不新增邀请按钮或海报 |
| 加载 / 失败 / 无正式权限 | 沿用 gk-page 的等待、重试与入口门禁 | 不绕过现有权限；玩法本身无网络加载或空数据 |

- 魔术机制采用原素材的两组近似牌面整体替换；先确认组内唯一、前后无交集，再进行排列随机化。点数和花色清楚可读，玩家无需点击自己记住的牌。交互保留原素材的上滑逐屏推进和 1 / 2 / 3 秒凝视铺垫。
- 品牌与资产：游戏表演页不重复铺鹅头像或 Logo；用橙金牌背、聚光眼睛、逐幕强调文字与扑克牌 CSS 动效建立自己的舞台感，台词承接鹅的角色。牌面保持白底及红黑花色；窄屏固定三列，两行展示。
