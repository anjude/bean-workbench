### 流程与状态

| 状态 | 内容与主动作 | 边界 / 回退 |
| --- | --- | --- |
| 开场 | 介绍鹅要借走一张牌，提示上滑开始 | 上滑手势推进，结果页除外 |
| 记牌 | 展示六张牌，提示默记点数与花色，不点选 | 本轮牌组固定；上滑进入凝视 |
| 凝视 | 依次展示读心兽的 1 秒、2 秒、3 秒铺垫，每屏上滑继续 | 不自动跳过，不限制玩家停留；保留原素材逐步加压的节奏 |
| 揭晓 | 整组替换为五张牌，留出空位并提示「你记住的那张，是不是不见了？」 | 上滑进入收尾 |
| 收尾 / 再玩 | 用鹅的口吻收住魔术，点击「再来一次」回到开场 | 两组牌的花色与点数组合无交集；候选内部无重复，保持六变五 |
| 菜单转发 | 小程序卡片落到游戏入口，接收方从开场开始 | 沿用此前正文按钮收敛决定，不新增邀请按钮或海报 |
| 加载 / 失败 / 无正式权限 | 沿用 gk-page 的等待、重试与入口门禁 | 不绕过现有权限；玩法本身无网络加载或空数据 |

- 魔术机制采用原素材的两组近似牌面整体替换；先确认组内唯一、前后无交集，再进行排列随机化。点数和花色清楚可读，玩家无需点击自己记住的牌。交互保留原素材的上滑逐屏推进和 1 / 2 / 3 秒凝视铺垫。
- 品牌与资产：游戏表演页不重复铺鹅头像或 Logo；用橙金牌背、聚光眼睛、逐幕强调文字与扑克牌 CSS 动效建立自己的舞台感，台词承接鹅的角色。牌面保持白底及红黑花色；窄屏固定三列，两行展示。

## 2026-10-31 原版表演节奏回归与魔术玩法储备

### 需求理解与原版对照

- 用户反馈「鹅会读心」作为魔术游戏，沉浸体验未达预期；确认参考原版后，目标是恢复原版七幕表演语言，继续使用阿白角色与当前牌组机制。
- 原版 `source/local-source/h5-game-library/400多套h5微信朋友圈小游戏源码/games/duxinshu/index.html` 共七屏：挑战式开场、默记牌、1/2/3 秒凝视三屏、五牌揭晓、谢幕。逐屏手动上滑；三段秒数是观众观看指令，不是自动计时。竖向翻页采用 rotate 页面转场，且不允许回翻；开场提示在页面出现约 3 秒后浮现。
- 当前实现保留七阶段与手动上滑，但额外显示阶段号和进度条，凝视连续使用抽象眼睛与同一版式，揭晓添加了原版没有的空牌占位。改版保留逐幕结构，恢复画面独立性、角色逐步施压、翻页感与无显式空位的揭晓。

### 本轮方案与验收

- 原型：沉浸式 detail，一次呈现一幕；阶段状态仍为开场、记牌、凝视一/二/三、揭晓、谢幕。
- 主动作：除结果页外继续通过上滑前进；结果页以「回到首页」为主按钮、「再来一场」为次按钮。进度条、幕数和品牌栏移除。
- 视觉：深色剧场框架，各幕使用不同色温和聚光焦点；开场按导航胶囊高度再留 28px 间距，插画不使用负上边距；三段凝视使用阿白不同神情的本地资产，表演对白以每字 36ms 快速显现，并在凝视时提示玩家默念所选牌、逐步强化阿白正在读心的表演；记牌与揭晓保留 3×2 牌阵，揭晓只显示五张牌，不标注缺失位置；通过纵向翻页感切换场景。
- 状态：加载与入口权限沿用 `gk-page`；场景按现有本地状态推进；短划不推进；结果可重开并生成新牌组；分享回到开场；今日挑战与图鉴记录不变；返回退出仍可用。
- 文件范围：`business-repo/uni-gknow/src/pages/game/goose-mind/index.vue`、`business-repo/uni-gknow/src/styles/06-pages/_goose-mind.scss`；无路由、牌组、接口、数据或契约变更，不搬运原版图像、脚本、外链。
- 验收：七幕次序和上滑交互不变；无阶段号/进度条；三幕读心角色与配色可辨；揭晓没有显式空位；窄屏和短屏内容完整；分享、返回、每日挑战、图鉴回归。

### 其他魔术技巧候选

- 预测 / 强迫选择：让阿白提前封存预测，用户在有限选项中做选择后揭晓。适合短流程和强结尾；需让选择过程自然，并用真实试验检查是否显得受操控。
- P.A.T.E.O. 淘汰法：用户与阿白轮流从两项中淘汰一项，最后留下预言对象。互动强，但需要控制每轮话术和角色行动，避免重复步骤显得机械。
- 21 张牌定位：用户反复指出目标牌所在列，经过三轮左右定位。数学上稳定，适合“阿白找到你想的牌”；步骤较多，须用表演动机掩盖程序感。
- Fitch Cheney 五牌传讯：观众选五张，助手藏一张并排列四张，表演者据排列推断隐藏牌。效果强、解释空间大，但单人手机场景缺少助手，可改成用户自己摆牌/选顺序的独立玩法后再评估。
- 位置引导与心理暗示：利用选项位置、措辞、视觉提示影响选择。心理学研究与魔术教材均讨论此类 force；因个体差异，不建议作为当前“鹅会读心”的唯一成功条件。
- 参考：[Goldsmiths 对魔术选择引导与自由意志的研究整理](https://www.gold.ac.uk/news/magicians-mind-control-tricks-/)、[21 张牌魔术推广与推广形式的数学论文](https://arxiv.org/abs/1809.04072)、[Vanishing Inc. 的 P.A.T.E.O. 玩法说明](https://www.vanishingincmagic.com/blog/easy-mentalism-tricks-you-can-do/)、[Cheney/Fitch 多牌传讯技巧的数学论文](https://arxiv.org/abs/2405.21007)。
