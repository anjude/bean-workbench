### 2026-10-17 端上反馈修正：海报内主动提供资料

## 2026-10-17 真机无反馈根因确认

- 用户提供真机原生错误：`chooseAvatar:fail api scope is not declared in the privacy agreement`。这证明微信已收到头像选择请求，但因该小程序后台隐私保护指引未声明对应 scope 而拦截，不能归因于按钮没有图片子元素或普通点击缺失。
- 需要在当前 AppID 对应的小程序后台《用户隐私保护指引》补充 `chooseAvatar` 对应的信息类型及真实用途，再按后台要求生效后重新进入真机验证。前端 `manifest` 添加 scope、重复改按钮或添加输入框不能替代后台声明。
- 当前保持原生头像回调→海报绘制→微信图片分享链路，不因该错误追加权限配置或改交互；尚未验证后台修改后的实际结果。
