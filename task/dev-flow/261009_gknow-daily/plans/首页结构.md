## 2026-10-13 首页长期结构与本期实现（已确认开发）

### 目标与稳定规则

- 首页同时服务直接使用与发现内容：项目卡始终点击直达；查看分类全部内容是可选动作，不强制增加点击。
- 分类顺序固定为趣味测试、小游戏、实用工具；每类首页显示精选项目，并在有第二项时直接展示第二张紧凑卡，保证已有内容可见。同类超过两项时，精选卡显示「另有 N 款」进入完整分类列表。推荐更新不改变分类顺序。
- 推荐是项目卡上的可选标记，当前「鹅会读心」标记「新上线」；不轮播、不新增重复推荐区、不按随机或访问频率调换顺序。上下线时由维护者显式调整标记。
- 目录只登记正式项目；demo 不混入正式分类。大转盘是一个工具，吃 / 逛 / 玩仍是工具内主题，不拆成三个工具。
- 当前尽量一屏呈现，文字可换行、小屏允许滚动；不锁定整页高度或缩小字号。分类列表随内容增长自然滚动。

### 长期演进条件

| 能力 | 启用时机 | 行为约束 |
| --- | --- | --- |
| 分类全部列表 | 本期提供；同类多于一项才显示首页入口 | 同一份项目目录，列表顺序显式维护，项目点一下直达 |
| 固定 / 最近使用 | 有多个回访工具或首页之外的项目，并出现反复查找需求时 | 最多一排三项；固定优先且顺序不自动变，其余用去重的最近成功打开记录补齐；空记录不展示，失效项目剔除，允许取消固定和清空最近 |
| 搜索 / 分类筛选 | 用户用列表仍难找到项目时，由使用反馈决定 | 先在分类页提供，不占首页；处理无结果、清空条件与回退 |
| 服务端目录 / 个性化 | 本地目录维护或明确推荐需求使其有实际价值时 | 加载 / 缓存 / 失败回退需独立设计；不能改变用户固定位置 |

固定、最近与搜索本期只确定规则，不写空界面或数据采集逻辑。先稳定当前三项目首页及新增项目的接入方式，再按真实需求展开。

- `src/pages/index/index.vue`、`src/styles/06-pages/_home.scss`：以目录生成稳定三类首页，清理原硬编码卡片。

### 原型与状态矩阵

| 场景 | 展示 / 操作 / 回退 |
| --- | --- |
| 每类一项 | 紧凑卡片直达；不显示全部入口 |
| 同类多项 | 指定精选项目留在首页，全部入口带实际数量；分类列表展示所有正式项目 |
| 分类暂时无项 | 首页不显示该类占位卡，其余顺序不变；分类直达显示空态及回首页 |
| 非法 / 缺失分类参数 | 明确空态与回首页动作，分享回首页，不错误落到其他分类 |
| 门禁加载 / 失败 / 非正式权限 | 继续由 gk-page 处理，不在分类页绕过门禁 |
| 项目跳转失败 | toast 提示重试，停留原位置 |
| 菜单分享 | 首页仍落首页；分类页落当前有效分类，接收方受同一门禁 |
| 长文案 / 窄屏 / 深浅主题 | 文本换行，卡片自然增高，按钮不挤压标题，沿用主题变量 |

### 验证与验收

- 类型检查、小程序构建、diff 检查；目录唯一 ID、路径注册与资产存在检查。
- 用独立测试样例覆盖同类新增项目、空分类、精选回退和固定分类顺序；不把虚构项目写入产品目录。
- 微信验收：首页三项直达；模拟新增同类项目时全部按钮只打开列表，列表项直达；未知分类、分享、设置与 demo 跳转回归。
- 体验信息来源：鹅BTI 六个现场、魔术六张牌、转盘三种主题；不编造使用时长或热度。
- 回滚：撤回目录与共用页面，恢复上一版首页；无存量数据迁移。沿用现有静态图片和 CSS 卡牌，不引入新视觉依赖。


### 长期首页本期落地与新增项目方法

- 已完成统一项目目录、首页自动分组、共用项目卡、分类全部页及导航失败反馈；三类各一项时保持直达，鹅会读心显示新上线标记。未实现长期规划中的固定 / 最近、搜索和个性化。
- 新增正式项目：先实现页面并注册 `pages.json`，再在 `src/data/projectCatalog.ts` 增加唯一 ID、分类、名称、说明、真实体验信息、路径及本地视觉；列表按数组顺序。首页每类由 `featured: true` 指定一项，换精选时先移除旧项标记；没有指定时以同类首项回退。
- 用户体验反馈：首页项目卡缺少清楚的类别区分。现采用分类货架：分组标题左对齐，多项目类别右侧显示「全部 N 款 ›」；多项目类别使用横向滑动卡片轨道，单项目类别保留宽卡片直达。小游戏的所有项目都在同一个货架里，不将分类级入口放在某款游戏卡内部或卡组尾部。该模式按目录项目数自动适配；`badge` 由维护者显式更新 / 删除，不自动改变分类和列表顺序。
- `npm run type-check`、`npm run build:mp-weixin`、`git diff --check` 通过。目录专项检查覆盖唯一 ID、页面注册、图片存在、分类顺序、多项数量、精选选择与回退、空分类和非法参数；构建检查确认全部按钮使用 catchtap，分类页已进入 app.json。
- 微信内卡片视觉、全部按钮与列表交互、主题及一屏效果待用户体验；未提交或推送。
