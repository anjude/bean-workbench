# 鹅眼看我 · 填写记录海报

- 2026-10-30：用户要求填写记录可以生成海报分享。在发起人打开某位朋友的一份对照记录后提供生成入口，海报对应当前记录。
- 内容：玩法名、朋友昵称、匹配题数、全部题目与双方答案、各题对照状态及小程序码。朋友填写后的页面仍只显示匹配题数，沿用既有规则。
- 复用 `gk-result-poster` 和小程序码服务，码进入玩法首页；缓存键包含答卷身份、完成时间、题目版本，避免不同记录串图。无新后端接口、Redis 写入或公开发布。
- 生成中防重复、失败可重试、原生图片分享由组件处理；本机生成与模拟绘制检查、type-check、微信构建，真机分享菜单和扫码由微信端验收。

## 实施记录

- 结果详情已接入共享海报组件，小程序码使用不含用户标识或邀请 key 的玩法入口。不同记录按答卷身份、完成时间、题库版本区分缓存。
- 旧版只展示摘要的海报已被下述长图替代。
