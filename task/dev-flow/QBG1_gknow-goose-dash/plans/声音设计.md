# 大鹅快划背景音设计

## 方向

不播放背景音乐，只在关键事件发生时播放短促、轻柔的音效。音效用柔和的水滴声提示部署、轻木质碰撞声提示两队接触、简短双音提示鹅成功冲线扣分；不额外铺底，不连发轰炸。

采用原创程序合成音色，不使用外部录音；MP3 使用 64 kbps 单声道有损压缩以控制资源体积。部署音效跟随成功部署事件，碰撞音效对新接触做限频，得分音效仅在分数下降时播放。音效开关保留本机偏好。

## 背景音

- 背景音乐关闭；事件发生时播放一次短音效。
- 进入后台或关闭音效时停止当前音效。
- 玩家可单独开关背景音；偏好保存在本机，并遵循手机系统静音开关。

## 验收

1. 部署、两队接触、鹅冲线扣分时各自触发对应短音效；无背景音乐。
2. 音效音量轻，不影响听清对局；频繁接触不会造成音效连发。
3. 开关即时生效，偏好重进页面后保持。
4. 结算后停止；页面隐藏后暂停，返回前台不叠播。
