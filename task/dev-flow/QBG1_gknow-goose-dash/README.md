# QBG1 鹅懂个啥「大鹅快划」

## 目标

在「鹅懂个啥」微信小程序新增双人对战小游戏，当前名称建议为「大鹅快划」。沿用《顶你个牛》的多赛道队伍合力与漏防扣分逻辑，双方将大鹅投入五条水赛道；鹅群整体对抗，鹅冲过对方基线后扣分。

## 范围

- `business-repo/uni-gknow` 新增游戏页面，并接入小游戏目录与「双人小游戏」分组。
- 沿用现有双人在线游戏的好友邀请及通用实时房间能力，具体对局同步方式以方案确认结果为准。
- 设计原创鹅角色、文案、页面与数值；只复用玩法机制，不复制原作素材或代码。

## 当前状态

当前只维护 Three.js 3D 页面；旧 2D 页面、路由、样式和专用素材已删除。目录入口及分享路径统一指向 `game3d/pages/goose-dash/index`，入口名称统一为「大鹅快划」。
