## 管理员专用品牌内容海报与贴图生产工具（方案待确认）

### 背景与需求理解

- 目标是给「鹅懂个啥」官方运营者提供内部内容生产工具：管理员输入虚拟情景、对话文字并提供/选择图片，按品牌视觉生成可发布的内容海报，再使用微信小程序当前可用的图片转贴图能力生成贴图内容，用于贴图号起号；同一内容可导出小红书笔记图片与配文，供官方账号人工发布。
- 这是官方内容生产能力，不向普通用户开放，不做用户截图编辑器、公开投稿、用户内容社区或真实聊天记录仿制器。
- 方向以「虚拟情景演绎」为前提；内容按创作作品呈现，不包装成真实恋爱经历或真实私聊证据。

### 本期目标与边界

#### 本期目标

- 管理员从设置页进入单一内容创作页，填写主题/标题、情境引子、对话内容、角色图片与发布文案。
- 使用「鹅懂个啥」自有色彩、字体层级、角色元素和版式生成海报预览；图片支持从项目品牌素材选择或从本机相册选取。
- 一次创作提供贴图号用图片与小红书用竖版图片两个导出选项；可复制小红书标题/正文/话题，手动发布。
- 贴图导出调用用户已确认可用的微信图片转贴图能力；同时保留保存到相册作为失败或后续人工处理的回退。
- 首版内容在本机编辑和生成，不上传内容、不存用户数据、不增加后端、数据库或共享契约。

#### 本期不做

- 不给普通用户开放创作入口，不允许用户公开投稿或浏览其他用户作品。
- 不调用小红书发布接口、不自动登录或代发笔记；不将小程序码、站外联系方式或诱导话术强行塞入小红书图片/文案。
- 不做聊天截图仿真，不伪造聊天软件 UI、时间戳、头像身份或真实经历。
- 不做云端内容库、多人协作、发布排期、审核后台、数据分析看板和生成式 AI 写文案。
- 首版不承诺自动批量发布或批量生成；以单条内容的快速生产和人工校对为准。

### 产品原型与操作流程

- 原型：单内容的沉浸式编辑页（detail/editor）。管理员围绕一条内容完成编辑、预览、导出，不在同一页叠加内容看板或内容流。
- 入口：现有设置页「管理员工具」增加「内容海报与贴图」入口；非管理员不显示入口，直接访问目标路由时也显示无权限回退并返回设置页。
- 编辑字段：内容标题、情境说明（可选）、对话段落（至少 1 段，首版最多 6 段）、角色/场景图片、品牌署名、贴图号发布短文案、小红书标题/正文/话题。
- 主要 CTA：`生成预览` → `转为贴图`。次要 CTA：`保存贴图图片`、`生成小红书版`、`复制小红书文案`、`重新编辑`。
- 生成前有“虚拟情景演绎”标识预览，可见品牌署名与内容审核提示；不把虚构内容伪装成截图。
- 生成后预览目标版式，管理员确认后再调用微信贴图能力；小红书版本为独立构图，不直接拉伸贴图图像。两种图片尺寸/格式应在开发前按账号实际贴图入口和小红书当前发布要求确认，避免在方案阶段臆定平台规格。

### 状态矩阵

| 场景 | UI 表现 | 数据来源 | 可执行动作 / 回退 |
|---|---|---|---|
| 首次进入 | 空白编辑表单，展示字段提示与一条虚拟内容示例 | 本地默认示例 | 编辑字段、选择图片 |
| 管理员有本地草稿 | 本期不做草稿恢复；每次打开新建内容 | 无持久化 | 重新填写 |
| 非管理员或用户资料未就绪 | 不渲染编辑器，显示权限说明 | `store.isAdmin` | 返回设置页；不提供申请入口 |
| 字段为空或超长 | 对应字段提示，不开始绘制 | 当前表单 | 修正字段后重试 |
| 图片选择中/图片不支持 | 显示处理状态或格式错误 | 微信相册选择器 / 品牌素材 | 重新选择，保留已输入文字 |
| 生成中 | 禁用重复提交，显示生成反馈 | 本地 Canvas | 等待；异常时回到编辑状态 |
| 生成成功 | 显示海报预览与导出操作 | 本地临时图片 | 转为贴图、保存、切换小红书版或继续编辑 |
| 贴图转换失败/接口不可用 | 保留海报预览并说明失败 | 微信能力调用结果 | 重试或保存到相册后人工处理 |
| 保存图片权限拒绝 | 说明相册权限未开通 | 微信授权结果 | 引导用户重试授权；可继续用其他操作 |
| 复制小红书文案 | 成功提示；复制失败保持文本可选 | 编辑表单 | 重试复制或手动选择复制 |

### 内容与品牌规范

- 主题优先选日常沟通、暧昧试探、恋爱相处、朋友群聊等可共鸣场景；表现为鹅角色的虚构对白和轻量观点，不以制造焦虑、羞辱关系对象或诱导评论为目标。
- 海报使用品牌角色、鹅懂个啥品牌名和轻松语气；保留足够留白与可读字号。对话内容是主角，装饰不压过信息。
- 图片由官方自有素材或管理员确认有权使用的素材组成。选择本机图片前提醒不得上传未获授权的真人肖像、私人聊天截图或敏感个人信息。
- 默认注明“虚拟情景演绎 / 创作内容”，不使用伪系统消息、聊天应用仿 UI 或冒充真人账号的头像名称。
- 小红书发布前由管理员人工检查平台内容规则和账号定位；社区公约强调原创与真实，商业规则对未经授权的第三方平台推广有限制，见[小红书社区公约 2.0](https://pgy.xiaohongshu.com/help/detail?id=1eda0a065dd894063c2e029a49e8f6a1&userType=4)与[内容审核规范](https://pgy.xiaohongshu.com/help/detail?id=6495c527d1eedeeb48fb18b1f875650e&userType=4)。是否标注 AI 参与仅在后续接入 AI 生成功能时再按当时规则处理。

### 验收标准

- 仅当前登录用户资料明确标记为管理员时可见并进入生成页；非管理员直接打开路由仍不能使用。
- 管理员能输入字段、选择图片、生成两种版式预览；排版无文字裁切、图像变形或品牌元素遮挡。
- 贴图版可调用已核实的微信贴图能力；调用失败时可重试或保存图片，不丢失本次编辑内容。
- 小红书版可独立保存；标题、正文与话题可复制，复制失败时仍可在界面查看。
- 页面离开、图片选择失败、绘制失败、图片保存权限拒绝等状态均有可理解反馈，且返回编辑不丢字段。
- 不向后端传输编辑文本或所选图片；不新增表、API、契约或普通用户入口。

### 风险与回滚

- 微信贴图 API 名称、入口或账号资格可能随小程序基础库/贴图号状态变化：以目标账号真机实测为准；保留保存图片回退，不因此阻塞其他图片导出。
- 贴图尺寸、格式与小红书发布图尺寸存在差异：分别绘制输出规格，不用缩放复用同一张图；规格在开发前据官方当前要求确认。
- 虚拟对话若被包装成真实经历，可能损害品牌可信度或触发平台审核：界面和输出默认保留创作标识，发布前人工审核。
- 个人肖像、私聊内容或第三方插画有版权/隐私风险：运营素材仅使用自有或获授权素材；首版不提供真实聊天截图导入模板。
- 回滚只需移除设置入口、页面路由和新增页面/绘图模块，不涉及数据迁移。

### 推荐实施顺序

1. 方案确认后，用管理员账号核实微信贴图能力的实际操作与接口签名、贴图号发布步骤、可用图片规格。

4. 由管理员将导出图文人工发布到贴图号和官方小红书账号，记录内容反响后再判断是否扩展模板或内容管理能力。
