# `hr` 工作台命令入口

## 需求与决定

- 工作台 Go 命令由 `bw` 改名为 `hr`。
- 新增 `hr collect bilibili <BV号或视频链接>`，并可选传 `--model`。
- 工作台 CLI 只负责发现并调用 beannote Python 采集器；采集、ASR、队列、存储和归档能力继续由 Python 模块负责。

## 实现

- 更新 Cobra root、版本输出、现有命令示例、Makefile 与业务仓索引中的命令名。
- Makefile 构建时注入工作台根目录，已安装的 `hr` 可从任意当前目录定位 Python 工具；另提供 `BEANNOTE_SOURCE_COLLECTOR_DIR` 路径覆盖。
- Go CLI 调用 `.venv-asr` 或 `.venv` 中的 `beannote-source`。Python `collect` 增加 `--model` 参数，供工作台入口透传。
- 更新 Python 工具 README 和开发任务记录中的使用方式。

## 验证

- `make install` 成功，安装到 `$(go env GOPATH)/bin/hr`。
- `hr --help` 显示 `collect` 子命令；`hr collect bilibili --help` 显示 BV/链接用法和可选 `--model`。
- 本轮未执行真实联网采集，避免重复创建/修改本机采集任务；现有采集链路由 Python CLI 继续处理。

## 限制

- 直接 `go build` 编译的二进制若需要从任意目录定位采集器，应使用 `make build`/`make install` 注入工作台根目录，或设置 `BEANNOTE_SOURCE_COLLECTOR_DIR`。
- 本机安装目录可能仍留有旧 `bw` 二进制；本次没有删除它，避免无意删除兼容入口。当前工作台说明与新安装入口统一使用 `hr`。
