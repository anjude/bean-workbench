# 本地视频与小红书接入 · 过程记录

## 做了什么

- 按用户确认范围扩展采集器：本地视频文件、yt-dlp 支持的公开视频链接、小红书专用下载；统一复用现有 ASR、任务表和来源包：`tools/source-collector/src/workbench_source_collector/`。
- 新增本地视频适配器，支持常见视频扩展名、2 GB 文件/2 小时视频上限、FFmpeg 音轨提取；网页支持本机视频选择上传，CLI 支持 `hr collect file`。
- 新增 yt-dlp 通用公开链接适配器，保留 B 站、YouTube 原专用适配器；未知 HTTP/HTTPS 链接走通用 extractor，并提供 `hr collect video` 命令。
- 新增小红书适配器，使用工作台 `tools/xhs-research/XHS-Downloader/` 子模块下载公开视频，再由 FFmpeg 抽取音轨；提供 `hr collect xhs` 命令，并向子模块传入独立的无 Cookie、无代理配置，避免继承用户已有下载器设置。
- 更新采集器与工作台工具说明：`tools/source-collector/README.md`、`tools/README.md`；回填任务范围：`../README.md`、`../../registry.md`。

## 得到的结论

- 现有任务流程与标准来源包结构可以承接本地、通用链接和小红书，不需新增数据库表；来源包平台标识扩充并保留 schema v1：`tools/source-collector/src/workbench_source_collector/core.py`、`docs/source-package-v1.md`。
- “通用视频”按 yt-dlp 当前 extractor 能访问的公开页面定义；登录、验证码、付费/私密权限、DRM、直播和平台规则变化会阻止采集。平台适配器可按后续实际需求增加：`tools/source-collector/README.md`。
- 网页上传的视频保存在 Git 忽略的本机运行目录，ASR 仍只在本机运行：`tools/source-collector/src/workbench_source_collector/server.py`。
