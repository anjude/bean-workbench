## 得到的结论

- 平台字幕提取与本地 ASR 是两条不同来源，需在导出元数据中保留区别；现成平台字幕也可能是机器字幕，不能全标为作者字幕。
- Chromium 扩展 service worker 不适合承担长时间推理；任务状态持久化，推理由 offscreen + 专用 Worker 执行。真实样本转写期间关闭并重开工作台，任务可继续。
- Whisper Tiny 虽然快，但中文同音字/数字错识别较多；默认改为 Small，Tiny 只供预览，不将任务成功等同于逐字准确。
- MV3/offscreen 不在 Playwright 常规 Page 路由拦截范围内；集成测试通过单独的测试构建替换网络边界，生产构建没有 mock。
- 重用浏览器测试 profile 可能缓存旧扩展代码，导致设置选项沿用旧版本；真实转写验收改用新 profile，并校验每条命令返回成功。

## 被推翻的判断

- 「接口的付费提示就是付费视频」已被实际完整播放和音频接口验证推翻，限制判断改看实际访问字段和音频时长。
- Tiny 足以默认收集中文原始资料的假设被实测识别质量推翻，改为更大模型优先。

## 待核 / 没答上来

- 长音频内存上限取决于设备，首版保护阈值不等于对所有设备的长视频性能保证。
- 真实网络、模型与字幕准确度的最终结果见阶段 03 验证记录。


## 设备策略修正

测试浏览器实际返回 Metal 硬件 GPU，并非已证实的软件模拟 GPU；观察到此量化模型本机 CPU 更快，默认改为 CPU。软件 GPU 排除逻辑保留为自动模式的设备判断，未把它当作本次慢速的已证实原因。依据与完整结果见 `03-验证.md`。
