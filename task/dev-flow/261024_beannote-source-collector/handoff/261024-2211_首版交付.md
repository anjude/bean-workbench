- 默认 Whisper Small + CPU/WASM：Tiny 中文误差较大，本机 Metal GPU 推理比 CPU 慢；保留模型与设备选择。
- 独立采集页 + offscreen/Worker：便于批量操作和后台长任务；完成或暂停后释放推理 Worker，模型文件缓存保留。
- 纯浏览器本地转写：音频和字幕不上传转写服务；首次使用需要下载公开模型权重。
