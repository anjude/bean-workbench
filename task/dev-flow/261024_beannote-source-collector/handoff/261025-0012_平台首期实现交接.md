## 关键决策与原因

- beannote 按内容生产平台建设，但不强制统一工具语言、仓库或进程：模块并行更便于保留现有工作台 Go 工具、bn skills 和 Chrome 插件。
- 原始媒体、SQLite、模型权重仅作本机运行数据：避免内容仓被大文件和易重建状态污染。
- 采集后先待归档，由用户选择主题：避免采集工具替用户做内容判断或自动写入错误主题。
- Tiny 只作链路验证，机器字幕标记需复核；large-v3-turbo 下载未完成，不能宣称默认模型质量已验收。
