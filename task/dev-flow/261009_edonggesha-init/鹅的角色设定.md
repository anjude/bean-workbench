# 「鹅懂个啥」角色设定

## 核心设定

**这只鹅总觉得自己看透了玩家。它会出题、设局、抢着下判断；玩家一旦出乎意料，它比谁都先有反应。它好胜，也认真承认玩家赢下的结果。**

这与产品名形成反差：「鹅懂个啥」既是玩家对它的质疑，也是它每次想证明自己时的起点。角色的戏来自它的判断和真实结果之间的落差，不靠自称“腹黑”、宣告“我要使坏”或无缘无故发疯。

鹅想要玩家继续玩，因为它既想赢回一局，也想看看玩家下一次会怎么做。它不会为了留住玩家贬低成绩、制造内疚或虚构自己掌握的信息。用户随时可以走；鹅的回应应让人愿意回来，而不是觉得被催促。

## 与玩家的关系

- **熟悉的对手，偶尔是同谋。** 玩游戏时它可以放话、设局；玩家突破时它会惊讶、找补，但最后认账。测试中它可以猜错、被结果反驳，不替用户定义人格。工具里它可以抢着拍板，但决定权仍属于用户。
- **锋芒指向局面和它自己的失算。** 可以调侃刚发生的一步或一次选择，不评价用户的智力、外貌、身份、处境或生活态度。输赢有来有回，玩家赢了就是赢了。
- **情绪有因果。** 自信来自它刚布下的局；惊讶来自玩家的具体操作；嘴硬来自刚被拆穿。没有触发事件时，它不需要表演情绪。

## 可识别的行为

| 情境 | 鹅的反应 | 产品表达 |
| --- | --- | --- |
| 开局、规则已说明 | 对自己的安排很有把握，留一点挑战意味 | 一句短话或一个表情；不占用规则的位置 |
| 玩家做出意外选择 | 迅速改口、短暂失去笃定 | 只有确有可观察的选择或结果时才反应 |
| 玩家完成关卡或破纪录 | 先露出不甘，再明确承认成绩 | 成绩和下一步操作先清楚显示；角色反馈只加一次 |
| 玩家失败或停下 | 对局势表示遗憾，给出可继续的路径 | 不补刀、不催促、不用“再不来”式提醒 |
| 分享或传播 | 可放大它的自信与翻车 | 内容必须对应实际玩法和结果，不泄露悬念 |

它的弱点是**过度自信，且很在意玩家是否看穿自己的安排**；它的可爱之处在于翻车后的反应快、嘴上不服却不篡改结果。不要把“喜怒无常”理解为随机换脸：情绪变化必须跟玩家行为连起来。

## 文案与露出规则

产品有两种声音：系统负责规则、按钮、分数、错误和权限，直接说清事实；鹅只在**挑战前、悬念揭晓、意外反转、胜负结算**等有具体触发点的时刻开口。同一屏通常只给它一次表达机会。普通列表、导航、表单、加载和错误状态无需让鹅代言。

鹅开口时用直接的第一人称短句。句子应包含它对眼前事实的判断、误判或态度；不靠“鹅”字、夸张标点和角色标签维持人设。表情与文案表达同一反应即可，不要让插画、标题、说明、按钮各讲一遍。现有表情可按真实情境选用得意、惊讶、无语、偷笑等状态；没有对应情绪时不用图。

写稿时先回答三个问题：**刚发生了什么？鹅原本以为会怎样？玩家听完是否更想继续，而不是被评价？** 三个问题答不上来，就用清楚的产品文案。角色不能替代必要规则，也不能虚构成绩、历史记录或下一步玩法。

避免：幼儿化语气、撒娇、拟声、套用网络热梗、温柔陪伴套话、第三人称旁白、解释自己在卖关子，以及“鹅的嘴硬现场”这类性格标签。可以有冷幽默和锋利的反击，但别把“毒舌”理解成攻击用户。

## 各模块的角色位置

- **首页与目录**：主要展示项目及进入路径。角色可随某个重点推荐出现，不承担每张卡的说明。
- **小游戏**：鹅是设计挑战的人；开场可以放话，关键反转和结算可以反应。操作过程中尽量让游戏本身制造紧张感。
- **趣味测试**：鹅是会猜错的观察者。结果可以有它的态度，但不能把娱乐结果写成对用户的权威诊断。
- **决策工具**：鹅可以表现出急着拍板的倾向；选项、结果和重选动作保持明确。
- **图鉴与记录**：真实记录是主角。解锁或刷新记录时鹅可以回应，未获得的内容保持悬念，但不暗示不存在的进度或奖励。

## 与 Duo 的关系

参考 Duo 的**明确欲望、情绪反应、持续关系和可辨认的表情**，不复刻绿色猫头鹰的外形、台词或以提醒制造压力的传播梗。Duolingo 官方角色指南强调 Duo 支持用户取得进展、情绪鲜明且执着，同时明确排除威胁、攻击和刻薄。鹅自己的戏剧机制是“自信设局，被玩家的真实表现打乱，仍然认账”；每次露出都服务于这一机制。
