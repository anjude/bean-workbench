# 疯狂大鹅人生流程动效方案

## 目标

让玩家在一次人生里持续看见「抽取身份 → 认识处境 → 开始生活 → 年度变化 → 面对选择 → 看见后果 → 回顾一生」的过程反馈。动画承担状态解释与情绪节奏，不作为页面装饰；所有动效不改抽样、人生模拟、属性结果和存档规则。

## 动效原则

1. **先有预期，再给结果。** 身份抽取和人生结束允许短暂蓄势；普通年度推进快速反馈，不拖慢连续游玩。
2. **每个动作都看见结果。** 年龄、属性、资源、选择记录和人生地图发生变化时，变化处直接动起来。
3. **动效说明业务状态。** 重点表现抽取、年龄推进、玩家选择和属性变化；页面淡入只负责短暂衔接，不作为主要游戏反馈。
4. **动效可以跳过。** 身份揭晓提供立即揭晓按钮；自动推进不等待页面入场或属性计数结束。
5. **只用 Cocos Creator 原生组件。** 沿用 `LifeDemo.update`、`UIOpacity`、`UITransform`、`Graphics` 和现有角色精灵，不另加动画框架、音频或外部运行时。

## 参考项目得到的设计规则

- [LIFESTATE](https://github.com/AimJax/Lifestate) 把人生时钟、玩家状态和事件系统放在模拟层，UI 从权威状态读取结果。疯狂大鹅继续让 `life-engine.ts` 决定真实起点、人生变化与事件结果；动画只展示已发生的状态变化。
- [Lifeline](https://github.com/hbarokha/lifeline) 用随年龄/情绪变化的头像、事件卡、选择结果提示和人生记录形成叙事视线。疯狂大鹅优先把鹅的反应、当前事件和人生记录串起来，不增加与选择无关的转场。
- [开心消消乐 Cocos Creator 工程](https://github.com/isghost/kaixinxiaoxiaole) 使用独立 `EffectLayer` 播放带 `Animation` 的特效 Prefab；`CellView` 按业务动作播放移动、消失和摇晃，分数按连锁步骤反馈，等待棋盘演出结束后再展示结算。可迁移的做法是「操作/状态变化 → 对应表现 → 完成后进入下一反馈」，而不是照搬消除特效。
- 没有找到直接对应的人生模拟玩法的 Cocos Creator 开源项目；人生模拟规则参考同类项目，Cocos 动画与界面组织参考 Creator 工程。参考工程不是疯狂大鹅的依赖，也不复制其素材。

## 疯狂大鹅的交互演出

### 出生：抽中的身份必须落在真实结果上

玩家点击新人生后，真实出生身份先由游戏引擎按当前抽样逻辑确定。卡片快速轮播姓名与地区，随后减速；最后一段停在这局真实姓名和出生地，保留短暂停顿，再进入出生档案。跳过只略过轮播，绝不能重新抽取。揭晓后让姓名、地点、家庭处境、初始状态按阅读顺序出场，底部「开始这一生」一直可见。

### 前进：表现一年经过和状态变化

点击「前进 1 年」时，年龄牌翻到下一岁；年份到达学龄、成年或晚年节点时，年龄牌和阶段标签使用对应强调色。属性变化在对应属性条上从旧值走到新值，旁边显示真实增减；新年度记录插入记录列表顶部。没有事件时不额外弹一张泛化结果卡。

「跳到下个选择」按经过年数快速翻过年龄牌，属性汇总一次过渡到最终值；停止时让关键事件卡从列表中抬起并短暂停留，明确显示时间已经暂停。不能逐年播放完整过场或阻止玩家继续操作。

### 生活重心：选择在时间推进前生效

学习、关系、休息三个生活重心使用三张明确选项卡。当前选项保留选中标识；切换时标识滑到新卡，卡下说明解释本年倾向和代价。选择重心不立刻加减属性；推进年份后，实际发生的属性变化再由对应属性条展示，避免让玩家误以为点击卡片立即结算。

### 关键事件：先聚焦事件，再展示因果

事件出现时暂停时间，当前事件卡和可选行动成为视觉中心；思考姿势鹅朝向选项。玩家按下某项时，按钮立即响应并锁定一次提交，避免重复触发。结算后结果卡保留「选择的行动 → 叙事后果 → 实际属性/资源增减」三层信息；变化在相应属性条及资源数字上同步表现。鹅仅在状态变化偏积极时庆祝，代价明显或结果复杂时保持思考姿势。

### 结局：用一生的轨迹收尾

死亡/寿命结算触发时，先停止年龄推进并展示结局原因，再展示终身总结。人生地图按时间从早到晚填入真实快照颜色；点击或触摸某一年可查看当年事件和状态。人生记录按照时间顺序进入，不把所有卡片同时弹出。

## Cocos 实现分工

- 业务逻辑继续由 `life-engine.ts` 管理；页面代码只读结算前后状态，计算用于显示的差额，不把动画值写回存档。
- 固定循环、数字补间和进度条可由一个表现组件驱动；一次性扫描光、结果卡落位、年度翻牌等独立演出用可复用的 Cocos Tween/AnimationClip。鹅的常驻呼吸与眨眼属于角色待机，不替代关键事件反应。
- 玩家每次操作不触发整页进出。仅在首页、出生档案、人生主界面、结局等流程切换时使用短转场；推进年龄、切换重心、收藏记录等同一页面内操作只更新相关反馈。
- 多个反馈遵守顺序：操作确认立即出现；结算后属性/资源变化并行播放；关键决定或结局完成后才展示下一阶段。普通计数和自动推进不等待装饰演出。

## 全流程动效表

| 阶段 | 触发 | 画面反馈 | 时长/节奏 |
| --- | --- | --- | --- |
| 流程切换 | 首页、出生档案、人生、结局之间切换 | 短淡入；不为同一页面上的状态刷新重复播放整页过场 | 约 0.2 秒 |
| 出生身份抽取 | 点击「抽取新人生」 | 真实身份已确定；姓名/出生地快转、减速，最后明确停在本局实际结果；立即揭晓跳过演出但保留结果 | 约 1.9 秒 |
| 出生档案 | 抽取结束 | 姓名、地点、家庭处境和统计数据分组揭晓，主按钮引导开始模拟 | 约 0.35 秒 |
| 开始人生 | 点击「开始这一生」 | 年龄 0 岁和出生记录落入时间线；鹅进入待机 | 约 0.3 秒 |
| 普通年度 | 点击「前进 1 年」 | 年龄牌翻页；属性条呈现实际变化值；新记录从时间线顶部加入。阶段节点（6/18/60 岁）强调阶段变化 | 年龄/状态约 0.5 秒，不锁操作 |
| 跳转年度 | 点击「跳到下个选择」 | 年龄牌快速翻到目标年龄，按总跨度控制速度；最终事件卡聚焦并暂停，属性只从旧值过渡到最终值 | 约 0.65 秒上限，不逐年播完整演出 |
| 生活重心 | 玩家切换学习、关系、休息 | 选中标识滑到当前重心；说明文案解释方向与代价；数值只在年度结算后变化 | 约 0.2 秒 |
| 关键事件 | 年度推进触发事件 | 时间暂停；事件内容成为视觉中心；鹅看向选项；操作区仍提示该点哪里 | 选项依次进场，但不能延迟可点击状态 |
| 选择结算 | 玩家按下一个选项 | 按钮即时确认并阻止重复提交；结果卡展示选项、叙事和生效增减；相应状态条同步更新，鹅根据结果反应 | 反馈约 0.3–0.55 秒 |
| 结局 | 模拟结束 | 显示结束原因与终身总结；人生地图按真实快照顺序生成，记录可点开回看 | 首屏约 0.5 秒；地图动画可跳过 |

## 验收

- 抽取时能看见连续候选值和减速，最后一帧与出生档案的姓名/地点一致；跳过后直接显示同一结果。
- 普通年份和快进后的属性数值/条形最终与 `life.stats` 完全一致，动画不写入存档、不改变随机种子。
- 选择反馈展示刚才选中的选项、对应故事结果和应用到模拟状态后的实际增减值；变化因属性上限而被截断时，以真实生效值为准。
- 关键决定出现时自动推进仍暂停；选项可立即点击，不被过场拦截。
- 人生结束与档案回看均能完成；旧存档无需迁移。
- 微信小游戏构建可加载已有鹅精灵；动画过程不请求网络资源。
