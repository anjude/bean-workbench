# QB91 鹅懂个啥大转盘配置化

## 目标

将鹅懂个啥大转盘改为由后端托管配置，减少调整转盘内容对小程序代码修改和重新发布的依赖。具体配置范围、管理方式与发布流程待需求沟通和方案设计确认。

## 范围

- `business-repo/uni-gknow`：大转盘配置加载与展示。
- `business-repo/backend-superone`：大转盘配置托管接口及数据持久化。
- `business-repo/frontend-contracts`：如需新增或调整跨端 API 契约。
- 本任务 `plans/`、`process/`：设计方案与阶段记录。

## 边界

- 先梳理现有大转盘功能、配置内容和运行方式，再确认后端数据结构、管理/发布方式及验收范围。
- 不默认建设可视化管理后台，不扩展到其他测试或副本配置。
- 不改动与本需求无关的鹅懂个啥功能。

## 当前状态

进行中。已盘点探索页现状：测试/副本内容有后端配置接口，但探索入口与页面组织仍由小程序静态定义；详细结论见 [需求理解与现状盘点](process/01-需求理解与现状盘点.md)。大转盘配置范围和技术方案待梳理。
