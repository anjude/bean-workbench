# QB91 鹅懂个啥大转盘配置化

## 目标

将鹅懂个啥大转盘的系统转盘改为后端配置，同时支持本地操作日志与独立自定义转盘。用户只读系统转盘；个人操作在本机重放，只有明确复制时才生成独立自定义转盘，系统配置始终不受用户改动影响。

## 范围

- `business-repo/uni-gknow`：大转盘配置加载与展示。
- `business-repo/backend-superone`：大转盘配置托管接口及数据持久化。
- `business-repo/frontend-contracts`：如需新增或调整跨端 API 契约。
- 本地操作日志、自定义转盘和选项仅保存在当前设备，本期不做账号云同步。
- 本任务 `plans/`、`process/`：设计方案与阶段记录。

## 边界

- 先梳理现有大转盘功能、配置内容和运行方式，再确认后端数据结构、管理/发布方式及验收范围。
- 不默认建设可视化管理后台，不扩展到其他测试或副本配置。
- 不改动与本需求无关的鹅懂个啥功能。

## 当前状态

已完成实现与生产配置同步。后端代码已在远端 `release`，契约仓与小程序 `release` 已推送 QB91 提交；live 已创建 wheel/option 表并从 test 精确同步 3 个转盘、202 个候选项。小程序类型检查与 mp-weixin 构建通过，微信平台已上传 0.1.1 版本代码，待在微信公众平台提交审核并发布。实现与发布记录见 [开发与迭代](process/03-开发与迭代.md)。
