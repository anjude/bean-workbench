# Topic 页面 UI/UX 重构

## 原型与信息层级

Topic 是桌面端的轻量记录工作区，采用紧凑工作台/记录流组合：主题用于切换上下文，快速记录是页面主 CTA，记录内容是主要阅读区。沿用 `uni-superone` 的主色点缀、语义令牌和克制层次，适配 uTools 桌面端，不复制 uni-app 页面结构。

视觉顺序：模块导航与新建主题 → 当前主题选择 → 快速记录与保存 → 当前主题的记录流。减少大间距、主题 chip 内边距和记录卡片操作按钮；记录正文占主要面积。

## 操作入口

- 高频动作保留可见入口：新建主题、保存记录、查看记录/跟进。
- 低频主题动作（置顶、取消置顶、编辑、删除）进入上下文菜单。
- 低频记录动作（复制、标记/取消标记、编辑、删除）进入同一个通用上下文菜单；记录的查看/跟进入口继续可见。
- 通用组件负责菜单布局、视口边界定位、点击外部/滚动/窗口变化/ESC 关闭和键盘方向导航；Topic 业务层只提供菜单项和动作映射。

## 状态矩阵

| 状态 | 页面表达与动作 |
| --- | --- |
| 首次加载且无主题缓存 | 保留页面骨架，显示加载反馈 |
| 主题加载失败 | 错误信息与重试入口 |
| 尚无主题 | 空状态；“新主题”入口可用；记录编辑器禁用 |
| 已有主题但未选中 | 展示主题切换条，提示先选择主题 |
| 已选中主题、暂无记录 | 记录区显示空提示；快速记录可用 |
| 已选中主题、有记录 | 显示记录列表、条数、时间、记录正文和紧凑详情入口 |
| 记录加载或失败 | 在记录区局部提示加载/错误，不遮掉页面主要框架 |
| 保存中/不可保存 | 保存按钮显示进行中；空内容或无主题时禁用 |
| 上下文菜单打开 | 视口内定位；外部点击、滚动、窗口变化及 ESC 关闭 |
| 记录删除/编辑等请求失败 | 沿用现有 composable 的错误反馈，不改变契约或业务语义 |

## 本轮调整

- 移除主题标题、数量和“右键管理”独立行；管理能力仍由主题 chip 的右键菜单触达。
- 为 `MarkdownEditor` 增加可选工具栏完成按钮能力；Topic 页将保存按钮放到 Vditor 工具栏右侧，并同步保存中与禁用状态。Vditor 支持自定义 toolbar item，因此无需依赖 uTools 私有接口或额外扩展 API。
- 编辑器外部卡片容器改为透明，Vditor 编辑区域、工具栏和预览区域统一使用卡片底色。
- 收紧记录卡片内边距、卡片间距、正文段落间距及元信息区域留白。

## 截图反馈修正

- 截图确认 Vditor 自定义工具栏项未因 `className: right` 自动靠右，改为给完成项显式设置 `float: right`，使保存按钮落在工具栏右端。
- 记录项此前仍继承通用 `cu-card cu-card--small` 与 MarkdownViewer 的默认正文间距；现移除通用卡片类，使用 Topic 页面专属卡片边框、底色和紧凑 padding，并显式压缩 Markdown 标题、段落、列表和代码块的 margin/padding。
- 本轮仅跑 `npm run typecheck` 与 `git diff --check`；不做浏览器检查。
- 新建/编辑主题弹窗单独采用紧凑尺寸，顶部间距固定为 24px、最大高度适配可视区，缩小标题/正文/底部 padding 与描述编辑器高度，减少工具栏按钮；避免全局 Element Plus 弹窗的大留白挤占 uTools 工作区。
- 记录详情/跟进页改用页面专属紧凑卡片，收窄页面间距、压缩正文 Markdown 间隔；跟进保存入口集成到编辑器工具栏，减少独立按钮行。
- 对照 `uni-superone` 的详情/长按操作：跟进列表不显示“继续跟进”按钮；结合三级记录上限，uTools 跟进卡片不提供下级跳转，只通过右键菜单编辑/删除，并为编辑增加轻量弹窗。
- 排查详情页“返回记录”偶发无响应：嵌套打开不同 LogDetail 时 Vue Router 复用组件，而页面仅在 `onMounted` 加载，返回虽切回旧路由参数但内容未重新加载；改为监听记录 ID 加载，并为无应用内历史时提供 TopicList 兜底。
- 限制记录层级为“主题 → 记录 → 跟进”：根记录详情加载和展示一层跟进；跟进卡片不再点击进入下级详情，并且跟进详情不加载/展示子跟进，也不提供新增跟进编辑器。跟进仍可通过右键编辑或删除。
- Topic 记录列表移除“主题名的记录 / 条数”标题行，让列表直接从编辑器下方开始。
- 将 Cmd/Ctrl+Enter 快捷保存统一收进 `MarkdownEditor`：配置完成按钮时由编辑器自身监听并触发 `complete`，移除 Topic 页的全局键盘监听，跟进编辑器复用同一快捷键。
- 提交前核对本次变更已有过程记录，并运行 `npm run check`，类型检查、lint、契约检查和 Vite build 均通过；未做浏览器检查。
