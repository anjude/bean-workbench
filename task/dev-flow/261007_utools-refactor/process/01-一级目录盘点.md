- `.env.development` 的 `VITE_ENV=develop`、`.env.production` 的 `VITE_ENV=release` 与 `src/constants/config.ts` 对 `MODE=development`/默认生产模式的回退结果一致，可评估移除；`.env.example` 没有有效赋值，目前只重复 README 说明：对应 `.env.*`、`README.md`、`src/constants/config.ts`。
- `auto-imports.d.ts` 目前为空，源码显式导入 Vue 与 Element Plus API；`unplugin-auto-import` 的配置未产生实际声明，可评估一并停用。`components.d.ts` 有效声明了 Vue 全局组件，须保留或确认组件自动导入插件不再生成全局组件：`vite.config.ts`、`auto-imports.d.ts`、`components.d.ts`。
- `docs/TECH_STACK_IMPLEMENTATION.md` 是旧的通用实施建议，提到现项目未采用的 axios、dayjs、Naive UI 等方案，容易误导；`docs/CHANGELOG.md` 的产品简介仍列已删除的股票功能，建议改为准确历史说明或移除：`docs/TECH_STACK_IMPLEMENTATION.md`、`docs/CHANGELOG.md`。
- `tsconfig.node.json` 被 `tsconfig.json` project reference 引用；`.gitmodules` 用于 contracts 子模块；CI workflow、lockfile、Vite/ESLint/Prettier 配置都有实际用途，不建议为减少文件数而合并：对应一级配置文件及 `.github/workflows/ci.yml`。
