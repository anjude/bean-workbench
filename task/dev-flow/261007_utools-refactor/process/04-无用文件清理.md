# 无用文件清理

## 结论

完成一轮高置信度清理：删除没有源码消费者的历史类型、常量、工具、barrel 和图标字体演示文件；去掉仍在使用的计划与清单状态枚举上的本地重复包装，改为直接消费共享契约。活跃源码目录未迁移。

用户明确要求 Vite 环境先不动。本阶段没有改 `src/constants/config.ts`、`.env.example`、`src/App.vue` 或 Vite 环境选择逻辑；此前已授权并完成的一级辅助文件精简保留。

## 删除内容

- 旧类型：`types/share.ts`、`types/components.ts`、`types/item-management.ts`、`types/md-editor.d.ts`、`types/store.d.ts`、`types/platform.d.ts`。
- 旧常量与工具：`constants/enums.ts`、`constants/static-data.ts`、`constants/item-categories.ts`、`utils/image-upload.ts`、`utils/permission.ts`。
- 未使用出口与样式：`constants/index.ts`、`composables/index.ts`、`plugins/index.ts`、`styles/index.scss`、`styles/variables.scss`。
- iconfont 生成器演示：`demo.css`、`demo_index.html`、`iconfont.js`、`iconfont.json`。运行时引用的 CSS 与字体文件保留。
- `contract.ts` 中无消费者的 `commonApi` 和 `itemApi` 绑定。

## 类型整理

- `types/plan.ts` 只保留仍有消费者的 `RecentTask` 与 `RecentTaskForm`；任务状态和优先级直接来自 `@/contracts`。
- 计划页面、管理 composable 和 store 移除 `TaskEnums` 包装，直接使用契约导出的 `TaskStatus`、`TaskPriority`。
- 清单执行状态直接使用契约 `ExecutionStatus`；保留用于界面文案映射的 `ExecutionMode`（Overview/Step）。
- 移除未使用的清单表单/筛选/模板/草稿类型，以及通用类型中的空 `BaseFormData`、未用验证和分页结构。

## 结构核查与验证

- 活跃样式入口为 `styles/main.scss`，运行时 iconfont 入口为 `styles/iconfont/iconfont.css`；这两者及字体文件保留。
- `constants/config.ts` 是当前应用配置入口，按用户要求不改。
- 对残留符号与已删除路径执行了源码搜索；未发现指向已删除类型、常量、barrel、工具或演示文件的导入。
- `npm run check` 通过：typecheck、lint、契约路径检查（9 个 API 域）和 Vite 生产构建均成功。
- 子仓提交 `eaec6c4`（`261007 清理uTools前端无用文件`）已推送到 `origin/release`。
