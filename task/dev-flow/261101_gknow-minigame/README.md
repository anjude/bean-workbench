# 261101 疯狂大鹅微信小游戏项目

## 目标

新建独立微信小游戏「疯狂大鹅」，主打副本体验和双人小游戏；从「鹅懂个啥」的部分模式中梳理可复用内容，候选包括「默契大作战」。

## 范围

- 「鹅懂个啥」现有玩法中适合小游戏形态的模式评估，包含「默契大作战」候选。
- 独立微信小游戏项目的产品范围、工程初始化、技术方案与后续实现。
- 与现有 `business-repo/uni-gknow` 小程序的玩法、品牌和必要能力关系梳理。

## 边界

- 本任务目标是微信小游戏项目，不是微信小程序项目；不在 `business-repo/uni-gknow` 中新增小游戏页面来替代独立工程。
- 当前只建立任务上下文；具体首发玩法、账号/房间/实时通信复用方式、小游戏工程目录与技术栈需在需求和设计阶段确认。
- 未经需求和方案确认，不开始业务代码实现；不把现有「默契大作战」实现假定为可直接移植。
- 不影响现有小程序的日常开发、发布和用户数据。
