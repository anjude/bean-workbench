# 逐年人生模拟 Demo

## 体验目标

以 [1 in 8 Billion](https://1in8b.life/) 为玩法参照，验证一局完整的人生模拟。每局抽取虚构的家庭处境，年龄逐年变化，年度重心影响状态，关键事件暂停让玩家选择。多年后出现的机会会受前面决定影响，结尾回顾这一生，再抽一个起点。

## 首版边界

- 使用原创背景、事件和演示概率。出生阶段交代家境与父母职业，随后覆盖童年、成年、晚年。
- 年度重心、逐年推进、跳到下个决定、自动推进。自动推进遇到决定会暂停，玩家可以中途切换重心或手动暂停。
- 本机记录当前年龄、选择和状态。打开后可继续，结局后可以再开一局。
- Cocos Creator 的竖屏场景是实际试玩入口。首轮玩法在客户端闭环。

## 页面与状态

| 状态 | 玩家看到和能做的事 |
| --- | --- |
| 首页 | 开始人生，已有有效存档时显示继续 |
| 出生 | 查看家庭与出生地，确认后进入年龄 0 |
| 成长 | 查看年龄、处境、四项状态和近期事件，设置重心、逐年或快进 |
| 决策 | 阅读事件并选一项，选择写进记录后恢复推进权限 |
| 结局 | 查看人生摘要和关键选择，回首页或再开一局 |
| 存档不可读 | 从首页开新局 |

## 实现与验证

项目原先仅有 Creator 工程骨架。用 Cocos 场景及 TypeScript 组件作为入口，独立的模拟规则根据种子、年龄、重心和决定更新状态，原创事件表负责文案及分支。组件渲染状态，推进和选择完成后写本地存档。验收覆盖同起点分支、快进停在选择、重开、续局以及 Cocos 构建结果。
