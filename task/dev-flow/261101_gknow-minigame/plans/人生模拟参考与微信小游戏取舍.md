# 人生模拟调研：让起点和决定在后来的场景里留下痕迹

## 推荐方向

「疯狂大鹅」可以做一个可重玩的短人生副本。开局给玩家一张具体的处境卡，之后用几次跨年推进串起值得亲手做的决定。结尾回放几个具体的人、物件和决定，让玩家看懂这局为什么走到这里，并想用同一个起点试一次不同选择。

首轮用一个虚构主题做样章，先验证玩家能否感到决定有后续影响。首发题材、时长和分支数量仍待确认。

## 原作观察

- 开局先揭晓角色的出生地和家庭。一局实玩抽到印度海得拉巴的女孩，出生卡交代父母工作、租住情况和兄长。具体的家比国家统计数字更快让人进入角色。原作将出生条件按真实数据抽取，还展示四位同秒出生者作对照。[原作首页](https://1in8b.life/en/) · [官方机制说明](https://1in8b.life/en/about/)
- 游戏平时按年推进，遇到事件时停下来选择，也能快进或自动推进。实玩中，选择去安慰哭泣的小孩后，下一条记录马上描述角色牵住了对方的手。到学龄后，年度重心还可以在学习、交友等选项间切换。原作说明这些决定会改变后续机会，实玩只抽样观察到童年，没有对同一起点做分支对照。[官方机制说明](https://1in8b.life/en/about/)
- 另看了一份公开纪念馆记录。它用职业摘要、人生轨迹、家庭照片和物件回顾一生，还允许玩家进一步看照片和影片。结局回顾的证据来自公开样本，未亲自通关到结算页。[原作纪念馆入口](https://1in8b.life/en/)

## 微信小游戏版怎么取舍

| 原作设计 | 我们可以怎么做 |
| --- | --- |
| 随机出生、国家数据、家庭条件 | 保留揭晓起点。用少量原创处境卡代替全球模型，每张卡交代家里能给什么支持、你想做什么、眼下有什么约束。起点差异要改变机会或代价。 |
| 逐年走、每年选重心、随时调速 | 改成几次有意义的跳年。普通年份用一句过场交代，遇到会改写下一段生活的事情才让玩家做决定。 |
| 面板、四项状态、收入和资产曲线 | 规则只跟踪确实会用到的状态，例如存款、与某个人的联系、是否掌握一门手艺。优先通过选项能否负担、谁还会联系你、有什么机会来表现。 |
| 完整年表、纪念馆、相册与留言 | 先做一张结局卡，列出起点、两三件改变走向的事和最后的生活状态。保留回放关键决定的入口，公开留言、纪念馆和影片制作留待需求明确。 |
| 同秒出生，看到不同起点的人怎么过 | 可以进一步做「同一起点」异步重玩。先让自己换个选项玩第二遍，有比较价值再让好友从同一张卡开局。对比差异发生在哪一幕，各自付出什么代价。 |

现有「大厂人的一生」有成熟的分幕、对白和局部回应，用户选择通常改变现场或下一幕的细节。新副本可沿用这些叙事手法，另外验证少量跨幕的因果。每个影响后续的选择至少要在后面改变一次可见机会、关系或结局；其余回应可以继续承担角色表达。[现有大厂副本方案](../../261009_gknow-daily/plans/人生副本-大厂人的一生.md)

## 样章建议：离家那一年

示例主题用来展示规则，未定为首发。你 22 岁，家里只够给你准备一个月房租。眼前有两条路：留在本地跟熟人学维修，或者去深圳做一份底薪更高、头两个月要自己垫住宿的工作。

- 选择留下，短期现金更宽裕，也能积累本地熟客。几年后熟人准备退休，你有接下铺面的机会，同时要承担经营风险。
- 选择外出，先看到押金吃掉积蓄，之后才出现跟同事带项目或转行的机会。几年后回家，熟人的铺面可能已经转给别人，但你手上有另一套工作经验和人脉。
- 结尾分别回放最初那笔房租、一个关键关系和多年后的生活场景。两条路线有不同所得和代价，结局卡不做成功排名。

先用一张起点卡、约五幕、两条能完整走通的路线试玩，目标单局 5–8 分钟。后续增加起点卡时，每张至少改变一次决策的可用选项或实际代价。以同起点复玩为对照，固定与选择无关的外部事件，避免玩家误把随机变动当成决定的后果。

## 首轮验证

1. 新玩家读完起点卡，能说出自己眼下缺什么、为什么要作第一次选择。
2. 同一个起点走两条路线，玩家在结算前已经看到至少一处实质差异，结算后能指出它从哪一步来。
3. 微信真机验证单手推进、切出微信再回来能接着上一幕，以及小屏幕能完整读到场景和选项。首轮可用本地进度保存，好友同起点分享单独验证冷启动和回到前台的落点。

工程上用 Cocos 的同一套场景播放器读原创剧本配置。样章先跑通场景、选择和结局，原有 `backend-superone` 可在确需跨设备进度或异步对比时承接服务。随着副本素材变多，可按剧本拆 Asset Bundle。[Cocos 小游戏分包文档](https://docs.cocos.com/creator/3.8/manual/zh/editor/publish/subpackage.html)
