# 261101 鹅懂个啥公司副本

## 目标

为「鹅懂个啥」探索页新增公司主题副本方向，围绕真实公司发生过的特殊事件，整理可核查的素材并改编成可互动、可读的副本故事。

## 范围

- 业务仓：`business-repo/uni-gknow`，复用现有副本目录与沉浸式故事播放器。
- 研究真实公司的特殊事件，优先使用公司公告、监管文件、法院材料及可靠新闻来源核实。
- 形成候选事件清单、来源记录与故事化方案；内容范围确认后再进入剧本和实现。

## 边界

- “play”指鹅现有的副本组件（沉浸式故事播放器）；本轮研究适配该组件的公司事件候选。
- 事件事实与虚构人物、情节分层表达；不把未经证实的传闻写成事实，不虚构真实公司或个人的违法结论。
- 复用现有小程序副本形态；暂不涉及独立微信小游戏项目。
- 选题和剧本取舍由用户决定，候选整理不等于确认开发。

## 当前状态

候选清单见[公司事件候选](plans/公司事件候选.md)。
