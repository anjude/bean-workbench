# 鹅游戏玩法方向评估

> 历史讨论资料：保留方向评估背景；当前实施范围和战斗规则见 [本地对战 MVP 方案](../../plans/本地对战MVP方案.md)。

## 评估范围

本评估基于用户 2026-11-15 确认的玩法方向，仅判断产品闭环、规则风险、差异化和首发复杂度。这里不是功能与系统设计方案，不授权业务代码或后端实现。

## 结论

方向有可理解的主循环：玩家在多条赛道间即时部署，观察兵力对冲和基地压力；战斗受阻后转入割草副本，取得资源并通过升级或固定配方合成提升卡牌，再回到对战。它把短时操作决策与长期成长连在一起，且副本内强化不带入对战，边界清楚。

当前最大问题不是玩法单元缺失，而是竞争公平和对战规则还不够闭合。建议下一阶段先设计一场可玩、可复盘的最小对局，并用数值原型验证双方能否读懂“哪条线占优、为什么推进、基地何时掉血”。割草副本和完整养成经济可随后接入，避免首版同时承担多个完整系统。

## 有利条件

1. **对局目标直观。** 赛道推进与基地血量提供可见的空间和数值目标，玩家无需理解复杂剧情即可判断局势。
2. **部署决策有即时反馈。** 多赛道竞争、手牌容量和定时刷新共同形成“现在把哪张牌放哪条线”的时间压力。
3. **副玩法有明确服务对象。** 割草副本专门供给卡牌成长材料；局内随机强化限定本局，避免副本随机增益直接污染对战平衡。
4. **合成规则容易建立预期。** 固定配方使素材收集对应明确目标，不需要抽卡概率或随机合成。
5. **广告点位自然。** 副本结束后选择是否双倍领取材料，比在对局中途插入广告更容易保持操作连续性。

## 主要风险与建议

### 1. 对战成长可能压过临场策略

卡牌升级永久增加战力，而副本持续产出升级与合成资源。若匹配双方按当前卡牌强度直接对抗，投入时间较多者会取得稳定优势；玩家可能把输局归因于卡池，而不是部署决策。减少胜负奖励差距并不能解决开局战力差。

进入系统设计前应明确对局公平规则，例如按卡牌池强度分段匹配、匹配内归一化关键属性，或把有成长差异的玩法和公平竞技分开。具体选项会影响卡牌成长的价值和匹配系统，需要由产品方案决定。

### 2. 多赛道对冲规则需要做成可读的因果链

当前定义从“赛道战力互耗”跳到“强者推进”，但缺少推进与伤害之间的定量关系。玩家需要能从战场直接看懂：战力差如何转为推进速度、什么情况下抵消、突破后造成多少基地伤害、双方同时突破如何结算。若这些过程只显示总战力数字，投卡决策容易变成比较大数字。

设计时要明确赛道数量、单位是否以实体存在、战力互耗频率、推进速度、伤害公式和对局结束条件，并让动画或标记展示这些变化。首个原型只需少数赛道和卡牌来验证因果关系，不必先铺开完整卡牌池。

### 3. 与《顶你个牛》的机制接近，原创性需要落实到规则层

第三方公开介绍将《顶你个牛》描述为五赛道、双方投放单位、单位未被拦住则扣分的对抗玩法。[九游玩法介绍](https://www.9game.cn/dngn/5698996.html) 当前方案同样以多条赛道、双方投放单位、对冲后突破扣基地血量为核心。换成鹅、美术、术语和数值能形成视觉差异，但不足以单独说明玩法体验已经拉开。

用户已经明确只借鉴通用机制。实施前建议逐条对照公开实机，避免沿用其赛道推进、单位合成、攻防节奏或胜负反馈的具体组合；应由本项目自己的手牌刷新、部署限制、卡牌职责、赛道互动或目标结构提供可感知的独特决策。这里是产品与知识产权风险提示，不构成法律判断。

### 4. 首发范围横跨两个可独立成立的游戏模式

实时卡牌对战包含匹配、邀请、手牌、战斗同步、网络异常与公平性；割草副本包含移动、自动攻击、怪物、局内强化、关卡和结算。二者各自都有完整玩法循环，再叠加卡牌成长、素材经济、广告及双平台适配，首发开发量和验收面较大。

建议将里程碑拆为“对战规则可玩验证 → 最小养成闭环 → 割草供料副本 → 双平台与广告适配”。这保留完整方向，但允许先验证核心赛道对冲是否好玩。具体先做 bot 或真实联网、以及首发是否必须同时上线两种模式，留给系统设计决策。

### 5. 隐藏对手实现有公平与信任边界

用户确认玩家端只显示匹配或邀请好友入口，对手底层实现内部决定。匹配对局可由系统按设计提供对手，但界面、头像、战绩和文案不应虚构“真人在线”等事实；邀请好友对战则需要明确邀请者与被邀请者确实进入同一房间。若为控制人数而在真人排队时切到系统控制角色，应核对是否会影响用户对竞技公平的理解。

### 6. 双平台 IAA 需要用户主动、收益兑现且不中断对战

副本结算页提供可选广告双倍领取是合理起点。抖音小游戏公开广告规范要求用户能清楚选择是否观看、明确看到奖励内容，并在完整观看后按承诺发放；广告不得在用户无感知时触发。[抖音小游戏广告审核常见问题](https://partner.open-douyin.com/docs/resource/zh-CN/mini-game/guide/contactus/ad) 对局中的奖励广告会打断实时战斗，建议先限制在结算或非战斗界面，并为广告不可用或播放失败设计可继续游玩的结果。

抖音小游戏内容规范还要求游戏开始画面展示指定信息标识和《健康游戏忠告》。[抖音小游戏内容规范](https://partner.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/content-norms-for-mini-game) 微信和抖音的广告接口、审核细则与发行要求应在发布阶段分别重新核对，不假设一套实现自动满足两端。

## 进入功能与系统设计前应解决

1. 对战的公平模式：永久成长对匹配战力的影响，以及匹配模式与好友模式是否使用相同规则。
2. 最小对局规则：赛道数、对局时长或结束条件、投放频率、赛道对冲与推进/伤害关系。
3. 对手策略与呈现：哪些模式可能由系统控制对手，玩家看到哪些身份和状态信息。
4. MVP 顺序：先验证对战，还是必须同时交付可供料的割草副本；哪种方式足以验证主循环。
5. 账号和数据范围：跨微信/抖音是否共享账号或进度，若不共享则明确平台间独立成长。

以上问题是下一阶段方案要具体化的产品决定；当前不需要逐项先行确认，方案可基于最小可验证版本提出推荐并说明取舍。
