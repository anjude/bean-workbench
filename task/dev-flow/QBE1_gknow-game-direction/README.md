# QBE1 鹅游戏方向重选

## 目标

开发面向微信与抖音小游戏的多赛道卡牌对战游戏，以临场布卡对冲为主玩法、割草肉鸽副本为养成资源来源，采用纯 IAA 广告变现。

## 范围

- 复盘现有「疯狂大鹅」人生模拟方向的尝试与问题。
- 主线多赛道实时对战、固定卡牌冷却和基地血量胜负。
- 对战卡牌的升级、固定配方合成，以及为养成供料的割草肉鸽副本。
- 微信、抖音小游戏适配及纯 IAA 广告变现。
- 核对 `business-repo/crazy-goose` 当前工程、已有投入和可复用能力。
- 原方向背景与实现记录见 [`QB12_gknow-minigame`](../QB12_gknow-minigame/README.md)。

## 边界

- 用户已确认本页所列的玩法方向和核心规则；实现方案、数值规则、对局公平机制及 MVP 范围仍需设计并确认。
- 未经方案确认，不改动小游戏业务代码、后端或现有小程序。
- 旧人生模拟方向的实现和验收记录保留在原任务中，不在本任务里覆盖历史。

## 已确认玩法方向

1. **核心定位。** 多赛道数值对冲卡牌博弈，突出临场部署；割草肉鸽副本提供卡牌养成资源；纯 IAA，目标平台为微信和抖音小游戏。
2. **参考机制。** 从《顶你个牛》参考多赛道对冲和单位属性取舍；从实时卡牌对抗参考动态刷新手牌、赛道投放和基地血量结算；从《次神：光之觉醒》参考割草生存与仅在副本内生效的三选一强化；从合成类超休闲游戏参考固定配方合成。
3. **核心单元。** 固定卡牌投放、赛道单位对战、基地血量结算、卡牌升级、固定配方合成、割草生存和局内肉鸽随机强化。
4. **对战。** 双方在多条平行赛道部署单位；单位前进并以血量、攻击、防御和攻击范围等属性交战，存活单位可攻击敌方基地；基地血量归零即负。MVP 使用固定卡牌，投放后各自冷却，冷却结束可再次使用。
5. **对战入口。** 面向玩家只提供匹配对战和邀请好友对战；对手实现由开发侧确定，具体机制对用户不可见。
6. **卡牌养成。** 卡牌升级消耗金币和普通碎片，永久提升基础战力、伤害等属性并作用于玩家卡牌池。合成按固定配方消耗指定低阶卡牌和稀有素材，产出可预知的高阶卡牌。
7. **割草副本。** 单指拖动角色移动并自动攻击；击杀怪物触发三选一随机强化，该强化仅当前副本有效。副本角色与对战卡牌池通用；存活或通关结算养成材料，可自愿观看广告双倍领取。
8. **玩法闭环与边界。** 对战遇阻后进入副本获取材料，升级或合成卡牌，再回到对战。只借鉴通用机制，视觉、美术、术语和数值原创；不做抽卡、下注或赌博表达；副本强化不进入对战数值；胜负奖励避免过大差距。
9. **基地防御。** 敌方单位进入基地攻击范围后，基地自动攻击；单位靠近基地并存活时持续对基地造成伤害。
10. **金币与单位属性。** 金币随时间恢复至上限后停止，花费后继续恢复；部署卡牌消耗金币；单位使用血量、攻击、防御、攻击范围、攻击间隔和移动速度参与对战。
