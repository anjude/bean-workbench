# 回答依据与不确定性

## 目标

让一般回答和 beannote 写作中的分析判断以证据及用户明确前提为基础，准确区分推论与已观测事实。

## 修改

- 在 `AGENTS.md` 的「面向读者的写作」中加入通用规则：先给当前可确认的判断；用必要定语标示推论前提；只说明实质性证据缺口；关键前提不清且无法推定时求证。
- 在 `.agents/skills/bn-tools-edit-flow/references/writing-rules.md` 加入同一原则，并明确保留用户表达的个人观点，不把观点包装成已证实事实。
- 在本任务 README 索引本次规则沉淀。

## 验收

已检查两处规则互相一致，且 beannote 条款保留既有的用户观点与事实核查边界。未改动其他写作规则。
