# 任务编号统一迁移

## 目标

让工作台任务与 beannote 选题统一使用新版日期码和当日序号，移除旧式任务目录编号及有效引用。

## 完成内容

- 将 `task/workbench/`、`task/dev-flow/` 和 `task/beannote/topics/` 下 42 个旧式编号目录迁移为新版编号；原本已使用新版编号的目录保持不变。
- 同一日期的旧目录按完整原路径排序分配序号；已有编号优先占用，避免重复。
- 同步所有任务目录内 README 标题、`task/registry.md`、路由与交接规则、工作台记忆、知识库以及业务仓文档中的任务路径。
- 更新 `AGENTS.md`、`task/README.md`、beannote 目录说明和续接脚本；新任务只使用统一编号。
- Git 历史提交信息保持原样。handoff 文件名里的日期仍表示交接时间，不作为任务编号。

## 验收

- 四类任务目录中旧式编号目录数量为 0。
- 所有带编号的任务 README 标题与目录编号一致。
- 全仓已检索不到指向旧任务目录的路径；当前工作区中的既有内容和子仓未提交改动均保留。
