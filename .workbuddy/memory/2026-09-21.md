## 任务目录加 process/ 层

豆哥：handoff 记太高层的东西，每个阶段的过程结论要单独进 `process/xx.md`，process 记更细的。

**两层分工**（已写进 `wb-handoff` 开头）：

| | `handoff/` | `process/` |
|---|---|---|
| 答什么 | 下一步干什么 | 这一步发生了什么 |
| 读者 | 下一个会话的 agent | 事后回溯的人 |
| 粒度 | 高层一屏 | 细节可以长 |
| 时间轴 | 横切面（此刻全貌） | 纵切面（逐阶段累积） |

一句话：**handoff 是「我从哪接着干」，process 是「这件事怎么被想清楚的」**。

**process 命名**：`{阶段号}-{环节名}.md`，阶段号跟随流水线（`00-方案设计`/`01-后端开发`/内容线 `01-讨论`）；不跑流水线的用两位流水序号。同一阶段多轮追加到同一份，用 `## {日期} 第 N 轮` 分次，不新建文件。

**写什么**：做了什么 / 得到的结论（带出处）/ **被推翻的判断**（当时怎么想、被什么数据打掉）/ 待核清单。

**红线**：process 不写下一步（那是 handoff 的活），handoff 不复述 process 内容只引用路径——两边重复就会出现两份都不准。
