## 前提交代写法修正（豆哥第二次反馈，同日）

豆哥原话："这个对读者来说很生硬，我知道你是想告诉我，你把话说在前面了，按我的要求做了，但是作为正文，你应该思考的是怎么不露痕迹的表达出来，因为这个东西读者并不是很关心。"

我上一轮把「不确定前置」写成了「加一段声明」（声明放第一段 + 接一句"为什么仍值得看"），形式仍然是免责流程，只是位置挪前了。这是**用遵守规则的姿态替代解决问题**。

新判据：**不是"有没有声明"，而是"读者看不看得出你在声明"。能看出就是失败。**

三类不确定分别处理：

1. 事实未落定 → 写成来源（谁/什么时候/以什么方式拿到）。来源自带可信度，也自带"非最终版"的意思，不需要另说一句。
   - 对：「这轮融资的条款，路透 9 月 11 日先拿到了。记者直接查阅了这单的条款文件，不是转述别人的说法，所以能拆。」——来源、日期、可信度、为什么值得看，一句话办完。
   - 错：「先把话说在前面：本轮尚未官宣，数字以港交所披露为准。数字可能变，结构不会变。」
   - 差别：前者说这事实怎么来的（读者想知道），后者说作者不担什么责（读者不关心）。
2. 算法简化 → 算式里用"粗算""按规模加权"自然带出，不单独声明。
3. 结论是推演 → 措辞降级（"看起来""等于是在说"）。

禁止：元话语开场（"先把话说在前面/需要说明的是/声明一下/仅供参考"）、单列声明段、括号脚注、结尾补刀。

已同步四处：`表达设计.md` 第 0 件改写 + 体检表一行、`创作准则.md`「不确定前置」节重写（含对比例子）、`bn-0101-draft-flow/SKILL.md` 六件事第 0 件 + 体检第 4 条、`正文质检清单.md` 受众检查项。智谱稿 03 已改。

**元教训**：用户要求"把 X 做进去"时，别做成"加一个 X 模块"。读者视角的检验永远优先于规则的形式完成度。

## 前提交代二次修正（豆哥第三次反馈，同日）

豆哥原话："好莫名其妙的话，你到底想告诉读者什么。你这段文字面向的是谁，是我吗……你给我解释有个毛用，你给读者说啊，看他会鸟你吗"

二版开头「路透 9 月 11 日先拿到了，记者直接查阅了条款文件，不是转述别人的说法，所以能拆」又翻车。两次翻车同一个根：**一版是向读者免责，二版是向读者自证，都在处理作者的顾虑，没一句在给读者东西。** "来源即信息"的上一版规则还是把"交代来源"当成必须完成的动作，只是包装得更像事实。

最终判据：**开头每一句，是给读者的，还是给作者的？** 给读者的是事实、反常、判断；给作者的是来源说明、可信度解释、免责。给作者的句子全是废句。读者默认作者是看过材料的，唯一要提醒的是"这不是官宣"，一个定语办完：

- 对：「但路透看到的条款里，打折的股票只占 20 亿」——五个字，来源+可信度+非官宣全办完，注意力全在数字上。
- 错一版（免责）：「先把话说在前面：还没官宣，以港交所披露为准」
- 错二版（自证）：「路透先拿到了，记者直接查阅了条款文件，不是转述别人的说法，所以能拆」——比一版隐蔽，看起来像在讲事实，实际每句都说给作者自己听。"所以能拆"是作者对自己说的。

新增禁止项：解释来源为什么可靠（记者亲自查阅/一手拿到/不是转述）全是自证；来源单独成段成句；"以公告为准"放发布文案，不占正文。

四处规则同步（表达设计.md 第 0 件+体检表、创作准则.md 不确定前置节、bn-0101 SKILL.md 六件事第 0 件+体检第 4 条、正文质检清单.md），创作准则里保留两次翻车实录当错例。智谱稿 03 第三版落盘（约 360 字，开头直接骂声+数字）。

**元教训 2**：连续两版被否时，别在原思路上打补丁——"声明→来源陈述"只是换包装，"完全不占正文、压成定语"才是换思路。被否后先问"读者到底需要从这里得到什么"，答案往往是"什么都不需要，直接给内容"。

## 正逻辑规则（豆哥第四次反馈，同日）

豆哥原话："多讲正逻辑，别总想着用反逻辑教人。"

智谱稿命中的两处：①「捡便宜的人不会这么签」——双重否定式说教，改正面陈述「他们买的是两年后的价」；②「这不是折价发行，是略微溢价」——"不是…而是…"打脸句式，改顺着事实说「折价的只占四成，溢价进来的占六成，这单是略微溢价发行」。

**反逻辑的本质：拿读者的认知当靶子，先立"大家以为 X"再打脸"其实是 Y"。用多了整篇都在教人"你想错了"，说教感由此而来。**

规则（入创作准则逻辑禁令）：

- 默认正逻辑：事情是什么、怎么运作、说明了什么，顺着事实说。
- 反转结构全文最多一处，且仅当事实本身构成反转、读者确实普遍持相反认知时才用；反转靠摆事实完成，不靠"不是…而是…"句式宣布。
- 禁双重否定式说教（"X 的人不会这么签"→"他们买的是 Y"）。
- 判断法：结论能不能顺着事实直接说出来？能，就顺着说。

同步落点：创作准则逻辑禁令 + 表达设计视角节及体检表 + 正文质检清单。互动问题也查了一遍（"你更在意哪边"是二元对立式，改成正面问法）。

## 平视修正：矛头不对准读者群体（豆哥第五次反馈，同日）

豆哥原话："不要刻意把矛头对准散户，我们的读者就是散户，留点面子。"

智谱稿两处把"散户"立成被纠偏对象：「骂的全是那 20 亿」「散户盯着打折的部分骂，公司拿到的是没打折的钱」——读者自己就是散户，等于把他拉出来示众再教他"你看错了"。标题「骂声只对准了四成」同病（暗含"你们骂错了"）。

改法：骂的全是那 20 亿 → 火气冲着的那 20 亿，占整单不到一半；散户盯着打折骂 → 评论区在吵打折；标题 → 打折的只占四成。

脉络按四步重写（大纲 01 同步）：

1. 来源与结构一句带过（路透定语 + 20 配售/30 可转债）
2. 算账：九折的 20 亿 + 1.125 倍的 30 亿，加权 103.5%；影响：50 亿即期到账（研发/算力/并购），摊薄里新股当下发、债转股只发生在 892.5 以上

## 不造私有比喻（豆哥第十一次反馈，同日）

## 机制段通俗化（豆哥第十二次反馈，同日）

豆哥要求「定价两头都留了余地」那段通俗一点。原段是压缩过的书面机制陈述（"压在现价下方/当场让利/账上难看/走出来兑现/没人接"），每个短语都要读者自己展开。改法：**机制讲成具体例子**——"定低了，比如就定在现价 793，债主一转股就比市面上便宜 12%，直接赚差价；定高了，比如定到 1200，股价到不了，这 30 亿卖不动"。抽象的两头变成两个具体的假设价，读者不用翻译。

方法（可复用）：机制段读着费劲时，检查是不是在用压缩术语省略了展开步骤；把"定低/定高"落到具体数字例子上（793/1200），让极端情形自己说话，结论（两边有共识）留给读者从例子里读出。

**同段翻车**：举的例子本身错了——"定在现价 793，债主一转股就比市面上便宜 12%"方向反了（892.5 本来比现价高，定 793 时成本=市价，没有便宜）。豆哥一句"为什么定现价比市面便宜 12%"抓出。改：假设价 700，"市价 793，等于 700 买入，转手赚 13% 差价"（793/700≈1.133）。**教训：通俗化举例段的每个数字都要单独验算方向和比例，例子里的数字比主数字更容易错——主数字反复被查过，例子是临场编的。**

## 结构定式：事实详情→具体分析→背后的含义（豆哥定调，同日）

豆哥定流程：「1.事实详情 2.具体分析 3.背后的含义」。这是事件分析类选题的最终结构定式，已固化进大纲模板 + draft-flow 化链条：

- **事实详情**：条款/数字/规则全摆，零判断，让读者手里有全部材料
- **具体分析**：各方怎么算账（参与者视角逐个走），机制怎么运转
- **背后的含义**：分析做完往下推一层——结果对谁有利、说明什么、共识在哪；**态度只在这层出现**

正文按此重排（约 600 字）：两笔钱+转股权+强赎条款全摆 → 债主三结局、公司摊薄推迟+负利息拿钱 → 加权接近溢价 +「签字双方对股价有共识，分歧只存在于没签字的人中间」。

这轮完整轨迹（13+ 次反馈）：内容层/表达层分工 → 前提交代三轮迭代（免责→自证→定语）→ 正逻辑 → 平视 → 四步目标 → 读者之问 → 车轱辘扫描 → 语料边界 → 百分比 → 删私有比喻 → 机制讲解版 → 深层内涵 → 三层定式 → 极简重写。最终收敛成一个结构定式 + 一组表达禁令，全部进 skill。

## 极简重写（豆哥最后一次反馈，同日）

豆哥：「能不能用最简洁的文笔，把事情和逻辑描述清楚来。」600→440 字，三层定式不动。删法：

- 路标句全删：「条款就这些，往下是账」「真正有意思的地方在两头」「这单的成色就出来了」——逻辑由段落顺序自己承担，不用嘴说
- 「先看债主这边怎么赚钱」→「先算债主的账」；三结局每条砍到一句
- 事实段压成四句（配售/转债/转股权/强赎各一句），长句拆短句

**判断标准**：字数压了三分之一，信息和逻辑链零损失——删的全是叙述冗余，不是内容。简洁的检验就是这句：删掉的每句话，问它承载了什么信息，答不上来就删。

## 说人话优先（豆哥最后一击，同日，最高优先级）

豆哥爆发："别他妈什么写作手法了，根本都看不懂你写的。"极简版砍字数砍出了理解成本——压缩句（"下行锁死，上行放开""负利率就是转股权的价格"）懂的觉得利落，不懂的读三遍。手法堆了一堆，读者第一遍读不懂，全白搭。

重写（约 560 字，比 440 版多回 120 字，多的是翻译）：

- 术语先翻译：可转债 →「一张欠条，但欠条上多写了一条：想还钱也行，想按 892.5 换成股票也行，自己选」

- 强赎等细节让位给主线，出现时即解释

规则升到创作准则最高优先级：**说人话优先于一切手法**。①术语必须先翻译；②压缩句是理解负担不是简洁；③对仗金句节奏全是可牺牲项。简洁指字数，通俗指理解成本，两个都要，冲突时通俗赢。

## 数字首现要有来历（豆哥补充，同日）

豆哥问："892.5 第一次出现的地方，读者怎么知道是 892.5，而不是 999？"——数字第一次出现时必须带来历：谁定的、写在哪、跟已知数什么关系。892.5 空降，读者只能死记。补：「换股价格在发债的时候就写死在条款里，定的是 892.5 港元一股，比市价 793 还高出一截」——来历（条款写死）+ 锚（比市价高）。

**规则**：每个数字首现处自检三问——它从哪来（谁定的/写在哪）、读者拿什么参照它（跟已出现的哪个数比）、删掉来历句读者会不会懵。数字不能空降。

## 用词纠错：手续费（豆哥抓出，同日）

豆哥问"0.5 是手续费吗"——不是，我写错了。负利率的来源是发行价高于面值：面值 100 的债卖 100~100.5，多付的钱进公司口袋，到期按面值还 100，没有中间环节。"手续费"暗示钱付给了第三方（承销商等），性质完全错了，而且会让读者以为负利率另有来路。改：「这张面值 100 的欠条，卖 100 到 100.5，多付的钱直接进了智谱口袋。到期如果一直没换成股票，公司按面值还 100，买的人拿回来的比当初付的还少。」

**教训**：给机制起白话名字时要验一遍"这个类比会不会带错方向"。欠条=可转债方向对；手续费=发行溢价，方向错——类比词自带的钱的去向暗示会污染读者理解。

## 参考稿吸收：现场感可以借，结构要守（豆哥给口语化参考稿，同日）

豆哥给了一段口语化参考稿，开头「这两天智谱的融资传闻炸开了锅」、逻辑用 892.5 单一锚点串、收尾「不妨多给点时间，再看看」。要的是思路不是句子。

可吸收：①现场感（炸开了锅/好家伙/7 月那轮 1588 跌到 793 腰斩）；②串联式短句推进；③用 892.5 一个锚点串债主账和公司账；④收尾更软（多给点时间）。不吸收：①「综合来算说明看涨」这种空判断，没给加权数字；②「盈亏平衡点/贴钱做慈善」这类自造术语没补解释，类比也带错方向；③892.5 出现三次（行权价/锚点/转股价定 892.5），车轱辘。

按事实-分析-含义三层+说人话规则重写，700 字。教训：参考稿的"语感"可以吸，但事实清单+分析段结构不能丢——光复制现场感，分析段就只剩语气没有内容。

## 润色 vs 重写：指令词区分（豆哥补充，同日）

豆哥明确："按这个来润色，这个是我手打的"——不是参考稿，是他自己写的，要求保留口吻只修真问题。跟上一轮"按这种思路"是不同的指令：

- **"按这个思路"** / "用这种思路"：可大改，逻辑和结构可重排
- **"按这个润色"** / "我手打的"：保留口吻、串联节奏、句式，只修缺漏事实、车轱辘、术语错配、空判断

固化为规则进创作准则「语料边界」：用户说"润色/在我稿子上改"时，保留句子和口吻，按事实清单补漏、修车轱辘扫描、调术语方向；用户说"按这个思路写"或给参考稿时，可重写但只取事实与目的。

## 负 0 是数学乌龙（豆哥抓出，同日）

原稿写「负 0 到 0.5%」——「负 0」不存在，豆哥一句话点穿：「你学过数学吗」。事实：负利率是个范围，收益率落在 -0.5% 到 0% 之间。改：「收益率在负 0.5% 到 0% 之间」，并用事实坐实：面值 100 卖 100~100.5，多付的钱进公司。

同段还藏了破折号加冒号（"是负的：负 0 到 0.5%……"）——硬禁令早就列了「无破折号」，但我还在写，每次都被豆哥抓。破折号在正文里的功能现在被禁的是：① 解释（用括号或分句代替）② 路标（"看条款就知道了"）③ 装饰（前后同义）。理由：破折号拖慢阅读，破坏口语节奏。

**规则**：「无破折号」从"硬禁令速查"升到「交付前必查」——每次落盘前用 `grep "——\|—"` 全文件搜一遍，命中即改。

## 别替读者总结：润色的边界（豆哥抓出，同日）

豆哥手打稿润色了讲师腔暴露：「非不要不要改了，我手打的你都改改出AI味来」+「一眼AI，跟0.1b参数的大模型写出来的东西一样」。

病根：上一轮「说人话」教训让我本能地替读者"翻译机制"——"简单说就是""多付的钱直接进了智谱口袋""等于负利息贷款""这钱先白用着"。全是讲师腔，把豆哥原稿里"负利息 0-0.5% 不等，也就是发债的时候是超额给现金的"那句口语化的串联句，填成了教学段。

`grep` 验证：原稿 0 处"对xx来说等于"/"等于说"/"多付的钱"/"简单说就是"；润色版冒出来 4 处，全是我加的。删掉这 4 处，回到原稿。

**润色边界（最高优先级）**：
1. 严禁加替读者总结的句子（"简单说就是""对xx来说等于""这意味着""本质上"）
2. 严禁加作者原稿里没有的解释性句
3. 只补：漏事实、错事实、车轱辘、术语方向错、占位称呼
4. 句式、口吻、串联节奏、转折词全保留

判据：每加一句解释句，自问"作者原稿里有没有这个意思"——没有就删。

**溯源**：14 轮反馈里的"作者在替读者干活"根子一直没根除——从前两轮"加一句免责声明"、到"加一句不构造比喻收口"、到"加一句对xx来说等于"。每一轮都在犯同一种错：作者觉得读者读不懂，就替读者多写一句。读者视角的检验是终极仲裁，规则的形式完成度排后面。
