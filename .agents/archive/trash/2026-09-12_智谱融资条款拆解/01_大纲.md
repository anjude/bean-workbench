# 大纲｜智谱融资条款拆解

## 一、选题方向

**拆题**：
1. 现象层：智谱（Z.AI）新一轮融资，整单约 50 亿美元，公司未正式公告，股吧/雪球吵的是"打折卖股"
2. 结构层：股和债反着来——20 亿美元配新股打九折，30 亿美元可转债零息负利率（发行价面值 100%~100.5%）、转股价 892.5 高出配售价 25%
3. 判断层：负利率的债还发得出去，说明债端买的是转股权不是利息；股小债大，加权后整单不是折价甩卖
4. 结论层：配售不等于稀释等于承压，这单条款走的是另一条路；未公告前别按最坏结果算

**最容易写歪成**：
- 写成情绪站队（替智谱喊冤 / 跟着骂收割）
- 凭空否定（"谈不上羞辱性折价"——没人说羞辱，自立靶子，已被豆哥抓过一次）
- 把加权口径当机构实际付款额（简化算法，正文标"粗账"或"按规模加权"带出）
- 滑向"机构认了=能买"的跟买暗示

**想表达什么（主判断，一句）**：负利率的债还能发出去，说明债端买的是转股权不是利息；股小债大，加权之后整单不是折价甩卖。

**写给谁**：在股吧/雪球被融资传闻点燃情绪、想搞清楚条款到底写了什么的散户

**一句话结论（中性）**：股票端打九折是小头，债端零息负利率、转股价高出配售价 25% 是大头，加权后整单接近溢价

**核心问题**：
- 倒贴利息的债为什么有人买
- 两笔钱合起来，这单到底算折价还是溢价

**标题草案**：
1. 智谱这轮融资，不是折价甩卖
2. 负利率的债都有人接，买的是什么
3. 智谱 50 亿融资：股小债大，越算越不像甩卖

**模式**：强判断

**边界**：不判断股价走势、不构成买卖指向；只拆条款结构，不做 Anthropic/DeepSeek 归因；语气收着，不冲锋

## 三、逻辑脉络

**脉络（推导链）**（豆哥定要点：股九折/债负利率 → 转股权溢价 25% + soft call 130% → 股小债大加权不是甩卖 → 负利率发得出去=买转股权 → 配售≠稀释≠承压）：
1. 读者刚听说"智谱融资 50 亿"，以为又是打折卖股 → 一句交代结构：20 亿股票打九折，30 亿债利息是负的，两头反着来 → 交出：债这半更怪
2. 负利率什么概念 → 发行价面值 100%~100.5%，收益率 -0.5%~0，借出去的钱还要倒贴 → 交出：换你买吗
3. 买的人图什么 → 转股价 892.5，比 714 的配售价高 25%，赌的是走到 892.5 上方之后的那一段 → 交出：要的是转股权，不是利息
4. 发行方怎么定的 → 定低了转股当场亏，定高了得真走出来才算数，定完还有人接，两头才对得上 → 交出：这个价是两边对出来的
5. 赎回线更高 → soft call 在 892.5 的 130% 即 1160 附近，连续 30 个交易日里 20 天站上去才能从 2027-02-18 起赎回，现价 793 差四成多 → 交出：公司给自己划的线比市价高得多
6. 合账 → 打折的股票是小头，溢价的债是大头，股小债大，按规模加权整单不是折价甩卖 → 交出：配售不等于稀释等于承压，这单走的是另一条路
7. 收口 → 公司和港交所都没公告，先别急着按最坏的结果算
