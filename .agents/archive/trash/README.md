# 豆小匠 Note

这是一个面向理财自媒体的内容管理库，帮助你完成从选题到发布的完整内容生产流程。

## 适用场景

- 账号定位：中产上班族视角的理财分享
- 内容方向：基金、ETF、股票、期权、保险、资产配置、理财误区、工资分配与家庭财务规划
- 主要平台：小红书、公众号
- 主要形式：图文为主，兼容短视频和口播脚本

## 目录结构

- `topics/`：唯一生产区，每篇选题一个目录，从选题到复盘不搬家；根只放当前月，往月按 `YYYY-MM/` 归档
- `knowledge-base/`：跨选题素材，长期可复用的理财知识
- `data/`：发布记录、数据分析、用户反馈
- `docs/`：项目说明、账号定位、内容手册

状态写在目录名前缀上：无前缀在制，`done-` 已发布，`drop-` 已归档。归档只换所在月份目录，不改目录名。

## 怎么开始

内容生产的规范由工作台 bn 系列 skill 承载，按交互回合走：选题与大纲 `bn-0000-outline-flow` → 成稿 `bn-0101-draft-flow` → 审稿 `bn-0201-review-flow` → 发布 `bn-0301-publish-flow` → 复盘 `bn-0302-retro-flow`。目录与状态约定见 `bn-tools-content-context`。

## 使用建议

- 一篇选题一个目录，路径只在跨月归档和发布/废弃时变化
- 按槽位推进，缺哪号就卡在哪步
- 不为完整流程造空文件
- 知识素材和具体内容分开，避免重复查资料
- 以人为本贯穿生产全过程：始终把受众当第一尊重对象，不为传播量设计钩子

## 项目规则入口

- `docs/项目说明.md`：项目是什么、东西放在哪（给接手的人看）
- `docs/账号定位.md`：品牌、人设、受众与内容边界
- `docs/content-playbook.md`：项目级内容创作手册与稳定规则
- `topics/索引.md`：全部选题的状态看板
