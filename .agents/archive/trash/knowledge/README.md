# 知识资料库

这里存放长期可复用的理财知识，是内容生产的"弹药库"。

## 存放内容

- 理财基础概念解释（ETF、复利、资产配置等）
- 产品知识（基金、保险、衍生品等）
- 数据来源和参考资料
- 常见误区和纠偏知识点
- 用户高频问题及答案

## 文件命名规范

格式：`主题_简述.md` 或 `主题_简述.xlsx`

- 使用中文，简洁明了
- 同一主题的多篇内容，可以放在同一文件夹内

例子：

- `ETF基础概念.md`
- `基金定投常见误区.md`
- `期权策略_wheel策略详解.md`

## 使用方式

- **内容生产时**：从本目录查找相关知识点，作为 `topics/日期_主题/03_正文.md` 的参考素材
- **复盘后**：将表现好的内容中提炼的知识点，补充到本目录
- **日常积累**：阅读、学习时有价值的内容，及时记录到这里

## 建议栏目对应知识方向

| 栏目 | 建议积累的知识 |
|------|----------------|
| 上班族理财入门 | 复利、资产配置、风险承受度 |
| 期权基础 | 期权术语、 Greeks、到期日计算 |
| Wheel 策略 | 行权价选择、theta 收益、保证金管理 |
