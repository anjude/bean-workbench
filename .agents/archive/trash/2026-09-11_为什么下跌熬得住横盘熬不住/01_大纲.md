# 大纲｜如何错过暴涨

## 主题分析

**拆题**：

1. 现象层：行情横住、赚钱效应弱，持有者把这段日子叫垃圾时间
2. 机制层：横盘不亏钱，浮亏停在那不动；亏损只在卖出确认那一刻成立
3. 人性层（主题核心）：下跌有故事可讲（等回本、骂行情），横盘连故事都没有；看盘喂即时反馈，反馈一断手就痒
4. 代价层：收益集中在少数不退出的时刻，换手是把自己从尾部事件名单里划掉；复利前慢后快——乱操作的后果，不是主题重心

**最容易写歪成**：

- 万能鸡汤：要耐心、拿住不动，没有判断维度
- 滑向利弗莫尔「等待是最难学的技巧」，和知识库预置角度撞切口
- 写成后市判断，变成时事文，违反只聊认知的定调
- 推成死扛就是对的，没有边界，变成变相持有建议

**想表达什么（主判断，一句）**：横盘比下跌难熬，不是因为横盘更危险，而是因为它拿走了两样东西——故事和反馈。下跌有故事可讲（等回本、骂行情），横盘连故事都没有；看盘喂即时反馈，反馈一断手就痒。乱操作不是判断力出了问题，是人在没有故事的行情里自己找刺激。

**脉络（推导链）**：

1. 读者在哪：行情横了一阵，账户没动静，难受，这段日子被叫垃圾时间（现象，非读者错觉）
2. 抛出疑问：为什么偏偏横盘最难熬 → 下跌有故事可讲，横盘连故事都没有（直接回答标题）
3. 深挖机制：看盘这个动作在喂即时反馈，反馈一断就忍不住要做点什么；亏损只在卖出确认那刻成立，浮亏停着不动
4. 递进到后果：手痒的代价——收益集中在少数不退出的时刻，换手是把自己从名单里划掉
4. 收口：代价讲完停在核心句，不另造收口段

## 选题判断

**写给谁**：有持仓、行情横住后坐不住想动手的普通人

**一句话结论（中性）**：横盘比下跌难熬，是因为它拿走了故事和反馈，人在没有故事的行情里会自己找动作

**核心问题**：

- 为什么横盘比下跌难熬（主题核心）
- 横盘期的乱操作从哪来

**标题草案**：

1. 如何错过暴涨（定稿，反讽式：暴涨错过的过程不在暴涨里，在横盘的每一次动手；正文落袋段和尾部事件段直接支撑）
> 备选：垃圾时间不亏钱，动手才亏；为什么下跌熬得住，横盘熬不住；市场没有垃圾时间，只有垃圾动作

## 核心内容摘要（生产闸门）

**定位**：写给横盘期坐不住、忍不住看盘和动手的持仓者

**结论**：横盘比下跌难熬，是因为下跌有故事可讲，横盘没有

**骨架**：

1. 横盘的难受 — 事实：行情横住、账户没动静、赚钱效应弱；写法：直接进现象，短句开场，沿用已试写口吻
2. 为什么偏偏横盘难熬（主题核心，直接回答标题）— 事实：下跌有故事（等回本、骂行情），横盘连故事都没有；写法：把两种行情的日常心态对写，不堆术语
3. 手为什么会痒 — 事实：看盘喂即时反馈，反馈一断就忍不住动作；写法：卡尼曼机制落到看盘动作上；顺手点破：亏损只在卖出确认那刻成立，浮亏停着不动
4. 手痒的代价 — 事实：尾部事件驱动一切、复利前慢后快；写法：豪泽尔两条撑底，落在核心句上直接收，不另造结尾观察
