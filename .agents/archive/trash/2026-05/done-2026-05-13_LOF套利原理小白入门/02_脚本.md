### 第 3 页（核心逻辑）

- 作用：解释为什么能套利，搞懂原理

```
为什么能套利？

按净值申购 → 按溢价卖出
差价就是利润

但要注意：
· 溢价率不够高，赚的可能连手续费都覆盖不了
· 申购T+3才到账，这段时间净值可能波动
· 基金持仓大跌，净值缩水，收益可能直接没了
```

### 第 4 页（为什么有溢价）

- 作用：讲清楚溢价来源，增加认知密度
- 文案：

```
二级市场为什么会有溢价？

场内申购有限额，而且不是T+0
部分投资者有即时买入的需求
所以愿意多花一点钱直接在市场上买

这个溢价，就由买卖双方自己消化
和基金本身的净值、规模没有关系
```

### 第 5 页（常见问题：净值怎么算）

- 作用：补充认知，让小白理解成本基础
- 文案：

```
Q：净值怎么计算？

场内申购的资金用于买入基金持有的资产
（股票、债券等）

基金净值 = （总资产 - 总负债）÷ 总份额

申购时的净值，就是我们的入场成本
后续净值涨跌，直接影响最终收益
```

### 第 6 页（常见问题：二级市场影响基金规模吗）

- 作用：打破误解，加深理解
- 文案：

```
Q：在二级市场买卖，会影响基金规模吗？

不会

二级市场的交易只是持仓人之间换手
溢价/折价部分由交易双方自己承担

只有场内申购/赎回，才会让基金规模变大变小
两件事完全独立
```
