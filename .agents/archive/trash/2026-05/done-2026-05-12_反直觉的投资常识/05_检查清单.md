# 发布检查清单

## 合规红线

- [x] 无推荐买入或卖出具体股票、基金、产品
- [x] 无具体收益率
- [x] 无保本保收益承诺
- [x] 无诱导开户或交易
- [x] 无把名人动作写成可跟随信号
- [x] 有免责声明

## 文风检查

- [x] 无第二人称"你"对读者下定义（结尾互动例外）
- [x] 无人设违规：豆小匠人设贯穿全文
- [x] 无纠偏式表达（别以为、不要以为、很多人会误以为）
- [x] 无主持人口吻强行转场
- [x] 无解释笑点或情绪
- [x] 无强行升华

## AI句式检查

- [x] 无自问自答（X管用吗？管用）
- [x] 无设问引导（为什么？因为...）
- [x] 无二元对立式概括（不是A而是B）
- [x] 无排比升华
- [x] 无定义式开头（所谓X，指的是...）
- [x] 无完美过渡（段落跳跃自然）

## 符号禁用检查

- [x] 无中文破折号、英文 em dash
- [x] 无角引号
- [x] 无滥用引号包裹关键词
- [x] 无装饰性项目符号

## 信息量

- [x] 每一段都有新增信息量
- [x] 没有垫话
- [x] 没有复述前文判断当结尾

## 爆款 5 维度

| 维度 | 检查 |
|------|------|
| 停 | 标题"跌了反而更安全"有反常识感 ✅ |
| 点 | 开篇直指投资痛点 ✅ |
| 留 | 前50字给冲突 ✅ |
| 值 | 三个反直觉常识的具体拆解 ✅ |
| 传 | 反人性、别跟烂公司谈恋爱等表达有争议性 ✅ |

## 标题

- [x] 3个备选标题
- [x] 标题有反常识感
- [x] 标题大胆不温吞

## 其他

- [x] 粗体3处
- [x] 结尾不重复前文，用轻互动收住
- [x] 公众号文章没有过度使用短句排比
- [x] 正文末尾附有精彩引言和封面 prompt
