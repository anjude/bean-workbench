# 大纲｜价值投资和长期投资的关系（长期持有是买入时的判断，不是买入后的承诺）

## 主题分析（讨论第一步，先于写法）

**主题与角度（两层分开）**

- **主题层（不变）**：价值投资和长期投资的关系。全文必须回答"两者什么关系、为什么被混为一谈"。
- **角度层（可换）**：切入角度、标题、开场都可以换。当前角度是"三个概念并排聊开（长期投资/长期持有/价值投资），顺着'下跌才做得到长期持有'这条线把价值投资的碰瓷揪出来"。
- **约束**：角度可动，主题不动。换角度只动开场和标题，落点仍须回到"长期持有是买入时的判断，不是买入后的承诺"。

**拆题**：三个概念分开，别搅在一起

1. **长期投资（参与时长）** — 股票要么不玩，要么玩了很难戒掉。做到长期投资很简单，顺着人性走就行，离场反而需要勇气。这个概念是铺垫，不是靶子。
2. **长期持有（持股时长）** — 反人性的那个：大部分人进场就想捞一笔开溜，最开始没有长期持有的想法；事实上也做不到，有数据。反差点：买入时信誓旦旦要长期持有，实际只有持续下跌才做得到"长期持有"，且这个长期也就两三个月。
3. **价值投资（买入时的判断）** — 被套的人拿来命名自己的被动持有。巴菲特"看十年"被截成半句用；完整版（不打算持有十年就不要持有十分钟）恰恰堵死了这条路：下跌拿十年、上涨拿十分钟，是碰瓷。
4. **为什么承诺守不住（机制）** — 看不懂。十年太久，谁能看清。由此引出尺度问题。
5. **看多远（尺度论证）** — 三天看情绪资金，三年看业绩周期，全是需要猜的因子；十年把这些过滤掉，只剩结构性问题（需求、定价权、会不会被绕开），方向对就立得住。模糊的正确 vs 精确的错误。

**最容易写歪成**：

- 概念科普：只讲"三者定义不同"，没有判断
- 语录汇编：堆巴菲特/段永平金句，没有主判断
- 说教"捞一笔就走"是错的：不批判动机，只指出下跌时的自我命名是碰瓷
- 数据口径混用：45.96% 是**单只基金持有期**（持股时长），本文讲的正是持有期，口径匹配；但引用必须写明报告年份与口径，不外推到"参与时长"
- 荐标的：点名买卖

**想表达什么（主判断，一句）**：

> 长期持有是买入时需要判断的事情，而不是买入后履行的承诺。只打算下跌时拿十年、上涨时拿十分钟，不是价值投资。

**脉络（推导链）**：

1. 三个概念并排开场（长期投资/长期持有/价值投资）→ 股票要么不玩要么戒不掉 → 长期投资顺着人性，简单，离场才需要勇气 → 交棒：长期持有呢
2. 长期持有反人性：进场都想捞一笔开溜 → 事实上也做不到，数据（45.96% 不到 3 个月）→ 交棒：但买入时明明信誓旦旦
3. 有意思的现象：信誓旦旦要长期持有，实际只有持续下跌才做得到，且只有两三个月 → 交棒：被套的拿着不动，需要个名字
4. 巴菲特"看十年"被截半句用：被套了一直拿，当价值投资好了 → 完整版堵死这条路：下跌拿十年、上涨拿十分钟是碰瓷 → 交棒：为什么承诺守不住
5. 机制：长期持有是买入时的判断，不是买入后的承诺 → 承诺守不住的原因是看不懂，十年太久沧海桑田 → 交棒：那换个问题，到底看多远容易
6. 尺度论证：十年 vs 三年 vs 三天 → 三天考情绪、三年考变量（都要猜）、内幕消息反问 → 十年过滤掉要猜的因子，只剩结构问题，方向对就立得住 → 交棒：所以
7. 收：看十年是模糊的正确，看三天是精确的错误 → 不打算待十年就不要待十分钟；打算待十年，用长期主义对抗短暂的迷雾

## 选题判断

**写给谁**：进场想捞一笔、被套后拿"价值投资"给自己做解释的人。

**一句话结论（中性）**：长期持有是买入时需要判断的事情，不是买入后履行的承诺；被套硬拿不是价值投资。

**核心问题**：
- 长期投资、长期持有、价值投资三个概念到底差在哪？
- 为什么信誓旦旦的长期持有，最后都变成下跌时的被动硬拿？
- 看十年、三年、三天，哪个是模糊的正确，哪个是精确的错误？

**标题草案**：
1. 想在股市待一辈子的人太少了，基本都是想着捞一笔就走（主推）
2. 只打算下跌时拿十年，上涨时拿十分钟，就别碰瓷价值投资了
3. 长期持有是买入时的判断，不是买入后的承诺

## 核心内容摘要（生产闸门）

**定位**：进场想捞一笔、被套后拿"价值投资"给自己做解释的人

**结论**：长期持有是买入时需要判断的事情，而不是买入后履行的承诺。只打算下跌时拿十年、上涨时拿十分钟，不是价值投资。

**反差**：买入时信誓旦旦要长期持有的人，实际只有持续下跌才做得到"长期持有"，而且这个长期也就两三个月。

**骨架**（与正文一一对应）：

1. 概念开场 — 三个词直接并排聊开，不设场景钩子；断言打底："股票这东西，要么不玩，要么玩了就很难再戒掉了"。
2. 长期投资简单 — 顺人性，离场才需要勇气。两三句带过，是铺垫不是靶子。
3. 长期持有难 — 进场想捞一笔；数据：景顺长城/富国/交银施罗德《公募权益类基金投资者盈利洞察报告》（2021，4682 万客户 5.65 亿笔交易）45.96% 不到 3 个月、61.6% 不到半年、11.46% 超过 3 年；信誓旦旦 vs 下跌才做得到、且只有两三个月。
4. 价值投资被碰瓷 — 巴菲特"看十年"截半句用 → 完整版"不打算持有十年就不要持有十分钟" → 下跌拿十年、上涨拿十分钟是碰瓷 → 加粗句"长期持有是买入时需要判断的事情，而不是买入后履行的承诺"。
5. 为什么守不住 — 自问自答：看不懂，十年太久沧海桑田。
6. 尺度论证 — "思考个问题"起：三年 vs 三天 → 三天情绪资金、三年业绩周期都要猜 → 内幕消息反问（连对象今天干了啥都查不到）→ 十年过滤因子剩结构问题（需求/定价权/被绕开），方向对就立得住 → 加粗句"看十年是模糊的正确，看三天是精确的错误"。
7. 收尾 — 不打算在股市待十年就不要待十分钟；打算待十年，用长期主义对抗短暂的迷雾。不批判捞一笔就走。

**锚点**：巴菲特"十年/十分钟"（完整版 vs 截半句）；《公募权益类基金投资者盈利洞察报告》数据。段永平作为这句话的流传推手可提可不提，不展开其持仓与卖出标准（已从本版剔除）。
