# 文章公共模块

## 免责声明

用户约定：**每篇文章都必须附带一份单独的 `置顶留言.md`，其中包含免责声明和风险提示。** 这是所有题材的必备交付，不因文章主题看起来没有明显风险而省略。留言文案供用户复制到留言区置顶，不放在文章正文、排版输入、预览或公众号 HTML。正文只写对读者有用的信息，直接推进主题；按文章题材补充具体风险。

- 每篇选题创建或更新 `发布稿.md` 时，同时检查并创建/更新同目录的 `置顶留言.md`；README 标注该文件。未生成留言文案时，不算完成本轮文章交付。
- 置顶留言至少包含通用免责声明和与题材相符的风险提示；没有额外专项风险时，也保留通用风险提示，不得因此省略文件。
- 免责声明只进入单独的置顶留言文案，不进入发布稿、排版输入、预览或公众号 HTML。
- 正文（包括插图文案）禁止出现免责声明及明显变体，如「不代表未来收益」「不构成投资建议」「仅供参考」「不能保证」等。交代来源、计算条件或估算假设即可，不重复加自我免责提示；具体风险作为正文论述时，写清事实和影响，正式风险提示仍放在置顶留言。
- 正文只保留理解论述所需的来源说明和必要归因；原文链接、完整出处、参考资料或延伸阅读等对正文论述没有直接帮助的内容，统一放入置顶留言。正文确有必要提及来源时，简洁说明一次即可。
- 正文保留理解论证必需的计算条件，如收益率、复投方式、是否追加本金；完整假设和复算依据继续保存在主题 source/。
- 内容上的事实、适用条件和必要的区别仍须表达准确；不能靠置顶留言支撑正文中的保证收益或固定年限爆发等错误结论。
- 按文章题材填写相关说明，不给无关题材机械添加投资风险文案，也不自动宣称免责声明具有法律免责效力。投资主题应针对文中实际做法，逐点说明可能亏损的原因、限制与成本，避免笼统写一句“投资有风险”。

投资演算类可采用以下模板，并按实际采用的假设调整：

> 本文仅作个人思考与知识分享，不构成具体投资建议。文中收益率为演算假设，不代表任何产品的预期或承诺收益。计算未考虑的费用、税费、通胀等因素应据实说明；本金规模或持有年限不保证相应收益。实际投资收益会波动，也可能亏损，请结合自身资金用途和风险承受能力独立判断。

置顶留言以独立标题和分点正文呈现，语气直白、易读，方便单独复制发布。适用于所有题材的基础文案如下，按实际主题补充具体风险，不要机械添加无关投资说明：

> **免责声明**：本文为个人观点与信息分享，不代表任何机构立场；内容仅供参考。
>
> **风险提示**：文中信息可能不完整或发生变化；涉及争议性事实、第三方报道或具体决策时，请核对可靠来源并独立判断。


## 开头自我介绍

公众号文章默认以这句作为开头自我介绍：

> 哈喽，这里是豆小匠的笔记。

允许根据文章主题微调措辞，但保持简短、自然，仍完成自我介绍，不额外扩成长铺垫。

## 排版固定头尾

公众号排版默认在文章外层注入账号固定头尾：头部含关注引导和公众号名片；尾部含「鹅懂个啥」小程序卡片、结束标记与点赞提示。它们由 `bn-tools-format-flow` 模板维护，不写入选题的 `发布稿.md`；头尾规则和显示限制见排版 skill 的 [布局说明](../../bn-tools-format-flow/references/layout.md)。
