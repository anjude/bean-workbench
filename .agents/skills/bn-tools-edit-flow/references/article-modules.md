# 文章公共模块

## 免责声明

用户约定：免责声明统一放在留言置顶，不放在文章正文。正文只写对读者有用的信息，直接推进主题；风险、收益不确定性、费用和非投资建议等另写成分点清楚的置顶留言。

- 免责声明只进入单独的置顶留言文案，不进入发布稿、排版输入、预览或公众号 HTML。
- 正文保留理解论证必需的计算条件，如收益率、复投方式、是否追加本金；完整假设和复算依据继续保存在主题 source/。
- 内容上的事实、适用条件和必要的区别仍须表达准确；不能靠置顶留言支撑正文中的保证收益或固定年限爆发等错误结论。
- 按文章题材填写相关说明，不给无关题材机械添加投资风险文案，也不自动宣称免责声明具有法律免责效力。投资主题应针对文中实际做法，逐点说明可能亏损的原因、限制与成本，避免笼统写一句“投资有风险”。

投资演算类可采用以下模板，并按实际采用的假设调整：

> 本文仅作个人思考与知识分享，不构成具体投资建议。文中收益率为演算假设，不代表任何产品的预期或承诺收益。计算未考虑的费用、税费、通胀等因素应据实说明；本金规模或持有年限不保证相应收益。实际投资收益会波动，也可能亏损，请结合自身资金用途和风险承受能力独立判断。

置顶留言以独立标题和分点正文呈现，语气直白、易读，方便单独复制发布。


## 开头自我介绍

公众号文章默认以这句作为开头自我介绍：

> hello，这里是豆小匠的笔记。

允许根据文章主题微调措辞，但保持简短、自然，仍完成自我介绍，不额外扩成长铺垫。
