# 正文质检清单

> 只放交付前检查项，不放写作准则，不放模板。

## 文件检查

- [ ] 主题目录使用 `{状态前缀}YYYY-MM-DD_主题简述`，当前月在 `topics/` 根，往月在 `topics/YYYY-MM/`
- [ ] `04_发布稿.md`（或 `02_脚本.md`）开头包含选题判断区（写给谁、一句话结论、核心问题、标题定稿）
- [ ] 公众号：有 `01_大纲.md`、`04_发布稿.md`、`05_检查清单.md`；`06_复盘.md` 仅在有用户反馈或规则沉淀时写
- [ ] 小红书图文：有 `01_大纲.md`、`02_脚本.md`、`03_正文.md`、`05_检查清单.md`；`06_复盘.md` 同上
- [ ] `manifest.yaml` 的 `slots` / `next` / `status` 已同步到本轮实际进度，索引已重跑
- [ ] 额外脚本、跨平台正文只在需要时生成

## 硬禁令（不通过就重写）

- [ ] 正文无第二人称"你"（互动问题可例外；选题区不计入）
- [ ] 无中文破折号 `——`
- [ ] 无英文 em dash `—`
- [ ] 无角引号 `「」` `『』`
- [ ] 无装饰项目符号 `•` `·`
- [ ] 无用引号包裹关键词或术语
- [ ] 无一句话里自相矛盾（不左右互搏）
- [ ] 无无意义平衡句（"当然是好事"、"这本身没问题"、"并不是坏事"）
- [ ] 无和稀泥句式（"谁对？都对"、"各有道理"、"只是场景不同"）
- [ ] 无空洞感慨（"这个坑踩过的人不少"、"很多人吃过亏"类无信息量垫话）
- [ ] 无凭空否定：对文中没出现的负面判断做否定（如"不是补窟窿"），属预设对立
- [ ] 无保本保收益承诺、"稳赚""无风险"等绝对表述
- [ ] 无直接喊买/卖具体标的
- [ ] 无开户或交易诱导
- [ ] 已保留免责声明

## 受众检查（把读者当目的，不是当流量；易接受、有收获，不强行灌输）

**没有爆款维度，只有"值不值得这个人花时间"。** 不要求每篇都教会读者什么，只要求把内容摆得容易接受、读完有收获感。以下每项都要过：

- [ ] 标题是真实判断或真实问题，无夸张恐吓 / 制造焦虑 / 数字 shock 无实质；标题承诺的，正文真的给了
- [ ] 开头不慢热，但慢热的代价由信息顺序决定，不靠倒挂结论或话术钩子——**没有为了留人而设计的悬念**
- [ ] 全文没有一处利用焦虑、恐惧、贪婪、稀缺感（"再不看就晚了""99% 的人不知道"）
- [ ] 没有把读者当傻子：不预设他不懂、不预设他想错了、不给他编一个他不持有的自我认知
- [ ] 现象写成现象：群体现象直接陈述，没有写成"你以为…""很多人误以为…""其实你只是…"（把事实降级成读者的错觉）
- [ ] 有主判断，不是资料摘要或温吞科普
- [ ] 精彩引言是从正文长出来的判断，不是为了截图而造的句子
- [ ] 读完有收获感：看懂了一件事、多了一个看问题的角度、或知道某个说法的来历——**不要求教会什么、不要求改变行为**（合规红线那条判据同样适用）
- [ ] 读者的疑问在文中被按顺序接住：每一步的推进都从上一步的答案里长出来，没有跳跃、没有强塞
- [ ] **没有强行灌输**：全文无"你应该/你要/记住/从今天起"式指令句（操作类必要步骤除外）、无文末"所以我们要…"式代总结段、无为讲道理硬加的升华段或忠告段；该停的地方停住了

## 信息量检查

- [ ] 每段都有新增信息量（新事实/新观察/新判断/新例子/新情绪）
- [ ] 强表达后面有事实、例子、数据、方法或边界支撑，不是空喊口号
- [ ] 至少有一个具体支撑物：数据、案例、场景、类比、框架、步骤、边界
- [ ] 读者看完能带走点什么（一个看问题的角度、一个说法的来历、或一个判断方式），不是只记住一句结论——**不要求带走行动方案**

## 文风检查（去AI味，不去个性化）

- [ ] 没有解释笑点或解释情绪
- [ ] 没有"表面看...往深一点看..."等升华模板
- [ ] 没有三段以上同动词排比（"变了X，变了Y，变了Z"）
- [ ] 没有升华式段尾（"X是Y的轮廓/缩影/注脚"）
- [ ] 没有主持人预告句（"X是一个分界线/转折点/里程碑"）
- [ ] **活人感：像一个人在边想边说，不是念提纲**——至少有思考痕迹（敢下断言先断后收／思考路标"有意思的是""思考个问题"／自问自答答得干脆／推进型反问），念提纲的段落重写；加"我"和语气词不算活人感，思考才算（见创作准则「活人感是思考带来的」）
- [ ] 结尾无空总结（整节只是在换句话复述前文→整节删掉）
- [ ] 粗体 3-5 处（小节标题加粗不计入），不泛滥
- [ ] 自述占比不过高（"我"字全文不超过3次，人设开场白除外）
- [ ] 无"在这个X时代""毋庸置疑""首先其次最后"模板"它不仅更"等AI套话
- [ ] 每条通过都附了原文行号或片段作为证据，不是空打勾（硬证据）

## 自进化检查

- [ ] 用户反馈已先落实到当前稿
- [ ] 已判断本次问题是一次性修改还是规则盲区
- [ ] 如属规则盲区，已同步更新 memory、skill 或 references 中对应文件
- [ ] 当前主题 `06_复盘.md`（仅在有用户反馈或规则沉淀时）已记录用户反馈和规则沉淀

## 数字与事实源（逐条附证据，不通过就删数字或改说法）

数字是这类内容唯一不能靠文风救的地方。写进正文的每个数字都要过一遍：

- [ ] 每个数字都能指到具体来源：机构 / 报告名 / 发布年份 / 样本区间，缺一项就补或删
- [ ] 同一指标存在多套口径时（不同机构、不同样本年份），取一版为主并在正文注明区间，另一版最多作对照，**禁止混用两版数字**
- [ ] 引用的统计报告已注明数据截止日期，不把历史统计说成当前状态
- [ ] 案例型数字（持仓股数、金额、时间跨度、涨跌幅）与原始披露一致，不取整到失真
- [ ] 用作类比或体感压缩的说法（如"十个人里九个"）与原数据方向一致，没有夸大一个量级
- [ ] 用于说明机制的案例，只用于该机制，不外推成对某个标的的判断

## 发布前确认

- [ ] 标题最终确定
- [ ] 事实源日期和说法已核对
- [ ] 如使用媒体截图或引用，来源清楚
- [ ] 留言引导不使用"你是不是也..."这类AI句式
