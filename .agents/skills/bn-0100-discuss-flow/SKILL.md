# 讨论（01 阶段）

## 这一步解决什么

主题只是一个词，答案还不齐。这一步只把问题问全、把答案查实。

| | |
|---|---|
| 输入 | 已初始化的 topic |
| 输出 | 问题清单 + 每个问题的答案（带出处） |
| 停下等什么 | 用户决定往哪走 |

## 步骤

1. **提问**：最基本的问题先问齐——它是什么？为什么现在值得关注？谁在参与、各自图什么？以前发生过吗、结果怎样？问到没有明显缺口为止。
2. **找答案**：一手源优先。答不上来的标"待核"，不用猜的填。答不上来的就如实说答不上来。

**到此为止。** 判断哪些问题有意思、哪些必须解释、选哪个方向，是用户的事。

## 问题往哪问

讨论阶段是**读厚**，问题要往事实和素材问，不是往判断问。问早了收敛，后面没得读薄。

- **从第一性原理问起**：它物理上是什么、从哪来、怎么变成现在这样。不从金融属性问起。
- **要数字，不要形容词**：产量多少、总量多少、结构占比多少、大头在哪。答不出数字就是没查到位。
- **多方视角并列**：散户 / KOL / 机构 / 国家，各自怎么看、各自的立场和思维是什么。
- **要事件和故事**：近几年有什么出圈的事，相关公司和矿区有什么有意思的事。素材够了角度才有得挑。
- **落到可执行**：普通人怎么参与、有哪些渠道、相关资产跟它是线性还是非线性关系。
- **问模型差异**：它跟别的大宗商品、跟公司估值，定价逻辑差在哪。

## 产物

- `source/`：查到的原始素材。命名 `{序号}-{来源}-{内容}.md`，文件头写来源 URL、数据口径、抓取时间。**要丰富、要严谨**：表格照抄原文不加工，写清样本区间与统计方法，原报告的自我限定照抄，口径冲突集中列清单。
- `01-1-问答录-{主题}.md`：**要通俗**。只放结论——问了什么、答了什么、哪些没答上来，末尾指向 `source/` 里的原始件。术语换成大白话，能不出现相关系数、R² 就不出现；必须给数字时配一句人话解释。
- `01-2-素材-{主题}.md`：用户点名要收的才放。agent 不自行往里塞。

**原文进 source，结论进槽位文件。** 槽位文件不膨胀，事实可追溯。

大纲槽位（`01-3-`）的用途待定，**用户没说之前不动它，也不替它规划结构**。

**不做归类，不做筛选，不提前规划后面的环节。**

## 规则

- **只提问和回答**。不评价哪个问题有意思、哪个答案重要、选哪个方向。
- **不超前规划**。后面的环节（大纲怎么写、正文什么结构）等用户说，不提前替它定结构、定字段。
- 事实标出处，二手数字回到一手源核过才用。
- 答不上来的如实说答不上来，不用模糊表述糊过去。
- 默认留在对话，用户说写入才落盘。

## 走偏信号

- 开场就谈"怎么写更有冲击力""用什么案例砸"
- 主动给问题归类、给答案排优先级、推荐某个方向——越界了，判定权不在这一层
- 替后面的环节做规划（"大纲应该分几块""正文结构可以这样"）——用户没说就不做
- 问题偏判断不偏事实（问"值不值得写"而不是"总量是多少"）
