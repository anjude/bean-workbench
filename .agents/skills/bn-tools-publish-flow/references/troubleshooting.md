# 接口排障

| 错误码 / 现象 | 判断与处理 |
| --- | --- |
| 40164 | 按微信报错显示的出口 IP 配白名单；代理出口可能随目标主机不同，不以通用 IP 回显站代替 |
| 40007 | 素材 ID 无效；既往本账号因 draft/add 缺封面复现，先核对 thumb_media_id 是否来自当前账号且有效，不能一律断定为缺封面 |
| 40013 / 40001 | 核对账号、凭证与 token；不要将凭证打印到日志 |
| 48001 | 该接口未授权，核对账号后台实际能力；草稿、发布提交、群发分别判断 |
| 45009 | 配额或频率限制，停止反复重试 |
| 超时或回执 pending | 请求结果未知，先查后台是否已经生成草稿或发布任务，避免重复写入 |
| 返回 publish_id | 仅代表受理，继续查 freepublish/get 或在后台核对公开状态与文章链接 |

历史上该机器曾出现「微信 API 与通用 IP 查询站出口不同」；不要把历史具体 IP 固化成新机器配置。

封面与正文图片是两种接口：`material/add_material?type=image` 返回永久素材 ID，`media/uploadimg` 返回正文图片 URL。封面裁成当前展示位比例不能替代素材上传。素材权限、尺寸和接口规则变化时以平台实际响应及官方文档核对。
