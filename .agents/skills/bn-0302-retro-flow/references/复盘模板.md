# 文章复盘模板

## 使用说明

对单篇文章进行结构化复盘，提炼可复用经验，识别待改进点。

输入：文章文件路径（`topics/[YYYY-MM/]done-{日期}_{主题}/04_发布稿.md`）
输出：复盘写入同篇的 `06_复盘.md`，不复写到别处

### 3. 读者收获感评分（不评传播量，不评"教会了多少"）

读者是目的，不是流量。不要求每篇都教会他什么或改变他的行为，只评：内容摆得容不容易接受、读完有没有收获感。不评有多少人看、多少人转。

| 维度 | 评分 | 说明 |
|------|------|------|
| 读得下去（易接受：顺序顺、门槛低、不绕、不装） | ⭐⭐⭐ | |
| 有收获感（看懂了一件事 / 多了一个角度 / 知道某个说法的来历） | ⭐⭐⭐ | |
| 被尊重（没被当傻子、没被焦虑裹挟、没被下指令） | ⭐⭐⭐ | |

注意：本项**不设"用"维度**——不评估读者有没有因此改变行为或拿到行动方案，那是灌输不是内容。

发布后数据（阅读、点赞、在看、留言）另设一栏只做**记录**，不评分、不设目标，仅作"被读懂没有"的旁证。
