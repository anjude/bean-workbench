# 模板合集

> 模板是骨架，不是枷锁。按内容自然调整，不要为了填模板制造段落、页数或文件。

## 默认文件组合

### 公众号文章

每篇一个文件夹 `YYYY-MM-DD_主题简述` 自闭环，不再分待生产/已发布/归档状态。默认只需要（复盘.md 仅在有用户反馈或规则沉淀时写，无则省略）：

- `公众号文章.md`（含选题区 + 正文）
- `发布检查清单.md`
- `复盘.md`

按需增加：

- `图文脚本.md`：需要拆成小红书图文
- `纯享正文.md`：需要跨平台复制版

### 小红书图文

默认需要：

- `图文脚本.md`
- `纯享正文.md`
- `发布检查清单.md`
- `复盘.md`

页数按内容自然决定，通常 4-8 页，不强行凑 6 页。

## 选题卡（话题池阶段）

话题池阶段的灵感沉淀。进入生产后不再单独保留，选题判断融入正文开头。可详可略，但「主题概览」的写法方向建议给到，避免进生产后死板或跑偏。

```markdown

## 基本信息
- 选题名称：
- 内容形式：（公众号文章 / 小红书图文 / 中性，暂定）
- 当前阶段：话题池（选题卡）
- 数据核验日：

## 写给谁
（一句话，别写「所有人」）

## 一句话结论（中性）
（选题卡阶段用中性表述；态度版最狠结论留到「核心内容摘要」）

## 核心问题
- 

## 三个标题草案
1. 
2. 
3. 

## 主题概览（事实 + 写法方向，定调不写正文）
**全篇写法定调**：（用哪句误解做钩子、什么体感、素材尺度；具体，不写空话）

### 1. <小节主题>
- 事实：（中性要点）
- 写法：（具体到用哪个例子、什么手法、避什么坑；只定调不写正文）

### 2. <小节主题>
```

> 主题概览每节先列事实（中性、可复用），再附「写法」一行：具体到本文要用什么素材、什么手法、避开什么，只定调不写正文。选题卡阶段结论用中性，态度版最狠结论留到「核心内容摘要」。

## 核心内容摘要（生产前确认门固定格式）

生产前确认门专用。字段顺序固定，方便一眼判断走没走偏。不要在字段间加解释段落。**骨架**字段内部可分行，每节一行。

```markdown
# 核心内容摘要｜<选题名>

**定位**：写给谁（一句话，别写「所有人」）
**结论**：强判断模式 = 本文一句话结论，最狠的那句、要有态度；事实流模式 = 事实陈述 / 核心机制，不强求态度、可开放收束
**反差**：反常识 / 钩子，最反直觉的一点（事实流模式可弱化为「事实本身的张力」）
**骨架**：
1. …（每节解决什么，含至少一种支撑物）
2. …
3. …
4. …
5. …
**锚点**：用哪些熟悉标的替代抽象（茅台 / 腾讯 / 英伟达 …）
**边界**：不点名 / 只机制观察 / 留免责声明
**核实**：发布前必须查的最新事实（数据 / 案例）

> 模式说明：默认强判断模式（结论须最狠、有态度）。若选题走「事实流模式」（用户要求少判断、给事实、让时间证明），结论字段改为「事实陈述 / 核心机制」；「结论含糊没态度」「骨架只是资料罗列」两项降级为可选，其余走偏信号仍生效。

**走偏信号**（命中任一项先改摘要再确认）
- 强判断模式专属：结论含糊、和稀泥、没态度（如「值得关注」「未来可期」）
- 反差缺失或落入俗套（如「到了年纪要注意这些坑」三段式）
- 强判断模式专属：骨架只是资料罗列、没有判断维度
- 边界写不清（点名具体公司 / 没提免责声明）
```

固定顺序即检查顺序：定位错、结论飘、反差无、骨架散、边界糊，任一项不对就是走偏，先改摘要再确认。
