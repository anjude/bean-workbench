# 小红书内容研究与预发布

用于「鹅懂个啥」小红书内容生产：从公开笔记中学习表达与视觉形式，保存有参考价值的素材，整理自己的图文包并完成人工发布前检查。内容决策由运营者完成，采集项目不是数据授权。

## 工具分工

| 用途 | 工具 | 使用边界 |
| --- | --- | --- |
| 搜索并采集笔记、评论 | [MediaCrawler](https://github.com/NanmiCoder/MediaCrawler) | 许可证为非商业学习使用；限少量学习研究，不做大规模采集或商业用途。使用前阅读仓库当前 LICENSE。 |
| 保存人工选中的笔记图文 | [XHS-Downloader](https://github.com/JoeanAmier/XHS-Downloader) | GPL-3.0；用于下载人工筛选的公开作品素材。尊重作者版权，不把下载素材直接当作自有内容发布。 |
| CLI 搜索、阅读与账号操作 | [xiaohongshu-cli](https://github.com/Apageoflove/xhs-cli-xiaohongshu) | 仓库没有 LICENSE 文件；不复制、安装或运行其代码。README 所列操作包含互动和发帖，并非仅保存草稿的预发布能力。获得明确授权并确认权限后再重新评估。 |

具体功能、许可证和适用边界以工具仓库当前版本为准，见 [工具说明](references/tools.md)。

## 研究步骤

1. 先由运营者给出主题、关键词或待研究的具体问题；不自动决定内容方向。
2. 用 MediaCrawler 小规模检索公开笔记和评论，只保留与这次内容问题相关的样本。优先使用项目支持的 JSON、JSONL 或 CSV 输出，避免建立长期全量数据集。
3. 对每条样本记录来源链接、采集日期、标题/正文、互动数（若工具提供）、相关评论和需要复核的上下文。账号名等无关个人信息不进入长期研究记录。
4. 运营者从结果中挑出少量有价值的帖子，再用 XHS-Downloader 保存需要观察的图片。记录来源链接，不移除原作者标识，不将其图片直接拼进自有发布成品。
5. 学习内容结构、封面信息层级、叙述节奏和评论讨论点；自有帖子需重新写作并使用有权使用的图片素材。
6. 将自有内容放入 [鹅懂个啥小红书图片工坊](../../../task/dev-flow/261010_gknow-content-studio/local-studio/README.md) 的 Canvas 模板，人工编辑标题、页面文案与视觉素材，导出 PNG/ZIP。

## 预发布准备

预发布包包括：最终标题、正文、话题、图片顺序、入口引导语、素材来源记录和人工检查结果。保存在当前内容生产任务目录，图片由图片工坊导出。

公开发布仍由运营者在小红书官方入口完成。当前不从 skill 调用非官方 CLI 发帖，不自动点赞、评论、关注或删除；用户明确指定一条已审定稿件并要求公开发布时，再按平台可用的官方入口逐项执行。

## 数据和发布边界

- 仅处理少量、与当前研究问题直接相关的公开内容；不采集私信、非公开账号内容或敏感个人信息。
- 不使用代理池、指纹伪装、验证码规避等方式绕开平台限制；遇到登录验证、访问限制或频率限制就停止。
- 不把抓取结果当成代表性调查或男女统计结论；样本只用于内容形式学习，发布文案不得编造用户反馈或平台数据。
- 不将原帖截图、图片、评论全文或用户身份信息直接用于公开内容；摘录、引用和二次使用前由运营者确认来源、授权与平台规则。
- 每轮研究完成后保留精选样本和来源链接即可；不默认长期保存完整采集数据库。
