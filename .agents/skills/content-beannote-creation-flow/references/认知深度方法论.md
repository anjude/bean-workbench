# 认知深度方法论（认知类 / 争议类选题专用）

> 适用：选题是「X 是不是 Y」「X 到底怎么看」这类带判断张力的议题（如「存储是不是周期股」「理财越早越好吗」「XX 是不是护城河」）。
> 目标：让文章显出「作者真想过」，而不是堆术语、甩金句、或玩伪辩证。本篇方法来自「存储到底是不是周期股」一稿的多轮打磨，已验证有效。
> 配套硬红线见 `创作准则.md`（尤其「无先抛结论再自己反驳」）。本文件只讲「怎么做深」，不重复禁令。

认知深度 = 拆得开 + 接得住质疑 + 结论自然浮现。三者缺一不可。

---

## 方法一：先拆后判（不要直接答二元题）

二元题（「是 / 不是」）先天有误导性，直接答一定是浅的。先把被判断的对象拆成几个成分，分别判断，再合起来看。

- 浅写法：直接答「存储是周期股」或「存储不是周期股」。
- 深写法：把存储拆成 **commodity DRAM/NAND**（同质可互换、价格接受者 → 周期属性）和 **HBM / 先进封装**（绑 GPU、长协锁产能、全球仅两三家具稳定供货 → 成长属性），分对象判断，结论自然浮现「周期打底、成长叠 buff」。
- 操作口诀：遇到「X 是不是 Y」，先问「X 能不能拆成几种赚钱方式」，能拆就别直接站队。

好处：拆开后读者自己能归类，作者不用替他下结论（也契合事实流模式）。

---

## 方法二：透镜堆叠（一层不够深就叠一层）

当一个分析层次显得浅，不要换话题，叠下一层分析透镜，直到不再浅。

本篇的透镜链（可复用为模板）：

1. **标品 / 非标品透镜**：决定有没有定价权。同质可互换 = 价格接受者 = 周期；定制绑定 = 定价权 = 成长。
2. **护城河透镜**：技术 / 资本 / 规模只是「原材料」，不是护城河本身；护城河 = 当这些原材料转化成**切换成本、客户锁定、规模成本优势、持续迭代能力**时的结构性优势。
3. **阶段性稀缺透镜**：连最像成长的那块（HBM 溢价），本质也是「眼下稀缺的租金」，会随产能和进入者跟上而收敛、褪色。

操作口诀：写完一段自问「这层还能再往下拆吗」，能，就叠一层透镜。每次用户指出「你这结论太浅」（如「护城河真的高吗」「技术是护城河吗」），几乎都是在提示：该叠下一层透镜了。

---

## 方法三：接住读者质疑（显出「想过」，区别于伪辩证）

让认知显深的最有效一招：把读者读到这**自然会问的反问**，直接在正文里抛出来并答掉。读者一看就知道作者预判了这些坑。

- 本篇实战：讲到 HBM4 护城河，主动接住三个质疑——「接口不是标准协议（标品）吗」「下游不想要新玩家吗」「美国不能出一个新厂吗」。正面答掉，认知立刻显深。
- 关键区分（务必分清）：
  - **这是允许的、且鼓励的**：顺着事实推到读者会卡的点，自然抛出并答掉。它服务事实流，不是作者演戏。
  - **这是禁的（见 `创作准则.md` 逻辑禁令）**：先甩一个结论、再由作者自己推翻或设问自答来反转（「容易想错的是…答案是」「表面是 X 其实不是」再由自己驳倒）。前者是接住真质疑，后者是伪辩证，味道天差地别，别混。

操作口诀：每写完一个有张力的判断，列 2-3 个「普通人读到这会反问什么」，挑最致命的一两个写进正文答掉。

## 方法四：改稿纪律（避免越改越乱）

多次重写时极易丢东西或抖出怪节奏，两条硬纪律：

### 4.1 git 比对第一版，找回被吞的内容

重写 / 重构前，先 `git show HEAD:<path>` 调出已提交的第一版，和当前版逐段 diff。多次重写常会：
- 把原本**单独成段的过渡句**全并进大段（丢失节奏）；
- 丢掉**定性句**（如「本质上是标品」被改成描述性）；
- 丢掉**精彩引言金句**。

找回后，按 4.2 筛选再决定留哪些，不要无脑全恢复。

### 4.2 过渡句信息量筛选（拒绝「神经抽搐」）

单独成段的短句，必须承载**真实信息**（转折 / 收束 / 新视角），纯领航废话（「下面讲 X 了」「先说存储的本来面目」「更关键的是产能这一环」「X 是个现成的例子」）不要单独成段，融进段落。

机械恢复「所有单独成段」会造出每节前面抖一下的排比节奏，像神经抽搐。判断标准：这句去掉后，上下文还连不连得起来？连得起 = 纯领航，融掉；连不起来或它本身就是转折点 = 保留单独成段。

典型该保留单独成段的：「但 AI 把故事改了一半。」（真转折）、「再回头看长鑫科技。」（从泛论收回到样本）。

## 红线提醒

- 禁止先抛结论再自己推翻 / 设问自答反转（伪辩证，臭熏天）。
- 浅判断（「护城河很高」「这是成长股」）要往下挖一层（叠透镜）再写，别停在套话。
- 事实流模式下，结论交由事实与读者，不替读者下对错结论；但「不替下结论」≠「不分析」，分析该深照样深。
