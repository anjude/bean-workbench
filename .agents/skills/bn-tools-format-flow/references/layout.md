# 排版参数与检查边界

## 配置

`formatter.py -c config.json` 接收局部覆盖，未填写的值沿用模板：

```json
{
  "accent_color": "#009874",
  "heading_color": "#009874",
  "emphasis_color": "#009874",
  "quote_bg": "#effaf4",
  "card_bg": "#f6fbf8",
  "font": {"body_size": "15px", "line_height": "1.9", "letter_spacing": "1px"},
  "spacing": {"paragraph_margin": "16px", "padding_left_right": "1px"},
  "image": {"border_radius": "8px"},
  "heading_numbering": false
}
```

模板数值是可选样式，不称为微信官方硬性规范。默认的微信绿模板以 `#009874` 渲染标题、正文重点字和强调装饰。内置模板分别提供章节标题色与正文重点色，可用顶层 `heading_color` / `emphasis_color` 或 `font` 同名字段覆盖。左右留白默认 1px。最终视觉效果以公众号后台与手机预览为准；深浅模式须实际查看。标题是否进入正文由当前稿件和预览要求决定，避免重复标题。

## 段落排版

正文段落默认不做首行缩进，通过段落间距区分内容，适配网页和移动端常见阅读习惯。章节标题默认不加圆形序号；有序和无序列表使用常规列表样式，不套灰底卡片。

## 自动检查能做什么

`seo_check.py` 按本地规则计算标题、关键词分布和排版分数，并用 `sensitive-words.json` 做字符串匹配。该词表没有平台实时审核能力，也不包含有效的处罚推断；引用、否定句、专业术语可能误报。

旧资源中的「24–28 字最佳」「关键词密度 2%–5%」「每 300–500 字一图」等值只作为脚本启发式保留，不是内容门槛。不要为了评分擅改稿件。

关键词热度、搜索趋势、账号互动表现仅在用户要求时以实际可访问的数据研究；没有数据就标记未知。不迁入旧指南的搜索排名权重、账号评分公式和固定文章结构，因为没有验证依据，也会替用户做内容取舍。

## 支持范围

Markdown 标题、段落、引用、简单列表、图片、代码块、分隔线、简单表格可转为内联样式 HTML。复杂嵌套、数学公式和任意 HTML 不是完整支持的语法，须检查预览并按实际内容转换。链接在当前排版器中显示链接文字，不保证保留可点击行为；需要读者访问的出处应写清名称和地址，并核对成品。
