# 外部封面样本的创意切口

猫笔刀公众号封面作为选取封面创意切口的外部样本。其封面没有单一固定画风；可借鉴的是按当篇内容找一个具体、有趣、带情绪或戏剧性的视觉钩子，而不是把封面做成全文摘要。样本收集与观察见当前主题目录 `source/猫笔刀封面参考/`。

## 可借鉴的做法

- 不要求封面概括整篇内容，可以抓住文中一处有趣的细节、反差、意外、动作或人物反应。
- 用具体的人物、物件和场景承载这个切口；夸张、幽默、悬念或情绪冲突都可以成为视觉钩子。
- 让封面与文章重点有关联，但给画面留出趣味和想象空间；读者不必只看图就复述全文。
- 缩略图下仍应先看到那个钩子，避免细节太多、重点分散。
- 生成后用一句话说清画面切口；若必须额外解释才能建立关联，就换一个更具体的画面。

## 豆小匠的表达方式

- 保持笔触鲜明的绘画或艺术插画方向，不限定画派；可学习其选取画面切口的方式，不复制具体原图、梗图、影视截图或构图。
- 画面可按文章题材采用生活隐喻、直接场景或有趣细节，不套固定物件、配色或模板。
- 投资理财主题避免直接使用钱币、钞票、K 线、走势图或金融终端；可从等待、错过、落差、反转等真实内容关系中找画面切口。
