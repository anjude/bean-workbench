# 每日持仓自检清单

用于日报、持仓健康检查及操作前复检。沿用主 skill 的用户规则、数据与权限边界；这是研究检查流程，不是自动风控或交易执行器。

## 执行口径

- 先读正式记录，覆盖全部已报送正股、存续期权及本次候选，包含远期；未知仓位不补零。
- 同一标的的基本面与事件只研究一次；各行权价、到期日、方向和数量独立计算，最后合并组合。
- 每项结论使用：**已检未发现异常 / 发现风险 / 待核 / 不适用**。“风险”表示需评估的具体事实，不必等到突破硬限额；“未发现异常”只适用于已核范围，不表示整体安全。
- 每项具备：检查对象、结论、证据/来源与时点、未知范围、对当前选择的影响。它们是分析中的工作字段，默认不新增报告文件或过程文档。

## 六类股价驱动因素覆盖

八个执行环节负责推进检查，下列六类负责检查内容，不能因完成仓位/账户资金核算就省略股价驱动因素。逐标的考虑短期与长期影响，按相关性和可核数据给状态；已核覆盖可共享，不能以一条宏观新闻代替全部标的分析。

| 因素 | 短期核查 | 长期核查 | 对应执行环节 |
| --- | --- | --- | --- |
| 公司经营 | 财报、指引、订单及实际结果相对预期的变化 | 收入质量、竞争优势、利润率、自由现金流与资本开支回报 | 2、3、4 |
| 行业与产业链 | 同行财报、客户开支/砍单、供应和成本冲击 | 行业空间、周期、竞争格局、技术替代与议价能力 | 2、4、6 |
| 宏观与政策 | 利率及收益率预期、通胀/就业、汇率、能源、地缘与政策变化 | 增长环境、资本成本、监管和贸易制度变化 | 2、3、4、7 |
| 估值与预期 | 消息是否已计价、预期差与风险偏好变化 | 买入估值是否透支增长、合理假设及判断失效条件 | 2、3、8 |
| 资金与交易结构 | 资金流、拥挤、强制去杠杆、期权对冲、再平衡、价差与隔夜流动性 | 融资渠道、长期资本供给、投资者结构与所要求风险补偿 | 3、4、7 |
| 股东权益与治理 | 增发、可转债、回购、解禁/减持、并购、管理层变动 | 每股稀释或增厚、资本配置、债务优先顺序、激励及治理 | 2、3、4 |

- 市场资金供求与用户账户资金是两种检查，不能用账户未超融资上限代替市场流动性检查。
- 资金流、拥挤程度、做市商对冲方向及强制平仓若无可验证数据，标待核；成交放大、下跌或高期权持仓量本身不能证明原因或方向。
- 已发生的下跌归因与事前风险识别分开：列已知事实、合理推断和未知项，不为每次涨跌强配单一原因；同一因素可能同时影响短期与长期。

## 检查顺序

| 环节 | 必查问题 | 影响后续判断的条件 |
| --- | --- | --- |
| 1. 仓位与数据 | 最新成交是否同步？合约、股数、张数、乘数和到期日是否一致？行情属于什么时段，bid/ask与IV是否有效？ | 冲突先定位；未知仅限制对应计算。不能把旧仓、已平仓合约、冻结价当作当前事实。 |
| 2. 长期资格 | 需求与竞争地位是否持续？利润能否变成现金？债务、再融资、资本开支、每股稀释、资本配置、治理及客户依赖是否恶化？原长期判断是否被推翻？ | 分别判断经营资格、股东每股受益与当前估值；资格未证实不推荐新增风险。ETF另评产品适合度及每日重置等机制。 |
| 3. 价格与预期 | 当前价格隐含的增长和盈利要求是否合理？新消息相对市场预期有什么变化？股价与行业走势是否出现需要解释的偏离？ | 区分价格变便宜与基本面变差；数据不足不伪造合理价，不凭跌幅、图形或IV高就判断适合买入。 |
| 4. 事件与传导 | 未来14天的宏观、自身、同行、主要客户、供应商、政策及融资事件有哪些？是否有增发、回购、解禁/减持、并购及管理层变化？开仓当晚盘后至候选到期新增跨越什么？ | 写清事件上海时间、确认/预估、传导路径和影响；ETF无自身财报也检查行业与成分股。候选超出14天时补查已知的跨期重要事件，不能声称远期全覆盖。 |
| 5. 合约与到期 | 本周、未来7天、全部存续合约各有多少义务？哪些价内、临近指派？全部接股/交割后各标的多少股？ | 结合实际交易截止时刻及夏冬令时判断紧迫性；Put接股意愿、最高总股数与Call覆盖未知不能默认满足。 |
| 6. 资金与共同风险 | 已知正股市值＋全部Put毛接股义务是否符合用户资金口径？融资上限、到期聚集、同行业及同一需求驱动的风险如何？ | 资金合并、正股不重复计、远期不漏算；不把预算余量当真实购买力。未确认集中度上限不自设，未知相关性不编系数。 |
| 7. 压力与可交易性 | 资金供求、拥挤/去杠杆或期权对冲是否可能放大波动，有何证据？事件跳空、继续下跌或波动上升时，单笔及组合承担什么？能否在相应时段买回、展期或接受交割？ | 依产品与事件选少量情景，披露假设、金额、股数；区分到期损益、内在价值和当前平仓成本。涉及现有股票一起看，不因下跌后预算余量变大便断言风险下降。 |
| 8. 周目标与方案 | 本周及用户指定归属周的已确认收入是多少？持有、接股、平仓、降价/同价roll、新开或等待各有什么代价？ | 先匹配周区间，包括已确认未来周收入；不重复累计roll双腿或互斥候选。不为完成目标提高风险，模型与报价结果按主skill并列。 |

## 长期与短期分开更新

- **每日核查变化**：新公告和事件、价格/预期变化、融资变化、到期紧迫性、持仓及组合压力。旧判断遇到新反向证据时重新评估，不能仅转述昨天的结论。
- **长期研究按需重评**：引用已有研究的依据和核验日；财报、重大订单/客户变化、政策、融资/稀释及治理等可能影响原判断时重评对应部分。没有研究底稿则保持待核，不能每天写“长期逻辑未变”。
- **候选操作单独复检**：检查交易后状态，不能只证明交易前未超限。新增张数、提高行权价、延长期限、跨越新事件和增加共同风险都需显式比较；收取净credit不代表风险下降。
- **进入实际决定前**：落实用户当次清醒及情绪条件；只读日报不反复要求自评，也不从聊天时段推断。行情、仓位或重要事件有变化时刷新受影响检查项。

## 从检查到结论

| 发现 | 应怎样表达和推进 |
| --- | --- |
| 用户已确认硬边界被突破，或有紧迫到期/交割风险 | 在日报第一层明确金额、期限和影响；比较降低风险、平仓或交割等方案，不自动下单或强制替用户决定。 |
| 长期资格、接股数量等关键适合度条件待核/不满足 | 明确目前不支持新增风险的原因；存量仍分析持有、接股、平仓及风险调整方案，不因待核遗漏风险提醒。 |
| 重大事件将到来，结果不可知 | 比较事件前后及替代期限的风险收益；需要时将等待作为优先候选，不把每次事件一律设为禁止交易。 |
| 缺有效报价、IV或合约身份 | 限制对应结论；有根据时给参考情景或观察条件，不声称可成交、不补造模型或报价。 |
| 已检范围内未发现新异常，但仍有未知项 | 简述检查范围和关键待核，不输出整体安全或所有条件通过。 |

## 日报如何呈现

- 沿用主skill现有日报结构，检查清单不另占一个完整模块。
- 将改变判断的结果写进“今天看这三件事”，例如关联财报新增、接股数量变化、融资超限或长期判断失效，并说明需要做什么选择。
- 持仓表提供对应合约与金额，资金结论给组合合计；同一事实不在多个段落重复。
- 证据时点、报价限制及其他数据说明集中在末尾。用户要求展开自检时，再按“标的｜长期资格｜估值/预期｜自身及关联事件｜接股/压力｜结论与触发条件”展示详情。
- 不在未执行检查时宣称已完成自检；本清单的建立也不代表当前所有标的已经通过。
